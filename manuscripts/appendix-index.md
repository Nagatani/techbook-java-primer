# 付録一覧<small>本文を補う資料集</small>

本書の付録は、本文と並行して使う資料（付録A・付録E）、本文の内容を深く掘り下げる資料（付録B・付録C）、本文で要点だけを説明した内容の詳しい資料（付録D・付録F・付録G）に分かれます。
付録の本体はGitHubリポジトリの`appendix/`で公開しています<span class="footnote">`https://github.com/Nagatani/techbook-java-primer/tree/main/appendix/`です。</span>。
紙面の各付録では、内容の概要・関連する章・資料の場所を示します。

## 付録の構成

| 付録 | 題名 | 内容 | 関連する章 |
|---|---|---|---|
| A | 開発環境の構築 | JDK 25とIDEの導入、OSごとの手順、トラブルシューティング | 第1・2章 |
| B | 技術的な詳細解説（Deep Dive） | JVM・コレクション・Stream・メモリモデルなどの内部の解説（15節） | 各章 |
| C | ソフトウェア工学の理論的基盤 | 品質メトリクス、抽象データ型、仕様記述などの理論と実装例 | 第3〜7・13・15・25章 |
| D | 高度なビルドとデプロイメント技術 | Maven・Gradleによる自動化、Fat JAR、jpackageの応用 | 第22・23章 |
| E | Javaのよくあるエラーと対処法 | エラー別の解説と、各章末の「よくあるエラーと対処法」の詳細 | 全章 |
| F | Swingの発展的な機能 | PropertyChangeSupport、ドラッグ&ドロップ、デバウンス、ツリーの動的な操作、セルエディター | 第19・20章 |
| G | 外部ライブラリの使用例 | OkHttp・Lombok・Guavaの依存関係とコード例 | 第22・26章 |

## 付録の使い方

1. 本書を読み始めるとき
    + 付録Aで開発環境を整える
2. 各章を読むとき
    + エラーで手が止まったら付録Eを、仕組みをもっと知りたくなったら付録Bの関連する節を開く
    + 第19・20章の発展課題やチャレンジ課題に取り組むときは、付録Fのコード例を参考にする
3. 本文を読み終えたあと
    + 作ったものを配布する方法をさらに学ぶなら付録Dに進む
    + 設計の判断の背景にある理論を知りたいときは付録Cを読む
