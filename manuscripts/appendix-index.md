# 付録一覧<small>実践と理論を深める資料集</small>

本書の付録は、実践的な開発に必要な環境構築手順から、JVMの内部動作やパフォーマンス最適化手法まで、幅広い内容を網羅しています。各付録は独立して読むことができますので、現在の学習段階やプロジェクトの要求に応じて参照してください。

## 付録の構成

### 付録A: 開発環境の構築

Java開発を始めるための環境構築手順を詳細に解説します。
初学者の人は、まずこの付録を参照して開発環境を整えてください。

主な内容は次のとおりです。

- SDKMANを使ったJDKのインストールとバージョン管理
- 統合開発環境（IDE）のセットアップ
- コマンドラインでのコンパイルと実行
- OSごとの手順とトラブルシューティング
- Docker環境での開発と、環境構築の自動化スクリプト



### 付録B: 技術的な詳細解説（Deep Dive）

本書の各章で扱った技術的概念について、より深い理解を提供する上級者向けの内容です。15の節で構成されており、節の番号はGitHubリポジトリの`appendix/`<span class="footnote">`https://github.com/Nagatani/techbook-java-primer/tree/main/appendix/`です。</span>のディレクトリ名（b01〜b15）と一致しています。

- 言語基盤と設計の考え方（第1〜3・11章関連）: B.01〜B.03
- オブジェクト指向（第5〜6章関連）: B.04〜B.05
- コレクション・ジェネリクス・Stream（第9・10・12章関連）: B.06〜B.08
- 言語機能（第7・8・13章関連）: B.09〜B.12
- I/O・並行処理（第14〜15章関連）: B.13〜B.14
- テスト（第21章関連）: B.15

各節のサンプルコードと実装例は、GitHubリポジトリの各ディレクトリにあります。
詳細は付録Bを参照してください。



### 付録C: ソフトウェア工学の理論的基盤

ソフトウェア開発の背景にある理論的な概念の要点を、Javaの実装例で示します。

主な内容は次のとおりです。

- 複雑度・結合度・凝集度などのソフトウェア品質メトリクス
- 抽象データ型・カプセル化・リスコフの置換原則
- デザインパターンの理論的分析
- 計算量の解析
- 事前条件・事後条件・不変条件による仕様記述
- 並行プログラミングの理論（データ競合、デッドロック、メモリモデル）



### 付録D: 統合プロジェクト

本書で学んだ知識を総合的に活用する統合プロジェクトです。
学生管理システムを6つのフェーズで段階的に組み立てながら、学習内容を深めます。

主な内容は次のとおりです。

- クラス設計と継承によるデータのモデル化
- コレクションとStream APIによる検索・集計
- 例外処理とCSVファイルの入出力
- SwingによるGUI
- SQLiteデータベースによるデータの永続化



### 付録E: データベースプログラミング

Javaアプリケーションとデータベースの連携について詳しく解説します。

主な内容は次のとおりです。

- JDBCの基礎と実践
- SQLの基本操作
- トランザクション管理
- コネクションプール
- java.timeとの連携



### 付録F: java.time API完全ガイド

Java 8で導入された日時APIの使い方を解説します。

主な内容は次のとおりです。

- 日時クラスの体系
- タイムゾーンの扱い
- 日時の計算と操作
- フォーマッティング
- レガシーAPIとの相互変換



### 付録G: 高度なビルドとデプロイメント技術

第23章で学んだ内容を発展させ、開発したアプリケーションを配布可能な形式にパッケージングする方法を解説します。

主な内容は次のとおりです。

- MavenとGradleによる実行可能JARの作成
- 依存ライブラリを含むFat JARの作成
- jpackageによるネイティブアプリケーション化
- 各OS向けのパッケージング
- そのままビルドできるサンプルプロジェクト



### 付録H: Java共通エラーガイド

Javaプログラミングで頻繁に遭遇するエラーパターンを体系的にまとめ、効果的な対処法を解説します。

主な内容は次のとおりです。

- 実行時例外の詳細と対処法
- コンパイルエラーの理解と解決
- スタックトレースの読み方とデバッグ手法
- 各章末の「よくあるエラーと対処法」の詳しい内容

## 付録の活用方法

1. 初学者のかた
    + まず付録Aで環境を整え、本文の学習を進めてください
2. 実践的な開発を始めるかた
    + 付録Dの統合プロジェクトで、複数の技術を組み合わせたアプリケーション開発を体験してください
3. より深い理解を求めるかた
    + 付録Bシリーズで技術的な詳細を学習してください
4. 理論的背景に興味があるかた
    + 付録Cでソフトウェア工学の基礎を学んでください

各付録は、本文の理解を深めるための補助教材として設計されています。たとえば、第9章のコレクションを学習中なら付録B.06で内部実装を理解し、第15章のマルチスレッドを学んだら付録B.14で並行処理の詳細を確認するなど、学習の進捗に合わせて参照することをオススメします。
