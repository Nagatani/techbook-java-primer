## 付録Eについて

本付録では、JavaのJDBC（Java Database Connectivity）<span class="footnote">JDBCはJDK 1.1から標準APIに含まれています。データベースごとの違いはJDBCドライバーが吸収するため、同じAPIで多くのデータベースを扱えます。</span>を使用したデータベースプログラミングについて、実践的な内容を詳しく解説しています。

### 学習内容

データベースプログラミングは、現代のアプリケーション開発において不可欠な技術です。
本付録では、実践的なデータベースアプリケーション開発に必要な次のトピックを学習します。

1. SQL基礎の復習
    + リレーショナルデータベースの基本概念とSQL文法
2. JDBCの基本
    + データベース接続とCRUD操作の実装
3. PreparedStatement
    + SQL Injectionを防ぐ安全なSQL実行
4. DAOパターン
    + データアクセス層の設計と実装
5. java.timeとの連携
    + 日付と時刻の列をLocalDateTimeなどで読み書きする
6. トランザクション管理
    + ACID特性の理解と実装
7. コネクションプール
    + 接続を再利用して性能を上げるしくみ
8. バッチ処理
    + 大量のデータをまとめて送って処理する手法

### 学習のポイント

データベースプログラミングを学ぶ際には、いくつかの重要な注意点があります。
これらの点を意識することで、より効率的に理解を深められます。

1. セキュリティ
    + SQL Injectionなどの脆弱性を理解し、つねに安全なコーディングを心がける
2. パフォーマンス
    + インデックス、バッチ処理、コネクションプールの役割を理解する
3. トランザクション
    + データの整合性を保つため、まとめて成功・失敗させる範囲を決める
4. エラーハンドリング
    + データベース特有の例外を捕まえ、接続を確実に閉じる
