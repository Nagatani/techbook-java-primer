# <b>付録A</b> <span>開発環境の構築</span> <small>JDKとIDEの詳細セットアップ</small>

## 付録Aについて

本付録では、本書のプログラムを動かすための開発環境の作り方を説明します。
第1章で紹介した手順を、OSごとの違いやトラブルへの対処まで含めて詳しくしたものです。

### 内容

1. JDKの種類と選び方、SDKMANによるJDK 25のインストールと版の切り替え
2. IntelliJ IDEAとVisual Studio Codeのセットアップと設定ファイルの例
3. コマンドラインでのコンパイルと実行、標準入力の扱い方
4. Windows・macOS・Linuxごとの手順
5. トラブルシューティング、環境構築のチェックリスト、FAQ
6. Dockerを使った開発環境と、環境構築の自動化スクリプト（任意）

IntelliJ IDEAは、2025.3（2025年12月8日公開）からCommunity EditionとUltimateが「IntelliJ IDEA」という1つの製品に統合されました。
統合版をインストールすれば、Community Editionにあった機能は無料のまま使えます。
本書の学習には、サブスクリプションが必要な機能は使いません。
