# 印刷所へ入稿するPDF

KDP以外の印刷所やオンデマンド印刷のサービスへ入稿するときのPDFです。正規版に、トンボ（裁つ位置の印）と塗り足し（3mm）を付け、印刷所で広く使われるPDF/X-1aの形式にします。

2026-11-18の時点で、このコマンドで最後まで作ったことはまだありません（トンボと塗り足しが付くことだけは確かめてあります）。初めて使うときは時間に余裕を持ってください。

## 作る

DockerのDesktopを起動しておきます。PDF/X-1aへの変換はVivliostyleがDockerの中で行います（初回は変換用のイメージを取得するので時間がかかります）。

```bash
docker info > /dev/null && echo "Docker OK"   # Dockerが動いているか
npm run build:press                           # → output/techbook-java-primer-press.pdf
```

トンボや塗り足しの幅を変えたいときは、`package.json`の`build:press`の`--bleed 3mm`などを変えるか、次のように直接オプションを渡します。

```bash
BOOK_EDITION=release npx vivliostyle build --crop-marks --bleed 5mm --preflight press-ready -o output/techbook-java-primer-press.pdf
```

## 確かめる

- ページの大きさ
    + 仕上がり（176×250mm）に、塗り足しとトンボの分が足された大きさになっている
- トンボ
    + 四隅と各辺の中央にトンボが付いている
- 表紙
    + 1ページ目の紺の地が塗り足しの外まで広がっている（仕上がりの線で切っても白い縁が出ない）
- PDF/X-1a
    + Adobe Acrobat Proがあれば「印刷工程」→「プリフライト」で「PDF/X-1aへの準拠を確認」を流す
    + Acrobatがなければ、印刷所の入稿前チェック（多くの印刷所がWebで提供している）を使う
- 色
    + PDF/X-1aではRGBの色がCMYKに変換されるので、表紙の紺やコードの色分けがくすむ。気になる色は印刷所の色見本や校正刷りで確かめる
- 文字
    + すべてのフォントが埋め込まれている（PDF/X-1aでは必須。変換で自動的に埋め込まれる）

## 印刷所の仕様に合わせる

入稿する前に、印刷所の入稿の手引きで次の点を確かめ、違っていれば設定を変えます。

| 項目 | いまの設定 | 変えるところ |
|---|---|---|
| 塗り足し | 3mm | `package.json`の`build:press`の`--bleed` |
| 形式 | PDF/X-1a | `--preflight`の指定（`press-ready`はPDF/X-1a） |
| 表紙 | 本文のPDFの1ページ目に入っている | 表紙を別のファイルで求められたら、本文から表紙を外す設定が要る（KDP向けの`build:kdp`のように、Claudeに依頼して加える） |
| 総ページ数 | 約766ページ | 16の倍数や4の倍数を求められたら、白紙のページを足すか内容で調整する |
| のどの余白 | 通常の組版（綴じ方によっては足りない） | 無線綴じで厚い本はのどが見えにくくなる。KDP向けの`kdp-theme.css`のような広げ方を検討する |
