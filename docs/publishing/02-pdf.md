# PDF（ALPHA版・正規版）

本の組版はすべてVivliostyleで行い、設定は`vivliostyle.config.js`、テーマは`theme/my-theme/`にあります。KDPの本文PDF（[04-kdp-paperback.md](04-kdp-paperback.md)）と入稿用PDF（[06-press.md](06-press.md)）は、ここで作るPDFと同じ組版に余白や塗り足しを加えたものです。紙面の目での確認は、このファイルの手順で正規版のPDFに対して1回行えば足ります。

## 作る

```bash
npm run build           # ALPHA版 → output/techbook-java-primer.pdf
npm run build:release   # 正規版  → output/techbook-java-primer-release.pdf
```

どちらも最初に`npm run mermaid:convert`が動き、図の元データ（`docs/diagrams/*.mmd`）からSVGを作り直します。ビルドには数分かかります。

ブラウザーで1ページずつ見ながら直したいときは、プレビューを使います。

```bash
npm run preview           # ALPHA版
npm run preview:release   # 正規版
```

## ページ数を確かめる

macOSでは次のコマンドでページ数を表示できます。

```bash
mdls -name kMDItemNumberOfPages output/techbook-java-primer-release.pdf
```

2026-11-18の時点で、KDPの本文PDFは766ページです（ALPHA版・正規版もほぼ同じ）。ページ数はKDPののどの幅、背幅、印刷の費用に関わるので、出版の前に必ず確かめます。

## 紙面を目で確かめる

PDFを最初から最後まで通して見ます。見開きの表示（macOSのプレビューなら「表示」→「2ページ」）にすると、左右のページの余白と柱を見比べられます。

### 毎回見るところ

- 表紙
    + 正規版に「ALPHA VERSION」が出ていない
    + ALPHA版には出ている
- 目次
    + 各項目の右端のページ番号が、実際の章・付録の始まりのページと合っている
    + 前付けのノンブルがローマ数字（i、ii、…）になっている
- 第1章
    + 第1章の最初のページのノンブルが1である
    + 右ページから始まっている
- 奥付
    + 正規版の発行日と「初版第1刷発行」の表示が正しい（「2026年○月○日」のままになっていない）
    + ALPHA版ではビルドした日と「ALPHA版（Web配布版）」が出ている
    + 著作権表示の年（「© 2025–2026」の後ろはビルドした年）

### 通して見るところ

- 改ページ
    + 見出しだけがページの最後に残っていない
    + コードブロックの分かれ方が不自然でない（1〜2行だけが次のページへ送られていない）
- はみ出し
    + 図・表・コードが紙面の右へはみ出していない（2026-11-18に第2章の表で見つかった。セルの中の長いインラインコードは折り返さないので、はみ出しやすい）
- 空白
    + 意図しない空白のページや、ページの下半分が大きく空いた箇所がない
- 図
    + 文字が読める大きさで、線が文字に重なっていない（`check:diagrams`で拾えない線どうしの交差など）
- 脚注
    + ページの下端に出ており、本文と重なっていない
- 柱とノンブル
    + 左右のページで正しい位置に出ている
    + 最初のページ（表紙）には出ていない

見つけた問題は、その場で直すか`docs/analysis/issues-tracking.md`に記録します。テーマを直した場合は、ほかの章に影響が出ていないかを、PDFを作り直して確かめます。

## 印刷して確かめる

画面では気付きにくい点（文字の大きさ、コードの色の濃さ、のどの余白）を確かめるため、何章かを実際の大きさで印刷して見ることを勧めます。B5の紙がなければ、A4に「実際のサイズ」（拡大・縮小なし）で印刷します。コードの色分けは白黒で刷ると濃淡だけになるので、白黒で印刷して読めるかも見ます（KDPのペーパーバックは白黒で刷る想定です）。

## よくある問題

| 症状 | 原因と対処 |
|---|---|
| ビルドが図の変換で止まる | 原稿に```mermaidのブロックを直接書いている。元データを`docs/diagrams/`に移す（`CLAUDE.md`の方針11） |
| 本の中のリンクがPDFで開けない | リンク先を`xxx.md#...`の形で書いているか確かめる（ビルド時に`.html`へ直される） |
| 段落の文字の間が開く | 原稿の改行やインラインコードの折り返し位置が原因のことが多い。`scripts/vfm-line-breaks.js`の対象か確かめる |
| PDFの日付が古い | `output/`に前のPDFが残っている。ビルドが途中で失敗していないか、ターミナルの表示を確かめる |
