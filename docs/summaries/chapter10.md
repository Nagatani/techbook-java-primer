# 第10章 ジェネリクス 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter10-generics.md` を参照する。

## 章の概要

- 第9章で説明なしに使った`List<String>`の記法を回収し、raw typeのClassCastExceptionを動機にジェネリクスを導入する
- ジェネリッククラス（Box<T>）、ダイヤモンド演算子、ジェネリックメソッド、境界のある型パラメータ（`<T extends Number>`）、ワイルドカード（`?`、`? extends`、`? super`）を順に扱う
- 後半はvar型推論に大きく紙幅を割き、最後にエラー集とまとめを置く
- 前提は第9章のコレクション。章は1つの版で構成されており、第9章や第11章のような版の結合はない

## 構成上の問題

- 章内の配分の偏り
    + ジェネリクスの中核（クラス・メソッド・境界・ワイルドカード）はL201–375の約175行に対し、var型推論の節はL376–726の約350行ある
    + ワイルドカード節は`? extends`の例（10-10）だけで、`? super`のコード例がない
- 学習目標と本文の不一致
    + 学習目標に「型消去の仕組み」「PECS原則」「複数の型パラメータ」を挙げるが、型消去はエラー集（10-23、10-24）と付録参照で触れるだけ、PECSという語は本文に出ない（L342–343でProducer/Consumerに触れる程度）、複数の型パラメータはvar節の10-14（Pair<T, U>）に埋もれている
    + 学習目標で「型パラメータと型引数」を区別すると予告するが、L172は`List<String>`の`String`を「型パラメータ」と呼んでいて用語が逆になっている
- 同じ内容の重複
    + raw typeのClassCastExceptionを10-2/10-3（「まずは問題を体験してみよう」「ジェネリクスによる解決」）と10-4/10-5（「型安全性の重要性」「基本概念」）で二度説明し、エラー集の10-17/10-18で三度目を扱う。第9章のエラー集（9-30 Raw type）とも重なる
    + ジェネリクスの利点の列挙がL114–117とL165–170で重複
- 前提知識と章順の矛盾
    + var節のサンプル（10-13〜10-16）はStream API（第12章）、ラムダ式・メソッド参照（第11章）、ConcurrentHashMap（第15章）を説明なしで使う（2026-11-08に、初出の箇所へ後の章で学ぶ旨と最小限の読み方の案内を加えた）
    + エラー集の10-20はSupplier（第11章）を、10-24はリフレクション（Array.newInstance）を説明なしで使う
- 統合するなら、10-2〜10-5を1組に絞り、var節を「ジェネリクスと関係する範囲」に縮めて残りは第2章や付録に回し、`? super`とPECSの例を追加するのが自然

## 節ごとの要約

- 本章の学習目標（L3–19）
    + ジェネリクスの基本（型消去を含む）、ジェネリッククラスとメソッド、境界ワイルドカード（PECS）、var型推論の4項目。前提は第9章のみ
- なぜジェネリクスが必要なのか？（L20–207）
    + 第9章で見た`<>`の記法を提示（10-1）
    + raw typeのリストに数値が混入してClassCastExceptionになる例と、ジェネリクスで書き直した例（10-2、10-3）
    + Java 5以前の状況を同じ構図で再説明（10-4）し、パラメータ化された型の3つの利点（コンパイル時検査・キャスト除去・再利用性）と`List<String>`の例（10-5）
- ジェネリッククラスの作成（L208–264）
    + 型パラメータTを持つBox<T>の定義と利用（10-6）
    + Java 7のダイヤモンド演算子（10-7）
- ジェネリックメソッド（L265–300）
    + 戻り値型の前に`<T>`を宣言するprintArray（10-8）。型推論でTが決まる
- 型制約（境界のある型パラメータ）（L301–343）
    + `<T extends Number>`のNumericBoxで、Numberのメソッド（doubleValue）を呼べることを示す（10-9）
- ワイルドカード（L344–382）
    + `List<?>`、`? extends`（Producer）、`? super`（Consumer）の3種を箇条書きで説明
    + `List<? extends Number>`の合計計算（10-10）。`? super`の例はない
- var型推論とジェネリクス（L383–658）
    + varの基本と従来の書き方・ダイヤモンド演算子との比較（10-11）
    + 使える場面と使えない場面（10-12）
    + 可読性のよい例・悪い例（10-13）、複雑なジェネリック型やジェネリックメソッドの戻り値との組み合わせ（10-14）
    + ベストプラクティスとアンチパターン（10-15）、リファクタリング例（10-16）、使用判断の基準
    + 末尾で付録B.07「型消去とジェネリクス」を参照する（付録B索引ではB.08。Issue #011）
- よくあるエラーと対処法（L659–678）
    + 2026-11-09に、エラーメッセージの例・修正コード・デバッグのヒントを`appendix/h-common-errors/chapters/chapter10.md`へ移した。本文には出会いやすいエラーと原因の要点のリストとGitHubのURLだけを残す
    + 本文に挙げるエラー: Raw typeの使用、型パラメータの使い方の誤り、ワイルドカードの誤用、型消去に関する問題、境界型パラメータの問題、varによる型推論の誤用
- まとめ（L679–691）
    + ジェネリクスの目的、自作ジェネリック型、型制約・ワイルドカード、var型推論の要点
- 章末演習（L692–714）
    + 演習リンクは`exercises/chapter10/`（2026-11-09に演習ディレクトリを現行の章番号に組み替え、リンクを直した。Issue #010）。次章の第11章への案内

## 校正で見つけた個別の問題

- 10-16: `import java.util.*;`だけでは`ConcurrentHashMap`（java.util.concurrent）が解決できず、コンパイルできない
- 10-6、10-9: 1つのコードブロックにpublicクラスが2つあり、1ファイルとしてはコンパイルできない
- 10-20、10-24: Supplier、java.lang.reflect.Arrayのimportがなく説明もない。10-26は計算結果を設定しておらず、対処法として不完全
- 10-4はコンパイル時の注意を日本語のjavacメッセージで示し、エラー集は英語のjavacメッセージで示しており、表記が混在（エラー集のEclipse形式のメッセージは2026-11-08にjavacの出力へ置き換えた）
- 10-15、10-17〜10-28: コードコメントに絵文字（✅、❌）を使っている
- L707: 「var型推論を使用するかどうかの判断基準。」が文として不完全。L709、L715はリスト項目の文末に句点がある
- L114: 見出し（####）を「ジェネリクスを使うことで」というリスト導入文として使っている
- L733ほか: エラー集の小見出しがH3からH5（#####）に飛んでいる
- L996とL1005: 「詳細な課題内容と実装のヒントは…README.mdを参照してください」が重複
- L983: まとめで「ローカル変数の宣言ではvar型推論を活用」と一律に勧めていて、var節の「使いすぎると可読性を損なう」という説明と温度差がある
