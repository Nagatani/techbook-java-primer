# 第10章 ジェネリクス 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter10-generics.md` を参照する。

## 章の概要

- 第9章で説明なしに使った`List<String>`の記法を回収し、raw typeのClassCastExceptionを動機にジェネリクスを導入する
- ジェネリッククラス（Box<T>）、ダイヤモンド演算子、ジェネリックメソッド、境界のある型パラメーター（`<T extends Number>`）、ワイルドカード（`?`、`? extends`、`? super`）を順に扱い、最後にvar型推論をジェネリクスと関係づけて扱う
- 前提は第9章のコレクション
- 2026-11-11に、raw typeと利点の説明の重複を1か所にまとめ、var節からStream API・ラムダ式・ConcurrentHashMapの先取りを外した。サンプルコードは12本になった

- 章内の配分の偏り

    + ワイルドカード節は`? super`を文章と図（chapter10-wildcard-bounds）で説明するが、コード例は`? extends`の10-8だけ（2026-11-12に解消。10-8に`List<? super Integer>`へ追加する`addNumbers`を足した）
- 学習目標と本文の不一致
    + 学習目標に「型消去の仕組み」「PECS原則」を挙げるが、型消去はエラー集の1項目と付録B.07の参照で触れるだけ、PECSという語は本文に出ない（2026-11-12に解消。学習目標を「型消去のしくみは付録B.07で扱う」とし、ワイルドカード節にPECS原則の名前を1文で加えた）
    + 複数の型パラメーターは、学習目標ではジェネリッククラスとメソッドの項目に挙げるが、var節（10-12の`Pair<T, U>`）で説明していた（2026-11-14に解消。「ジェネリッククラスの作成」に小節「複数の型パラメーター」を置き、第9章の`Map<K, V>`を例に説明する。10-12はそこを参照する）
    + 型パラメーターと型引数の用語の逆転（2026-11-11に解消。L138で区別している）
- 同じ内容の重複（2026-11-11に解消）

- 説明の順序（2026-11-14に解消）

## 節ごとの要約

- 本章の学習目標（L3–19）
    + ジェネリクスの基本（型パラメーターと型引数、型消去）、ジェネリッククラスとメソッド（複数の型パラメーター）、境界ワイルドカード（PECS）、var型推論の4項目。前提は第9章のみ
- なぜジェネリクスが必要なのか？（L20–146）
    + 第9章で見た`<>`の記法を、第9章と同じダイヤモンドの形で提示（10-1）
    + raw typeのリストに数値が混入してClassCastExceptionになる例（10-2）。実際の表示ではモジュールの情報とスタックトレースが続く旨を添える。コンパイル時には注意（ノート）が出るだけであることを示し、Java 5でジェネリクスが入った経緯を述べる
    + ジェネリクスで書き直した例（10-3）。数値を足す行がコンパイルエラーになる
    + パラメーター化された型、型引数と型パラメーターの区別、利点4点（コンパイル時検査・キャスト不要・意図の明確化・再利用性）
- ジェネリッククラスの作成（L147–206）
    + 型パラメーターTを持つ`Box<T>`の定義と利用（10-4）。右辺も`new Box<String>()`と型引数を書く
    + Java 7のダイヤモンド演算子（10-5）。10-4の右辺の型引数を省けること、第9章のコード（10-1）で`<>`が空だったのはダイヤモンドのためであることを述べる
- ジェネリックメソッド（L207–243）
    + 戻り値型の前に`<T>`を宣言する`printArray`（10-6）。型推論でTが決まる
- 型制約（境界のある型パラメーター）（L244–287）
    + `<T extends Number>`の`NumericBox`で、Numberのメソッド（doubleValue）を呼べることを示す（10-7）
- ワイルドカード（L288–361）
    + `List<?>`、`? extends`（Producer）、`? super`（Consumer）とPECS原則を文章で説明し、当てはまる型を図で示す
    + `List<? extends Number>`の合計計算と、`List<? super Integer>`への追加（10-8）
- var型推論とジェネリクス（L362–585）
    + 長いジェネリック型を繰り返さずに済む点で本章に置く理由を述べる
    + varの基本と従来の書き方との比較（10-9）。varの変数の型は右辺の`ArrayList<String>`になり、`List<String>`とは異なること（`ArrayList`だけのメソッドを呼べる）を実行結果つきで示す
    + 使える場面（ローカル変数、ループ変数、try-with-resources（第13章）、Java 11以降のラムダ式の引数（第11章））と使えない場面（10-10）
    + 可読性のよい例・悪い例（10-11。数値リテラルは書き手の意図した型が伝わらない）、`Pair<T, U>`とジェネリックメソッドの戻り値との組み合わせ（10-12）
    + 使用判断の基準（型を明示する場面に「インターフェイスの型として扱いたい」を含む）と、varでも型安全性は変わらないこと。末尾で型消去などの高度な内容として付録B.07「型消去とジェネリクス」を参照する
- よくあるエラーと対処法（L586–605）
    + 出会いやすい誤り6点（Raw type、型パラメーターの使い方（クラスの型パラメーターはstaticメンバーで使えない）、ワイルドカードの誤用、型消去、境界型パラメーター、varの誤用）の要点と、付録H（`appendix/h-common-errors/chapters/chapter10.md`）のURL
- まとめ（L606–619）
    + ジェネリクスの目的、自作ジェネリック型、型制約・ワイルドカード、var型推論の要点。varは右辺から型が明らかな場面に絞ると書く
- 章末演習（L620–640）
    + `exercises/chapter10/`へのリンクと、基礎・発展・チャレンジ課題の概要。第11章への案内
