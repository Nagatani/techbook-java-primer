# 第10章 ジェネリクス 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter10-generics.md` を参照する。

## 章の概要

- 第9章で説明なしに使った`List<String>`の記法を回収し、raw typeのClassCastExceptionを動機にジェネリクスを導入する
- ジェネリッククラス（Box<T>）、ダイヤモンド演算子、ジェネリックメソッド、境界のある型パラメーター（`<T extends Number>`）、ワイルドカード（`?`、`? extends`、`? super`）を順に扱い、最後にvar型推論をジェネリクスと関係づけて扱う
- 前提は第9章のコレクション
- 2026-11-11に、raw typeと利点の説明の重複を1か所にまとめ、var節からStream API・ラムダ式・ConcurrentHashMapの先取りを外した。サンプルコードは12本になった

## 構成上の問題

- 章内の配分の偏り
    + var型推論の節（L338–544、約200行）が、ジェネリクスの中核（クラス・メソッド・境界・ワイルドカード、L146–337、約190行）と同じくらいの分量を占める（2026-11-11に約350行から縮めた）
    + ワイルドカード節は`? super`を文章と図（chapter10-wildcard-bounds）で説明するが、コード例は`? extends`の10-8だけ（2026-11-12に解消。10-8に`List<? super Integer>`へ追加する`addNumbers`を足した）
- 学習目標と本文の不一致
    + 学習目標に「型消去の仕組み」「PECS原則」を挙げるが、型消去はエラー集の1項目と付録B.07の参照で触れるだけ、PECSという語は本文に出ない（L293・L296でProducer/Consumerに触れる程度）（2026-11-12に解消。学習目標を「型消去のしくみは付録B.07で扱う」とし、ワイルドカード節にPECS原則の名前を1文で加えた）
    + 複数の型パラメーターはvar節（10-12の`Pair<T, U>`）で説明している（2026-11-11に、L470–471で書き方を説明するようにした）
    + 型パラメーターと型引数の用語の逆転（2026-11-11に解消。L137で区別している）
- 同じ内容の重複（2026-11-11に解消）
    + raw typeのClassCastExceptionは10-2・10-3の1組だけになり、ジェネリクスの利点はL139–144の1か所にまとめた。第9章のエラー集は本章へ誘導する
- 前提知識と章順の矛盾（2026-11-11に解消）
    + var節のサンプルからStream API・ラムダ式・メソッド参照・ConcurrentHashMapを外した。エラー集のSupplierやリフレクションのサンプルは付録Hへ移っている

## 節ごとの要約

- 本章の学習目標（L3–19）
    + ジェネリクスの基本（型パラメーターと型引数、型消去）、ジェネリッククラスとメソッド（複数の型パラメーター）、境界ワイルドカード（PECS）、var型推論の4項目。前提は第9章のみ
- なぜジェネリクスが必要なのか？（L20–145）
    + 第9章で見た`<>`の記法を提示（10-1）
    + raw typeのリストに数値が混入してClassCastExceptionになる例（10-2）と、コンパイル時には注意（ノート）が出るだけであることを示し、Java 5でジェネリクスが入った経緯を述べる
    + ジェネリクスで書き直した例（10-3）。数値を足す行がコンパイルエラーになる
    + パラメーター化された型、型引数と型パラメーターの区別、利点4点（コンパイル時検査・キャスト不要・意図の明確化・再利用性）
- ジェネリッククラスの作成（L146–203）
    + 型パラメーターTを持つ`Box<T>`の定義と利用（10-4）
    + Java 7のダイヤモンド演算子（10-5）
- ジェネリックメソッド（L204–240）
    + 戻り値型の前に`<T>`を宣言する`printArray`（10-6）。型推論でTが決まる
- 型制約（境界のある型パラメーター）（L241–284）
    + `<T extends Number>`の`NumericBox`で、Numberのメソッド（doubleValue）を呼べることを示す（10-7）
- ワイルドカード（L285–337）
    + `List<?>`、`? extends`（Producer）、`? super`（Consumer）を文章で説明し、当てはまる型を図で示す
    + `List<? extends Number>`の合計計算（10-8）
- var型推論とジェネリクス（L338–544）
    + 長いジェネリック型を繰り返さずに済む点で本章に置く理由を述べる
    + varの基本と従来の書き方との比較（10-9）、使える場面と使えない場面（10-10）
    + 可読性のよい例・悪い例（10-11）、`Pair<T, U>`とジェネリックメソッドの戻り値との組み合わせ（10-12）
    + 使用判断の基準と、varでも型安全性は変わらないこと。末尾で付録B.07「型消去とジェネリクス」を参照する
- よくあるエラーと対処法（L545–564）
    + 出会いやすい誤り6点（Raw type、型パラメーターの使い方、ワイルドカードの誤用、型消去、境界型パラメーター、varの誤用）の要点と、付録H（`appendix/h-common-errors/chapters/chapter10.md`）のURL
- まとめ（L565–578）
    + ジェネリクスの目的、自作ジェネリック型、型制約・ワイルドカード、var型推論の要点。varは右辺から型が明らかな場面に絞ると書く
- 章末演習（L579–601）
    + `exercises/chapter10/`へのリンクと、基礎・発展・チャレンジ課題の概要。第11章への案内
