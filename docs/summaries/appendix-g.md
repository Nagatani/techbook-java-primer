# 付録G 高度なビルドとデプロイメント技術 要約

行番号の正確な対応は `docs/book-index/appendix-g-build-and-deploy.md` を参照する。

## 章の概要

- 第23章の続きとして、Maven/Gradleによる自動化、Fat JAR、jpackageの高度な活用を扱う付録。本文は概要のみで、詳細はGitHubの`appendix/g-build-and-deploy/`（maven、gradle、scripts、troubleshootingなどが実在）にある
- サンプルコードはない

## 節ごとの要約

- 付録Gについて（L3–71）
    + 学習内容（L7–15）: ビルドツールによる自動化、Fat JAR、jpackage、プラットフォーム固有の設定、カスタマイズオプション、トラブルシューティングの6項目
    + 前提知識（L16–23）: 第23章（JAR作成、jpackage）、第22章（Maven、Gradleの基礎）
    + オンライン資料（L24–36）: リポジトリの内容5点
    + 関連する付録と章（L42–46）: 第23章、第22章。前提知識と同じ内容の再掲
    + 学習のポイント（L47–61）と実践への応用（L62–71）

## 他章との関係

- 第22章: Maven/Gradleの基礎を前提とする
- 第23章: 本付録の直接の前提。第23章とのどこまでが本編か、という境界（Maven/Gradleでのビルド自動化を第23章でどこまで扱うか）を第23章側の要約と照合する必要がある
