# 第3章 オブジェクト指向の考え方 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter03-oop-basics.md` を参照する。

## 章の概要

- C言語の構造体と関数の分離が招く問題（データ保護不可、関数管理の困難、変更の影響範囲）を動機に、オブジェクト指向の考え方を導入する
- オブジェクト・クラス・インスタンスの用語と、委譲・カプセル化・インターフェイス・継承の考え方を説明したあと、3原則を短いコードで示す
- クラスの構成要素（フィールド、メソッド、getter/setter、コンストラクタ、オーバーロード）、アクセス修飾子public/private、static、オブジェクトの配列を扱う
- 発展的な内容として、実用的なクラス設計例、equals/hashCode、Record・パターンマッチング・sealedクラスの紹介がある
- 前提は第2章（基本文法、staticメソッド、配列）とC言語の構造体の知識
