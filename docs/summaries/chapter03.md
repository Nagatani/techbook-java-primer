# 第3章 オブジェクト指向の考え方 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter03-oop-basics.md` を参照する。

## 章の概要

- C言語の構造体と関数の分離が招く問題（データ保護不可、関数管理の困難、変更の影響範囲）を動機に、オブジェクト指向の考え方を導入する
- カプセル化・継承・ポリモーフィズムの3原則を短いコードで紹介し、クラスの構成要素（フィールド、メソッド、getter/setter、コンストラクタ、オーバーロード）を教える
- 後半でアクセス修飾子public/private、static、オブジェクトの配列を扱う
- 章末以降にエラー集、equals/hashCode、Record・パターンマッチング・sealedクラスの紹介が付け足されている
- 前提は第2章（基本文法、staticメソッド、配列）とC言語の構造体の知識

## 構成上の問題

この章は、少なくとも2つの版が結合されたまま残っており、さらに章末の後ろに別の節が追加されている。

- 前半（L3–1344）は学習目標から始まり、「まとめ」（「このパートでは」で始まる）で一度終わる
- 後半（L1345–2469）は用語解説から始まり、手続き型との比較、クラス定義、アクセス修飾子、static、配列、章末演習、次章への橋渡しで終わる
- 章末の後ろ（L2470–2761）に、エラー集、等価性、モダンJavaの3節が続く。「次章への橋渡し」が章の途中にある
- 重複している内容
    + 手続き型とオブジェクト指向の比較: L55–160（C言語の学生管理・銀行口座）、L216–304（3-1、3-2）、L1393–1456（C言語のStudent構造体と3-24）の3回
    + カプセル化とprivateの必要性: 3-3（BankAccount）、getter/setter節（3-16）、「処理をお任せする」節（L1475–1484）、アクセス修飾子節（3-27〜3-29）
    + Bookクラス: 3-22（図書管理）と3-25・3-26（クラスとオブジェクト）で、ほぼ同じ題材をもう一度定義している
    + フィールドのデフォルト値: L551–592（3-7）とL679–689（表）で同じ小見出しが2回ある。配列の初期値（L2267–2284）でも再度触れる
    + 「フィールド（属性）の基礎」（L524）と「フィールド（インスタンス変数）の詳細」（L594）が並立している
    + クラス・オブジェクト・インスタンスの関係: L513以降とL1349–1378で2回説明する
- 統合するなら、前半の流れ（動機→3原則→クラスの構成要素→設計例）を骨格にし、後半の用語解説（L1349–1378）を前半の冒頭へ、アクセス修飾子・static・配列を「クラスの作成」の後に置き、重複する比較とBookクラスを1つにまとめるのが自然
- 末尾3節は、エラー集を章末演習の前に移し、equals/hashCodeとモダンJavaは第5章・第8章へ移すか削除するのが自然

### 予告と本文、章順との矛盾

- 学習目標で継承とポリモーフィズムを挙げるが、本文は3-4・3-5の短い例だけで、詳細は第5章・第7章に委ねている。予告の範囲を「概念の紹介」と明示すべき
- 3-4で`protected`と`extends`、3-5で`interface`と`implements`を説明なしに使う（第4章・第5章・第7章の内容）
- 3-23（ShoppingCart）は`List<Item>`と`ArrayList`を使う。コレクションとジェネリクスは第9章・第10章
- 3-33は`throw new IllegalArgumentException`を使う（第13章の内容）
- 3-47・3-48は`@Override`を使う（オーバーライドは第5章）
- `this`を多数のサンプルで使うが、本章では説明していない（第4章「コンストラクタとthisキーワード」で扱う）
- 「章の構成」（L37）は「プログラミングパラダイムの歴史的な発展を理解したうえで」と書くが、歴史は付録へ移されていて本文にない

## 他章との関係

- 第2章: staticメソッドと配列の基本を前提として参照している（L1917、L2136）
- 第4章（クラスとインスタンス）: getter/setter、コンストラクタ、メソッドオーバーロード（第4章「高度なメソッドオーバーロード設計」）、アクセス修飾子、BankAccountのカプセル化が重複している。本章で導入・第4章で深化という分担を明確にする必要がある
- 第5章（継承とポリモーフィズム）: 3-4の継承、3-49のinstanceof、3-47の`@Override`が先取りになっている
- 第7章（抽象クラスとインターフェイス）: 3-5のインターフェイスとL1486–1492の説明が先取り。static節は第7章で高度な活用を学ぶと予告する
