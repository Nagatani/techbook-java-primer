# 第4章 クラスとインスタンス 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter04-classes-and-instances.md` を参照する。

## 章の概要

- 第3章で学んだクラスの基本（public/private、getter/setter、コンストラクター、`this.name`）を前提に、カプセル化・4つのアクセス修飾子・パッケージ・コンストラクター設計を「実践的なクラス設計」として掘り下げる
- 銀行口座クラスをV0（全フィールドpublic）→V1（private化）→V2（検証追加）→V3（final・取引履歴・防御的コピー）と段階的に改善するのが章の背骨
- 後半はコンストラクターチェーン（`this(...)`）、`return this`、コールバックへのthis渡し、オーバーロードによるAPI設計、神クラス・過度なgetter/setter・防御的コピーの欠如という設計上の問題を扱う
- 2026-11-11に、第3章との分担（第3章で導入・本章で深化）を冒頭で明示し、継承を使うEnhancedBankAccountを削除し、防御的コピーとビルダーパターンの詳細を第6章へ委ねた
- 章のタイトルは「クラスとインスタンス」だが、インスタンス生成そのものより設計技法が中心で、内容は「中級のクラス設計」に近い

## 他章との関係

- 第3章: クラス作成、コンストラクター、`this.name`、オーバーロードの基本、public/privateを扱う。2026-11-11に、本章の冒頭（アクセス修飾子、getter/setter、コンストラクターのオーバーロード、this）で第3章を受ける形にし、第3章側から`this(...)`・protected・パッケージプライベートを本章へ誘導するようにした。第3章のまとめの予告（アクセス修飾子の詳細、BankAccountの段階的改善、検証、防御的プログラミング、パッケージ）は本章の内容と一致している
- 第5章: 継承を正式に扱う。4-4の`extends`は誘導付き（継承を本格的に使うEnhancedBankAccountは削除済み）
- 第6章: 不変性、final、防御的コピー、ビルダーパターンを体系的に扱う。本章は防御的コピー（4-13、4-34）とビルダー（4-25）から第6章へ誘導する（2026-11-11）
- 第9章: 本章で先行使用するList・Mapを正式に扱う（初出の箇所に誘導あり）
- 第13章: 例外処理。本章のIllegalArgumentExceptionの送出やNullPointerExceptionの扱いを体系化する（カプセル化の節に章参照あり）
- 付録H: Java共通エラーガイドのchapter04.mdをエラー集から参照している
