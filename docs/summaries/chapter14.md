# 第14章 ファイルI/O 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter14-file-io.md` を参照する。

## 章の概要

- バイトストリームと文字ストリームの区別から入り、テキスト（Scanner、BufferedReader/Writer、Files）、文字エンコーディング、バイナリ（DataInput/OutputStream）、直列化、NIO.2のファイル操作、CSV処理を順に扱う
- 後半はJFileChooser、Text Blocks、よくあるエラー7種の要点で構成される
- try-with-resourcesは第13章を参照し、本章ではファイル処理での注意点2つだけを書く（2026-11-11に重複を解消）
- 前提は第13章の例外処理とtry-with-resources、第12章までのコレクションとStream API
- Text Blocks節は2026-11-11に縮め（L632–923、約290行）、ファイルI/O本体（L50–631）より小さくなった

- Text Blocks節の肥大化（2026-11-11におおむね解消）

    + 用語集の「テキストブロック」は第14章を指すようになった（解消）
- 学習目標と完了確認チェックリストで予告しているのに、本文で扱っていない内容が残る（2026-11-12に解消。学習目標を本文に合わせ、チェックリストは削除した）
    + ディレクトリ操作とファイル検索（Files.walk、Files.find、DirectoryStreamなどの説明がない）
    + エンコーディング変換の実践、国際化対応プログラムの実装
    + 大容量ファイルのストリーミング処理（エラー一覧で1行ずつ処理すると触れるだけ）
    + JSON・XMLへの「対応」（Text Blocksで文字列を生成するだけで、読み込み・解析はない）
    + チェックリストの「ログファイルの解析」
- 「完了確認チェックリスト」（L28–49）が章の冒頭に残る。他章（第13章など）は2026-11-08に削除しており、本章だけ残っている。L48は本文の文脈にない演習ディレクトリ`advanced/`を前提にしている（2026-11-12に削除して解消）
- 章順との矛盾（案内で対処済み）

- 「日付時刻処理について」（L569–584）は付録Fへの誘導だけの節で、「本章ではファイル操作に最低限必要な日付時刻処理のみを扱い」と書きながら本章では扱っていない（2026-11-12に解消。本章では14-6と14-13で現在の日時を取得するだけである旨に書き直した）

## 節ごとの要約

- 本章の学習目標（L3–27）
    + 本文に合わせた項目（ストリームの使い分け、ファイルの読み書き、文字エンコーディング、NIO.2、直列化、CSVとText Blocks）。2026-11-12に本文と一致しない項目を外した
- ファイルI/Oの基礎とストリーム（L50–81）
    + ストリームの概念、バイトストリームと文字ストリーム、クラス階層図2点
    + try-with-resourcesでストリームを閉じる（2026-11-11に、第13章を参照する形に書き換え）。重ねたストリームは外側だけ宣言すればよいこと、`Files.newBufferedReader`の戻り値は閉じ、`Files.readAllLines`などは閉じなくてよいこと
- テキストファイルの読み書き（L82–308）
    + Scannerによる行単位・デリミター・型指定の読み込み（14-1）。キーボード入力は`IO.readln`を使う旨と、`data.txt`は全文と同じディレクトリにある旨
    + BufferedReaderの1行ずつ読み込みとreadAllLinesの使い分け（14-2）
    + BufferedWriterとStandardOpenOption、APPENDによる追記（14-3）と作成されたファイルの内容
    + UTF-8・Shift_JIS（Windows-31J/MS932との違いを含む）・ISO-8859-1と文字化けの例（14-4）
    + 「テキストファイルの読み込み」の小見出し（L84）が1文だけで、直後に別の小見出し（Scanner）が始まる（2026-11-12に解消。この後に紹介する3つの方法を案内する文にした）
- バイナリファイルの高度な処理（L309–382）
    + DataOutputStream/DataInputStreamでプリミティブ型と文字列を読み書き（14-5）。順序の一致、ビッグエンディアン、writeUTFの65535バイト制限を文章で注意
    + BufferedInputStream/BufferedOutputStreamの役割と、14-5でストリームを重ねる構造の図
- オブジェクトの直列化（シリアライズ）（L383–446）
    + Serializable、ObjectOutputStream/ObjectInputStream、transientによる除外（14-6）。直列化のセキュリティ上の注意はない
- ファイルシステムの操作 (NIO.2)（L447–505）
    + Path・Paths・Filesの説明リスト。ディレクトリ作成、writeString、copy、deleteの一連の操作（14-7）
- 実践的なファイル処理例（L506–568）
    + splitによる簡易CSV読み書き（14-8）。カンマや改行を含むデータはApache Commons CSVなどを使う
- 日付時刻処理について（L569–584）
    + java.time APIの推奨と付録Fへの誘導のみ。コードなし
- GUIでのファイル選択: `JFileChooser`（L585–631）
    + Swingは第17章から学ぶ旨の案内。ダイアログで選んだファイルのパスを表示する（14-9）
- Text Blocks - 複数行文字列の効率的な処理（L632–923）
    + 本章で扱う理由。従来の文字列連結の問題（文章で説明）
    + 基本構文と従来の文字列との比較（14-10）、共通インデントの自動除去（14-11）、エスケープシーケンスの簡略化（14-12）
    + JSONなどの構造化データを作ってファイルに保存（14-13、実行結果は抜粋。ファイル一覧は名前順に並べる）
    + ベストプラクティス（文章で説明）と付録B.13「NIO.2の高度な機能」への参照
- まとめ（L924–933）
    + 7項目。try-with-resourcesとText Blocksにも触れる
- よくあるエラーと対処法（L934–955）
    + ファイルパス、文字エンコーディング、ロックとアクセス権限、メモリの使いすぎ、OSによる違い、複数スレッドからの同時アクセス、一時ファイルの削除忘れの要点と、`appendix/h-common-errors/chapters/chapter14.md`のURL
