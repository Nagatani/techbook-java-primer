# 第14章 ファイルI/O 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter14-file-io.md` を参照する。

## 章の概要

- バイトストリームと文字ストリームの区別から入り、テキスト（Scanner、BufferedReader/Writer、Files）、文字エンコーディング、バイナリ（DataInput/OutputStream）、直列化、NIO.2のファイル操作、CSV処理を順に扱う
- 後半はJFileChooser、Text Blocks、よくあるエラー7種の要点で構成される
- try-with-resourcesは第13章を参照し、本章ではファイル処理での注意点2つだけを書く（2026-11-11に重複を解消）
- `Path`は`Path.of`で作る（2026-11-14に全サンプルを`Paths.get`から移し、`Paths`は古いコードで使われる旨を脚注付きで書いた）
- 前提は第13章の例外処理とtry-with-resources、第12章までのコレクションとStream API

## 構成上の問題

- Text Blocks節（L629–917）がファイルI/O本体と同程度の分量を持つ（2026-11-11に縮めた。ファイルに書き出すときに役立つため本章で扱う、という理由を節の冒頭に書いた）
- 章順との矛盾（案内で対処済み）
    + JFileChooser（L582–628）はSwingを使うが、GUIは第17章で初めて学ぶ。第17章から学ぶ旨と、組み込むときは`SwingUtilities.invokeLater`に従う旨を案内している
    + 同時アクセスは、エラー一覧でスレッドは第15章で学ぶと案内している
- 以前の問題（学習目標・チェックリストと本文の不一致、日付時刻処理の節の記述）は2026-11-12に解消した

## 節ごとの要約

- 本章の学習目標（L3–26）
    + 本文に合わせた項目（ストリームの使い分け、ファイルの読み書き、文字エンコーディングと文字化けのしくみ、NIO.2、直列化、CSVとText Blocks）
- ファイルI/Oの基礎とストリーム（L27–59）
    + ストリームの概念、バイトストリームと文字ストリーム（キャラクタストリーム）、クラス階層図2点
    + try-with-resourcesでストリームを閉じる（第13章を参照）。重ねたストリームは外側だけ宣言すればよいこと、`Files.newBufferedReader`の戻り値は閉じ、`Files.readAllLines`などは閉じなくてよいこと
- テキストファイルの読み書き（L60–299）
    + この後に紹介する3つの方法の案内
    + Scannerによる行単位・デリミター・型指定の読み込み（14-1）。キーボード入力は`IO.readln`を使う旨と、`data.txt`は全文と同じディレクトリにある旨
    + BufferedReaderの1行ずつ読み込みとreadAllLinesの使い分け（14-2）
    + BufferedWriterとStandardOpenOption、APPENDによる追記（14-3）と作成されたファイルの内容
    + UTF-8・Shift_JIS（Windows-31J、Javaでの名前は`windows-31j`、別名`MS932`）・ISO-8859-1。既定がUTF-8になったJEP 400の脚注
    + 14-4は「こんにちは」をUTF-8で書き、Shift_JISで読むと「縺薙ｓ縺ｫ縺｡縺ｯ」と文字化けする例（2026-11-14に、例外になる例から実際に化ける例へ作り直した）。文字化けのしくみと、解釈できないバイト列があると`MalformedInputException`になることを本文で説明する
- バイナリファイルの高度な処理（L300–373）
    + DataOutputStream/DataInputStreamでプリミティブ型と文字列を読み書き（14-5）。型の情報は保存しないので順序を一致させる、ビッグエンディアン、writeUTFの65535バイト制限を文章で注意
    + BufferedInputStream/BufferedOutputStreamの役割と、14-5でストリームを重ねる構造の図
- オブジェクトの直列化（シリアライズ）（L374–437）
    + Serializable、ObjectOutputStream/ObjectInputStream、transientによる除外（14-6）。非直列化の脆弱性と`ObjectInputFilter`、`serialVersionUID`を脚注で補う
- ファイルシステムの操作 (NIO.2)（L438–500）
    + Path（`Path.of`で作る）とFilesの説明リスト。`Paths.get`は古い書き方である旨と、`Paths`が将来非推奨になりうる旨の脚注
    + ディレクトリ作成、writeString、copy、deleteの一連の操作（14-7）。出力はファイル名だけを表示し、OSで区切り文字が変わらないようにした（2026-11-14）
    + 付録B.13「NIO.2の高度な機能」（WatchService、非同期のファイル入出力など）への誘導（2026-11-14にText Blocks節の末尾から移した）
- 実践的なファイル処理例（L501–563）
    + splitによる簡易CSV読み書き（14-8）。`split(",", -1)`で末尾の空の項目も残す。カンマや改行を含むデータはApache Commons CSVなどを使う
- 日付時刻処理について（L564–581）
    + java.time APIの推奨と付録Fへの誘導。本章では14-6と14-13で現在の日時を取得するだけである旨
- GUIでのファイル選択: `JFileChooser`（L582–628）
    + Swingは第17章から学ぶ旨の案内。ダイアログで選んだファイルのパスを表示する（14-9）
- Text Blocks - 複数行文字列の効率的な処理（L629–917）
    + 本章で扱う理由。従来の文字列連結の問題（文章で説明）
    + 基本構文と従来の文字列との比較（14-10）、共通インデントの自動除去（14-11）、エスケープシーケンスの簡略化（14-12）
    + 「実践例：構造化データの生成と保存」: JSONなどを作ってファイルに保存（14-13、実行結果は抜粋。ファイル一覧は名前順に並べる）
    + ベストプラクティス（文章で説明）
- まとめ（L918–927）
    + 7項目。try-with-resourcesとText Blocksにも触れる
- よくあるエラーと対処法（L928–949）
    + ファイルパス、文字エンコーディング（ファイルと異なる文字コードで読むと文字化けや`MalformedInputException`）、ロックとアクセス権限、メモリの使いすぎ、OSによる違い、複数スレッドからの同時アクセス、一時ファイルの削除忘れの要点と、`appendix/h-common-errors/chapters/chapter14.md`のURL
- 章末演習（L950–969）
    + リンクは`exercises/chapter14/`。基礎課題4つ・発展課題2つ・チャレンジ課題1つの課題名を書いた（2026-11-14）
