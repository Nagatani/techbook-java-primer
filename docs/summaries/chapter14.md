# 第14章 ファイルI/O 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter14-file-io.md` を参照する。

## 章の概要

- バイトストリームと文字ストリームの区別から入り、テキスト（Scanner、BufferedReader/Writer、Files）、バイナリ（DataInput/OutputStream）、直列化、NIO.2のファイル操作、CSV処理を順に扱う
- 後半はJFileChooser、Text Blocks（約790行）、よくあるエラー7種で構成される
- 前提は第13章の例外処理とtry-with-resources、第12章までのコレクションとStream API
- 章の分量の4割強をText Blocksが占め、ファイルI/O本体（L50–628）は比較的薄い
- 過去の版の結合による節の二重化は見当たらない

## 構成上の問題

- Text Blocks節（L687–1475）が章の中心より大きい
    + Text Blocksは言語機能（文字列リテラル）であり、ファイルI/Oの章に置く必然性が薄い
    + 用語集（glossary.md L180、L245）は「テキストブロック - 第2章」としているが、第2章には記述がない。第2章へ移すか、用語集を第14章に直す必要がある
    + 節の後半（14-15、14-16）はJSON・SQL・HTML・XML・Markdownのテンプレート生成が中心で、長大なサンプルが続く
- 学習目標で予告しているのに本文で扱っていない内容
    + ディレクトリ操作とファイル検索（Files.walk、Files.find、DirectoryStreamなどの説明がない。14-15で`Files.list`が使われるだけ）
    + エンコーディング変換の実践、国際化対応プログラムの実装
    + 大容量ファイルのストリーミング処理（エラー集の14-24で`Files.lines`が出るだけで本文の節がない）
    + JSON・XMLへの「対応」（Text Blocksで文字列を生成するだけで、読み込み・解析はない）
    + チェックリストの「ログファイルの解析」も本文で扱っていない
- 章順との矛盾
    + JFileChooser（L645–686）はSwingを使うが、GUIは第17章で初めて学ぶ。他章でJFileChooserを扱う箇所はない
    + 14-28は`synchronized`と`FileChannel`を使うが、synchronizedは第15章（マルチスレッド）の内容
- 「日付時刻処理について」（L629–644）は付録Fへの誘導だけの節で、「本章ではファイル操作に最低限必要な日付時刻処理のみを扱い」と書きながら本章では扱っていない

## 節ごとの要約

- 本章の学習目標（L3–27）
    + ストリームの使い分け、NIO.2、文字エンコーディング、大容量ファイル処理の4項目を掲げる。前述のとおり本文と一致しない項目が多い
- 完了確認チェックリスト（L28–49）
    + 基礎・技術要素・応用の3レベル。L48の「advanced/の発展課題」は本文の文脈にない演習ディレクトリを前提にしている
- ファイルI/Oの基礎とストリーム（L50–90）
    + ストリームの概念、バイトストリームと文字ストリーム、クラス階層図2点（figure14-01a/b）
    + try-with-resourcesの基本形（14-1）。第13章（13-3、13-10）の説明と重複する
- テキストファイルの読み書き（L91–347）
    + Scannerによる行単位・デリミター・型指定の読み込み（14-2）
    + BufferedReaderの1行ずつ読み込みとreadAllLinesの使い分け（14-3）
    + BufferedWriterとStandardOpenOption、APPENDによる追記（14-4）
    + UTF-8・Shift_JIS・ISO-8859-1の紹介と文字化けの例（14-5）
    + 「テキストファイルの読み込み」の小見出し（L91）が1文だけで、直後に別の小見出し（Scanner）が始まる
- バイナリファイルの高度な処理（L348–414）
    + DataOutputStream/DataInputStreamでプリミティブ型と修正UTF-8を読み書き（14-6）
    + 読み書きの順序一致、ビッグエンディアン、writeUTFの65535バイト制限の注意
    + BufferedInputStream/BufferedOutputStreamはコードなしの1段落のみ
- オブジェクトの直列化（シリアライズ）（L415–480）
    + Serializable、serialVersionUID、transientによる除外（14-7）。直列化のセキュリティ上の注意はない
- ファイルシステムの操作 (NIO.2)（L481–544）
    + ディレクトリ作成、writeString、copy、deleteの一連の操作（14-8）
    + Path・Paths・Filesの説明リストでクラス名が消えている（後述）
- 実践的なファイル処理例（L545–633）
    + splitによる簡易CSV読み書き（14-9）。引用符を含むデータはApache Commons CSVを使うよう案内する
- 日付時刻処理について（L634–649）
    + java.time APIの推奨と付録Fへの誘導のみ。コードなし
- GUIでのファイル選択: `JFileChooser`（L650–691）
    + showOpenDialog/showSaveDialogとAPPROVE_OPTION（14-10）
- Text Blocks - 複数行文字列の効率的な処理（L692–1480）
    + 従来の文字列連結の問題（14-11）、基本構文と従来文字列との同等性（14-12）
    + 共通インデントの自動除去とstripIndent（14-13）
    + 引用符・バックスラッシュ・三重引用符・行末制御`\`と`\s`（14-14）
    + JSON・SQL・HTML・XMLを生成してファイルに保存（14-15）
    + ログ設定・HTMLレポート・README.md・project.jsonなどの一括生成（14-16）
    + ベストプラクティス5項目と、付録B.13「NIO.2の高度な機能」への参照（L1473）
- まとめ（L1481–1489）
    + 6項目。Text Blocks（章の4割）とエラー集に触れていない
- よくあるエラーと対処法（L1490–1885）
    + ファイルパス（14-17、14-18）、エンコーディング（14-19、14-20）、ロックと権限（14-21、14-22）、メモリ効率（14-23、14-24）、クロスプラットフォーム（14-25、14-26）、並行アクセス（14-27、14-28）、一時ファイル（14-29、14-30）の7種
    + デバッグのヒント3点（14-31〜14-33）
    + まとめの後に置かれていて、章末の順序が他章（まとめが最後）と異なる
