# 第18章 基本的なイベント処理 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter18-event-basics.md` を参照する。

## 章の概要

- イベント処理とEDTを正式に説明する章（2026-11-11に、第17章の「イベント処理入門」と「EDT」節の内容をこの章に集めた）
- イベント駆動の考え方（イベントソース・イベントオブジェクト・イベントリスナーの3要素）と、イベントキューとEDTの働き、Swingがコンポーネントの操作をEDTに限る理由を説明する
- ActionListenerを匿名クラスとラムダ式で書き、挨拶プログラムとカウンターで入力・状態・表示をつなぐ
- WindowEvent、MouseEvent、KeyEvent、ItemEvent、FocusEvent、ChangeEventのリスナーを1つずつ示す
- 最後に、リスナーが動くスレッドの確認、invokeLaterとinvokeAndWaitの違い、長時間処理の回避、javax.swing.Timerを扱う
- 前提は第17章のコンポーネントとinvokeLaterの定型、第11章のラムダ式、第15章のスレッド

## 節ごとの要約

- 本章の学習目標（L3–28）
    + イベント駆動の基本概念（3要素、EDTの役割）、基本的なリスナーの実装、主要なイベントの種類、EDTを意識したイベント処理（スレッドの確認、長時間処理の回避、Timer）の4項目
- イベント駆動プログラミングの理解（L29–81）
    + 手続き型ではプログラムが流れを制御し、イベント駆動ではユーザー操作が流れを制御するという対比
    + 3要素とその働く順序を文章で説明し、イベント処理モデルの図（chapter18-event-model）を示す
    + EDT: 第17章の定型を受けて、イベントキューとFIFOの処理、再描画やinvokeLaterの依頼も同じキューに並ぶこと（図chapter18-edt）、Swingがスレッドセーフでないためにアクセスを1つのスレッドに限ること、長時間の処理でUIがフリーズすることを文章で説明する
- ボタンクリックの実装（L82–155）
    + ActionListenerを匿名クラスで実装し、`addActionListener`で登録する（18-1、invokeLaterでEDT上に組み立てる）
    + リスナーの登録（addXXXListener、複数登録）と匿名クラス（第8章）を文章で説明
- ラムダ式による簡潔な記述（L156–294）
    + 18-1をラムダ式で書き換える（18-2）。詳細は第11章へ誘導
    + テキストフィールドの名前を読んでラベルに挨拶を表示する挨拶プログラム（18-3）
    + カウント値をフィールドに持つカウンター（18-4、GUIの組み立てはコンストラクターに置き、invokeLaterで呼ぶ）
- 代表的なイベントの種類（L295–582）
    + 7種類のイベントと対応するリスナーの表
    + `WindowAdapter`と`DO_NOTHING_ON_CLOSE`による終了確認ダイアログ（18-5）
    + `MouseAdapter`によるクリック・出入りの検出（18-6）。移動・ドラッグ等は第19章の19-1へ誘導
    + `KeyAdapter`によるキー押下の表示、Ctrl+Sの検出と`consume()`（18-7）。同時押しとキーバインディングは19-2へ誘導
    + ItemListenerでチェックボックスとラジオボタンの選択状態を監視する（18-8）
    + FocusListenerでフォーカス時の背景色変更と、フォーカス喪失時の入力検証（18-9）
    + ChangeListenerでスライダーとスピナーを連動させ、`getValueIsAdjusting()`でドラッグ中を区別する（18-10）
- イベント処理のベストプラクティス（L583–726）
    + mainはmainスレッドで動き、リスナーはEDT上で呼ばれることを説明し、`isEventDispatchThread()`で確かめる（18-11）
    + `invokeLater`と`invokeAndWait`の違い（EDTから呼ぶとError、デッドロックの危険）
    + 長時間処理でUIが固まる悪い例と、`Thread`で別スレッドに任せ`invokeLater`で結果を反映するよい例（18-12）。SwingWorkerは第19章へ誘導
    + `javax.swing.Timer`による1秒ごとのデジタル時計（18-13）。java.util.Timerとの違い、処理を短く保つこと
- まとめ（L727–741）
    + 重要なポイント6項目と、第19章（DocumentListener、カスタムイベント、パフォーマンス）への導入
- 章末演習（L742–758）
    + 演習リンクは`exercises/chapter18/`。課題は描画、フォームバリデーター、メニュー、マウストラッカーの4つ
