# 第18章 基本的なイベント処理 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter18-event-basics.md` を参照する。

## 章の概要

- イベント駆動プログラミングの考え方（イベントソース・イベントオブジェクト・イベントリスナの3要素）とEDTを説明する
- ActionListenerを匿名クラスとラムダ式で書き、挨拶プログラムで入力と表示をつなぐ
- WindowEvent、MouseEvent、KeyEvent、ItemEvent、FocusEvent、ChangeEventのリスナを1つずつ完全なサンプルで示す
- 最後にEDT上でのGUI初期化と長時間処理の回避をベストプラクティスとしてまとめる
- 前提は第17章のコンポーネントと第11章のラムダ式。章内に版の結合による二重構造はない

## 構成上の問題

- 第17章との重複が大きい
    + 第17章「Part B: イベント処理入門」がイベント駆動の3要素、ボタンクリック、リスナの登録、テキストフィールドとの連携、ラムダ式、チェックボックスとラジオボタンの選択状態をすでに扱っている。本章のL26–196とItemListenerの節（18-7）はこれとほぼ同じ内容
    + 第17章「Part C」がEDTを詳しく扱っている。本章のEDTの説明（L52–61）とベストプラクティス（18-10）はその簡略版の繰り返し
    + L30の「前章で作成した画面は、まだ見た目だけの『静的』なものでした」は、第17章にイベント処理がある現状と矛盾する
    + 境界の整理案は、第17章からPart B（とPart Cの大半）を本章へ移すか、本章の冒頭を「第17章の復習」として短く圧縮するかのどちらか
- 第19章との境界
    + 第19章は「マウスイベントの完全な処理」「キーボードイベントの高度な処理」「SwingWorkerによる非同期処理」を扱う。本章の18-5、18-6、18-11は基本編として位置付けが明確なので重複は許容範囲だが、18-11の説明文がSwingWorkerを名乗っている点は第19章の内容と衝突する（下記）
- 本文とコードの不一致
    + L737はSwingWorkerを使った解決法を示すと述べるが、18-11のコードは`new Thread`と`invokeLater`を使っていて、SwingWorkerは登場しない
    + L264はMouseListenerとMouseMotionListenerを実装すると述べるが、18-5は`MouseAdapter`を`addMouseListener`で登録するだけで、移動（`mouseMoved`）の検出がない
    + ベストプラクティスで「すべてのGUI操作をEDT上で実行する」と教える（18-10）が、前半の18-1、18-3、18-4は`main`から直接GUIを組み立てていて`invokeLater`を使っていない

## 節ごとの要約

- 本章の学習目標（L3–25）
    + イベント駆動の基本概念、基本的なリスナの実装、主要なイベントの種類の3項目
    + 前提は第17章のコンポーネントの使い方と、ラムダ式・関数型インターフェイスの基本知識（第11章で既習なので章順と矛盾しない）
- イベント駆動プログラミングの理解（L26–61）
    + 手続き型ではプログラムが流れを制御し、イベント駆動ではユーザー操作が流れを制御するという対比
    + イベントソース・イベントオブジェクト・イベントリスナの3要素と処理の流れ
    + EDTの特徴4項目（単一スレッド、GUI更新はEDT上でのみ安全、長時間処理でフリーズ、FIFOのイベントキュー）
- ボタンクリックの実装（L62–121）
    + ActionListenerを匿名クラスで実装し、`addActionListener`で登録してダイアログを表示する（18-1）
    + 匿名クラスの簡単な説明
- ラムダ式による簡潔な記述（L122–198）
    + 18-1をラムダ式で書き換える（18-2）
    + テキストフィールドの名前を読んでラベルに挨拶を表示する挨拶プログラム（18-3）
- 代表的なイベントの種類（L199–714）
    + 7種類のイベントと対応するリスナの表
    + `WindowAdapter`と`DO_NOTHING_ON_CLOSE`による終了確認ダイアログ（18-4、L213–259）
    + `MouseAdapter`によるクリック・出入りの検出（18-5、L260–342）
    + `KeyAdapter`によるキー押下の表示、Ctrl+Sの検出と`consume()`（18-6、L343–404）
    + ItemListenerでチェックボックスとラジオボタンの選択状態を監視する（18-7、L405–512）
    + FocusListenerでフォーカス時の背景色変更と、フォーカス喪失時の入力検証（18-8、L513–608）
    + ChangeListenerでスライダーとスピナーを連動させ、`getValueIsAdjusting()`でドラッグ中を区別する（18-9、L609–710）
- イベント処理のベストプラクティス（L715–770）
    + `SwingUtilities.invokeLater`によるEDT上での初期化（18-10）
    + イベントハンドラ内の`Thread.sleep`でUIが固まる悪い例と、別スレッドで処理して`invokeLater`で結果を反映する良い例（18-11）
- まとめ（L771–783）
    + 重要なポイント4項目と、第19章（DocumentListener、カスタムイベント、パフォーマンス）への導入
- 章末演習（L784–800）
    + 演習リンクは`exercises/chapter18/`で現行番号と一致している
    + 基礎・応用・発展の3レベル構成

## 他章との関係

- 第11章（ラムダ式）: 匿名クラスからラムダ式への書き換えは第11章でも扱っている。本章ではGUIへの適用として短く示すにとどまる
- 第15章（マルチスレッド）: 18-11の別スレッド実行は第15章の知識を前提にしている
- 第17章（GUIの基礎）: イベント処理の入門とEDTを大きく重複して扱っている（構成上の問題を参照）
- 第19章（高度なイベント処理）: マウス・キーボードの詳細、DocumentListener、カスタムイベント、SwingWorkerを引き継ぐ。まとめの予告内容は第19章の構成と一致している
