# 第18章 基本的なイベント処理 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter18-event-basics.md` を参照する。

## 章の概要

- イベント処理とEDTを正式に説明する章（2026-11-11に、第17章の「イベント処理入門」と「EDT」節の内容をこの章に集めた）
- イベント駆動の考え方（イベントソース・イベントオブジェクト・イベントリスナーの3要素）と、イベントキューとEDTの働き、Swingがコンポーネントの操作をEDTに限る理由を説明する
- ActionListenerを匿名クラスとラムダ式で書き、挨拶プログラムとカウンターで入力・状態・表示をつなぐ
- WindowEvent、MouseEvent、KeyEvent、ItemEvent、FocusEvent、ChangeEventのリスナーを1つずつ示す
- 最後に、リスナーが動くスレッドの確認、invokeLaterとinvokeAndWaitの違い、長時間処理の回避、javax.swing.Timerを扱う
- 前提は第17章のコンポーネントとinvokeLaterの定型、第11章のラムダ式、第15章のスレッド

## 節ごとの要約

- 本章の学習目標（L3–28）
    + イベント駆動の基本概念（3要素、EDTの役割）、基本的なリスナーの実装、主要なイベントの種類、EDTを意識したイベント処理（スレッドの確認、長時間処理の回避、Timer）の4項目
- イベント駆動プログラミングの理解（L29–81）
    + 手続き型ではプログラムが流れを制御し、イベント駆動ではユーザー操作が流れを制御するという対比
    + 3要素とその働く順序を文章で説明し（イベントリスナーは、イベントソースに登録しておき、通知を受けて処理を実行するオブジェクト）、イベント処理モデルの図（chapter18-event-model）を示す
    + EDT: 第17章の定型を受けて、イベントキューとFIFOの処理、再描画やinvokeLaterの依頼も同じキューに並ぶこと（図chapter18-edt）、Swingがスレッドセーフでないためにアクセスを1つのスレッドに限ること、長時間の処理でUIがフリーズすることを文章で説明する
- ボタンクリックの実装（L82–156）
    + ActionListenerを匿名クラスで実装し、`addActionListener`で登録する（18-1、invokeLaterでEDT上に組み立てる）
    + リスナーの登録（addXXXListener、複数登録）と匿名クラス（第8章）を文章で説明
- ラムダ式による簡潔な記述（L157–308）
    + 18-1をラムダ式で書き換える（18-2）。詳細は第11章へ誘導
    + テキストフィールドの名前を読んでラベルに挨拶を表示する挨拶プログラム（18-3）
    + カウント値をフィールドに持つカウンター（18-4、GUIの組み立てはコンストラクターに置き、invokeLaterで呼ぶ）。実行結果は地の文で説明する
- 代表的なイベントの種類（L309–614）
    + 7種類のイベントと対応するリスナーの表
    + `WindowAdapter`と`DO_NOTHING_ON_CLOSE`による終了確認ダイアログ（18-5）。実行結果のボタン名は日本語環境の表示（はい・いいえ・取消）に合わせる
    + `MouseAdapter`によるクリック・出入りの検出（18-6）。移動・ドラッグ等は第19章の19-1へ誘導
    + `KeyAdapter`によるキー押下の表示、Ctrl+Sの検出と`consume()`（18-7）。`consume()`は、イベントを処理済みにして後続のキーバインディングなどへ渡さないものと説明する。同時押しとキーバインディングは19-2へ誘導
    + ItemListenerでチェックボックスとラジオボタンの選択状態を監視する（18-8）。直前の変化はラベルに、選択中の一覧はコンソールに出す
    + FocusListenerでフォーカス時の背景色変更と、フォーカス喪失時の入力検証（18-9、名前が空のままフォーカスを失うと背景をピンクにしてメッセージを出す）
    + ChangeListenerでスライダーとスピナーを双方向に連動させる（18-10）。`getValueIsAdjusting()`で、表示はそのつど更新し、確定した値の処理はドラッグ終了時に1回だけ行う。コードの後で、スピナーで変えたときも最終値が出ることと、値が変わらないとイベントが出ないので互いを呼び続けないことを説明する
- イベント処理のベストプラクティス（L615–777）
    + mainはmainスレッドで動き、リスナーはEDT上で呼ばれることを説明し、`isEventDispatchThread()`で確かめる（18-11、`EdtCheckExample`）
    + `invokeLater`と`invokeAndWait`の違い（EDTから呼ぶとError、デッドロックの危険）
    + 長時間処理でUIが固まる悪い例（ほかのボタンが反応せず、中身も描き直されない。枠を動かせるかはOSによると脚注で断る）と、`Thread`で別スレッドに任せ`invokeLater`で結果を反映するよい例（18-12）。SwingWorkerは第19章へ誘導
    + `javax.swing.Timer`による1秒ごとのデジタル時計（18-13）。`setInitialDelay(0)`で開始直後に1回目を実行する。java.util.Timerとの違い、処理を短く保つこと
- よくあるエラーと対処法（L778–796）
    + 本文に挙げるエラー: ラムダ式から外側のローカル変数を変更する、`Timer`のあいまいな参照（`java.util`と`javax.swing`の`*`のimport）、リスナーの登録忘れ、EDTでの長い処理による画面の固まり、`HeadlessException`。詳細は`appendix/e-common-errors/chapters/chapter18.md`
- まとめ（L797–813）
    + 重要なポイント6項目（最初は「イベント処理の3要素」）と、第19章への導入（マウス・キーボードの詳細、DocumentListener、カスタムイベント、SwingWorkerを扱い、ドラッグ&ドロップとイベントの間引きは要点を紹介する）
- 章末演習（L814–832）
    + 演習リンクは`exercises/chapter18/`。基礎課題は入室カウンター・ピザの注文・色の調合・会員登録フォーム（2026-11-13に、第19章の内容を求めていた描画・フォームバリデーター・メニュー・マウストラッカーから作り直した）、発展課題はストップウォッチと単位換算、チャレンジ課題は制限時間つきクイズ
