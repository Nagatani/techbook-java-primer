# 第15章 マルチスレッドプログラミング 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter15-multithreading.md` を参照する。

## 章の概要

- 逐次処理の限界を朝食の準備（コーヒー・トースト・卵）で示し、Thread/Runnableによるスレッド生成、synchronized、volatile、Atomicクラス、ExecutorService、Future/Callable、CompletableFutureを教える
- 後半はベンチマーク（parallelSort・並列ストリーム・ForkJoinPool）、スレッドセーフなシングルトン、並行処理の落とし穴、パイプライン・リトライ・サーキットブレーカーを、長い完成コードで示す
- 前提は第11章のラムダ式（15-2から説明なしで使う）、第9章のコレクション、第13章の例外処理
- 本文は「です・ます」だが、自動変換の跡（「。」で終わる導入句など）が残る。項目名と説明の連結と「CompleテーブルFuture」は2026-11-08に修正した
