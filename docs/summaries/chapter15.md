# 第15章 マルチスレッドプログラミング 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter15-multithreading.md` を参照する。

## 章の概要

- 逐次処理の限界を朝食の準備（コーヒー・トースト・卵）で示し、Thread/Runnableによるスレッド生成、synchronized、volatile、Atomicクラス、ExecutorService、Future/Callable、CompletableFutureを教える
- 後半はベンチマーク（parallelSort・並列ストリーム・ForkJoinPool）、スレッドセーフなシングルトン、並行処理の落とし穴、パイプライン・リトライ・サーキットブレーカーを、長い完成コードで示す
- 前提は第11章のラムダ式（15-2から説明なしで使う）、第9章のコレクション、第13章の例外処理
- 本文は「です・ます」だが、自動変換の跡（コロン削除による項目名と説明の連結、「。」で終わる導入句、「CompleテーブルFuture」）が多い

- 結合の痕跡

    + 「次のパート：[Part D …](chapter16d-practical-concurrency.md)」（L1563）、「次のパート：[Part E …]」（L2188）と、`<!-- Merged from … -->` コメント（L1565、L2190）が残っている
    + L1557に空の見出し「##」があり、その下に「Exchangerスレッド間のデータ交換」「低レベル同期wait/notifyメカニズム」というリストの断片だけが残る。Part C（並行コレクションと同期プリミティブ）の本文はほぼ失われ、その末尾の要約だけが残ったと推測される
- 演習が本文より前にある
    + Part Eに相当する「基礎レベル課題」「実装のヒント」「実装環境」「完了確認チェックリスト」（L236–877）が、本文「マルチスレッドプログラミングの基礎」（L878〜）より前に置かれている

    + 課題の「技術的背景」に、本文にない解説（Coffman条件、ReadWriteLock、BlockingQueueの種類、wait/notifyのifとwhile、Little's Law）が入り込んでいる
- 章内の二重説明
    + マルチスレッドの必要性: 「並行処理の世界への招待」L34–47と「マルチスレッドプログラミングの基礎」L885–891

    + LockインターフェイスとReentrantLock、ReadWriteLock、Semaphore、CountDownLatch、CopyOnWriteArrayList、ライブロック対策は、課題の仕様や箇条書きに名前が出るだけで、本文での解説やサンプルがない（失われたPart Cの内容と考えられる）
