# 第15章 マルチスレッドプログラミング 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter15-multithreading.md` を参照する。

## 章の概要

- 逐次処理の限界をレストランの厨房と朝食の準備（コーヒー・トースト・卵）で示し、Thread/Runnableによるスレッド生成、synchronized、volatile、Atomicクラス、ExecutorService、BlockingQueue、Future/Callable、CompletableFutureを教える
- 後半は、parallelSortとForkJoinPoolのベンチマーク、スレッドセーフなシングルトン、並列パイプラインとリトライ・サーキットブレーカーを、長い完成コードで示す
- 並列ストリームは第12章、並行処理の落とし穴の詳細は付録Hへ寄せた（2026-11-11）
- 前提は「第13章まで」（L26）。ラムダ式（第11章）は15-2から使う

## 節ごとの要約

### 導入（旧目次ファイル部分）

- 本章の学習目標（L3–31）
    + スレッドの基本、同期制御（synchronized・ReentrantLock・Atomic）、ExecutorServiceとCompletableFuture、並行コレクションの4分野を予告する

- 並行処理の世界への招待（L32–178）

    + 朝食の準備をシングルスレッドで約10秒（15-1）、3スレッドとjoinで約5秒（15-2）にする。出力の順序が実行ごとに変わる旨
