# 第15章 マルチスレッドプログラミング 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter15-multithreading.md` を参照する。

## 章の概要

- 逐次処理の限界をレストランの厨房と朝食の準備（コーヒー・トースト・卵）で示し、Thread/Runnableによるスレッド生成、synchronized、デッドロック（Coffman条件）、volatile、Atomicクラス、並行コレクション、ExecutorServiceとスレッドプールの設計、BlockingQueue、wait/notify、Semaphore、Future/Callable、CompletableFutureを教える
- 後半は、parallelSortとForkJoinPoolの時間の比較、スレッドセーフなシングルトン、並列パイプラインとリトライ・サーキットブレーカーを、要点の抜粋と解説で示す
- 並列ストリームは第12章、並行処理の落とし穴の詳細は付録Hへ寄せた（2026-11-11）
- 前提は「第13章まで」。ラムダ式（第11章）は15-2から使う

## 構成上の問題

この章は、旧第16章の目次ファイルと分冊（Part A〜E）を機械的に結合したもの。結合の痕跡、本文より前にあった演習、章内の二重説明、学習目標と本文の不一致、解説のないコードだけの節は、2026-11-08〜12に解消した。

- 残っている問題
    + LockとReentrantLock、CopyOnWriteArrayList、ライブロック対策は本文で扱っていない（学習目標からは外してある）
    + 15-20のリトライは、待つあいだ（`sleep`と`join`）共通プールのスレッドを占有する簡略化した実装。本文に注記を置いた（2026-11-14）。`exceptionallyCompose`などで非ブロッキングにするかは著者の判断

## 節ごとの要約

- 本章の学習目標（L3–33）
    + マルチスレッドの基本、同期制御、ExecutorServiceとスレッドプール、並行コレクションとスレッド間の協調、実践的な並行処理の5分野を予告する。前提は「第13章まで」
- 並行処理の世界への招待（L34–182）
    + Webブラウザーのたとえ。レストランの厨房で、シェフ1人と3人の時間を図（chapter15-chef-timeline）で比べ、1人ならAが25分・Bが50分、3人ならAが15分・Bが30分でそろうと本文に書く（2026-11-14）
    + 朝食の準備をシングルスレッドで約10秒（15-1）、3スレッドとjoinで約5秒（15-2）にする。15-2は2026-11-14に全文（`sample-code/chapter15/15-02/`）を置き、実行結果は順序が実行ごとに変わるので「一例」にした
- マルチスレッドプログラミングの基礎（L183–992）
    + スレッドの定義。マルチスレッドが役立つ場面（マルチコア、GUI、サーバー）。GUIでのスレッドは第18章・第19章へ誘導する
    + スレッドの状態遷移の説明と図。Runnableの実装とラムダ式（15-3）、Threadの継承を本書で使わない理由、start()とrun()の違い
    + ATMの二重引き出しによる競合状態と図、count++の非原子性（15-4）、synchronizedメソッド（15-5）と図、デッドロックの図とCoffman条件・ロック順序による防止、synchronizedブロック（15-6）、同期化が性能に与える影響
    + volatileによるフラグ停止（15-7）と複合操作には使えない注意、Atomicクラス（15-8。2026-11-14にExecutorServiceを使わずThreadの配列とjoinで書き直した）、Atomicとsynchronizedの速さの比較
    + HashMapとConcurrentHashMap（15-9）、バケットごとの排他制御とアトミックな複合操作
    + スレッドの無制限生成の問題（15-10）。スタックは最大で約10GBを予約、仮想スレッドの脚注
    + ExecutorServiceとスレッドプールの利点と図、種類、固定スレッドプールとシャットダウン（15-11）、リトルの法則によるスレッド数の見積もり、キューの大きさと拒否ポリシー
    + BlockingQueueによるプロデューサー・コンシューマー（15-12）と実装クラス、容量に上限を設ける理由
    + wait()とnotify()、ifとwhileの違い（15-13）と偽の起床、Semaphoreによる同時実行数の制限
    + Future/Callable（15-14）、CompletableFutureの連鎖・例外処理・allOf・orTimeout（15-15）、thenComposeなどによる非同期処理の合成（15-16）。thenApplyとthenApplyAsyncは「どのスレッドで実行するか」で書き分けた（2026-11-14）
- 実践的なパフォーマンス測定とベンチマーク（L993–1066）
    + 時間を測って確かめる必要性、RecursiveTaskの`compute`・`fork`・`join`の説明、並列ストリームは第12章を参照
    + Arrays.sortとparallelSort、ForkJoinPoolによる合計（15-17）
- スレッドセーフなシングルトンパターン（L1067–1139）
    + 第8章のenumによる書き方を受け、確認と作成が2段階に分かれる問題を説明する。synchronizedメソッドの方式は欠点（毎回ロックを取る）を述べてコードは全文に回す
    + ダブルチェックロッキングとvolatile、Holderクラス、enumの3方式（15-18）と解説
- 実践的な並行処理パターン（L1140–1297）
    + ステージごとに`thenApplyAsync`でつなぐ並列パイプライン（15-19）と解説
    + 固定の待ち時間で最大`maxRetries`回やり直すリトライ（指数バックオフは「にすれば」と紹介するだけ）と、Atomicクラスで状態を持つサーキットブレーカー（15-20）。リトライが待つあいだスレッドを占有する旨の注記。サーキットブレーカーは成功すると連続した失敗の回数を0に戻し、HALF_OPENの1回の試行が成功すればCLOSEDに戻る（2026-11-14に不具合を修正）。HALF_OPENで複数のスレッドが試しうる点と`compareAndSet`による対策
- よくあるエラーと対処法（L1298–1313）
    + 競合状態、デッドロック、スレッドセーフでないコレクションの使用、ExecutorServiceのシャットダウン忘れの要点と、`appendix/h-common-errors/chapters/chapter15.md`のURL
- 本章のまとめ（L1314–1341）
    + スレッドの基本、同期制御、Executorフレームワーク、並行コレクションとスレッド間の協調、実践的な並行処理の5項目
- 章末演習（L1342–1366）
    + リンクは`exercises/chapter15/`。基礎課題（Threadを継承する書き方とRunnableの比較、データ競合と同期、スレッドプールと非同期の処理、生産者と消費者）・発展課題・チャレンジ課題の一覧。第16章への案内と、付録B.14「Javaメモリモデル」の参照
