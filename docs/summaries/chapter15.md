# 第15章 マルチスレッドプログラミング 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter15-multithreading.md` を参照する。

## 章の概要

- 逐次処理の限界をレストランの厨房と朝食の準備（コーヒー・トースト・卵）で示し、Thread/Runnableによるスレッド生成、synchronized、デッドロック（Coffman条件）、volatile、Atomicクラス、並行コレクション、ExecutorServiceとスレッドプールの設計、BlockingQueue、wait/notify、Semaphore、Future/Callable、CompletableFutureを教える
- 最後の節「並列化の効果を確かめる」で、時間を測って確かめる考え方とFork/Joinのしくみを文章で示す。Fork/JoinとparallelSortの比較、スレッドセーフなシングルトン、並列パイプライン、リトライとサーキットブレーカーのコードは付録H（2026-11-16に移した）
- 並列ストリームは第12章、並行処理の落とし穴の詳細は付録E（`appendix/e-common-errors/`）へ寄せた（2026-11-11）
- 前提は「第13章まで」。ラムダ式（第11章）は15-2から使う

この章は、旧第16章の目次ファイルと分冊（Part A〜E）を機械的に結合したもの。結合の痕跡、本文より前にあった演習、章内の二重説明、学習目標と本文の不一致、解説のないコードだけの節は、2026-11-08〜12に解消した。

    + 旧15-20のリトライが待つあいだ共通プールのスレッドを占有する簡略化した実装である点は、2026-11-16にコードを付録Hへ移したため本文の問題ではなくなった

## 節ごとの要約

- 本章の学習目標（L3–31）
    + マルチスレッドの基本、同期制御、ExecutorServiceとスレッドプール、並行コレクションとスレッド間の協調、並列化の効果の確かめ方（コード例は付録H）の5分野を予告する。前提は「第13章まで」
- 並行処理の世界への招待（L32–181）
    + Webブラウザーのたとえ。レストランの厨房で、シェフ1人と3人の時間を図（chapter15-chef-timeline）で比べ、1人ならAが25分・Bが50分、3人ならAが15分・Bが30分でそろうと本文に書く（2026-11-14）
    + 朝食の準備をシングルスレッドで約10秒（15-1）、3スレッドとjoinで約5秒（15-2）にする。「〜しています」の順序は実行ごとに変わり、「〜ができました」は処理時間の短い順（トースト・コーヒー・卵）になる旨を書く。15-2は2026-11-14に全文（`sample-code/chapter15/15-02/`）を置き、実行結果は順序が実行ごとに変わるので「一例」にした
- マルチスレッドプログラミングの基礎
    + スレッドの定義。マルチスレッドが役立つ場面（マルチコア、GUI、サーバー）。GUIでのスレッドは第18章・第19章へ誘導する
    + スレッドの状態遷移の説明と図。Runnableの実装とラムダ式（15-3）、Threadの継承を本書で使わない理由、start()とrun()の違い
- 共有リソースと同期制御（2026-11-23に「基礎」のh3からh2にした）
    + 冒頭で競合状態と、スレッドセーフ（複数のスレッドから同時に使っても正しく動くこと）を定義する（2026-11-23。第12章の誘導先）
    + ATMの二重引き出しによる競合状態と図、count++の非原子性（15-4）、synchronizedメソッド（15-5）と図、デッドロックの図とCoffman条件・ロック順序による防止、synchronizedのロックはオブジェクトごとで、別々のオブジェクトなら同時に実行できる旨（2026-11-19）、synchronizedブロック（15-6。残高を`double`で持つのは説明のためで、お金は第6章の`BigDecimal`で扱う旨）、同期化が性能に与える影響。15-5の`getCount`もsynchronizedにする理由は、ほかのスレッドが書いた最新の値を読むため
    + volatileによるフラグ停止（15-7）と複合操作には使えない注意、Atomicクラス（15-8。2026-11-14にExecutorServiceを使わずThreadの配列とjoinで書き直した）、Atomicとsynchronizedの比較（ロックを待って止まらないこと。速さは条件で変わるので測る。2026-11-19に実測と合わない記述を直した）。性能・設計の一般論と、意図して簡略化した説明（スレッドの状態の戻り方、count++の3操作、Coffman条件、上限のないキューなど）には、正確な事実や一般論である旨の脚注を付けた（2026-11-19）
    + HashMapとConcurrentHashMap（15-9）、バケットごとの排他制御とアトミックな複合操作
    + 小節「スレッドセーフにする方法の整理」（2026-11-23に追加）: 共有しない・不変にする（第6章）・排他制御・アトミック操作・並行コレクションの5つを、考えることの少ない順に並べる
- Executorフレームワークと非同期処理（2026-11-23に「基礎」のh3からh2にし、Future・CompletableFutureを「実践的なマルチスレッドの例」から移した）
    + スレッドの無制限生成の問題（15-10）。スタックの既定はx64で1MB・AArch64で2MBで、1MBでも1万スレッドで約10GBを予約（2026-11-19）、仮想スレッドの脚注（`Thread.ofVirtual()`と`Executors.newVirtualThreadPerTaskExecutor()`）
    + ExecutorServiceとスレッドプールの利点と図、種類、固定スレッドプールとシャットダウン（15-11）。shutdownNowの後に、割り込み（interrupt）の意味と、catchでinterrupt()を呼び直す理由、15-7のvolatileフラグとの関係を説明する（2026-11-23）、リトルの法則によるスレッド数の見積もり、キューの大きさと拒否ポリシー（`AbortPolicy`は`RejectedExecutionException`をスローする）
    + Future/Callable（15-12。第11章・第13章で使ったCallableと受ける）
    + CompletableFuture（2026-11-23に「高度な非同期処理」と「連鎖と合成」の2つの小節を1つにまとめた）: supplyAsyncの説明（共通プール）、主なメソッドの一覧を1回だけ置き、15-13（全文のmain全体を載せ、1〜4の流れを先に説明）と15-14（thenComposeによる連鎖。前の処理が終わっていればthenApplyを呼んだスレッドで変換する旨の脚注）
- スレッド間の協調（2026-11-23に「実践的なマルチスレッドの例」から改めた）
    + BlockingQueueによるプロデューサー・コンシューマー（15-15）と実装クラス、容量に上限を設ける理由
    + wait()とnotify()、ifとwhileの違い（15-16）と偽の起床
    + Semaphoreによる同時実行数の制限（プロデューサー・コンシューマーの下のh5から、並ぶh3に出した）
- 並列化の効果を確かめる（L1009–1020）
    + 分けても速くならないことがある理由と、`System.nanoTime()`で時間を測って確かめる考え方（比べ方は第12章を参照）
    + Fork/Joinフレームワーク（`ForkJoinPool`・`RecursiveTask`、`fork`と`join`）のしくみを文章で説明し、並列ストリームと`Arrays.parallelSort`も内部で使う旨
    + Fork/Joinの合計と並列ソートの比較、スレッドセーフなシングルトン、パイプライン、リトライとサーキットブレーカーのコード例は付録Hへ案内する
- 新しい並行処理のしくみ
    + 仮想スレッド（Java 21で正式。待ち時間の長いタスクを大量に扱える、`newVirtualThreadPerTaskExecutor`、計算の重いタスクは速くならない）、構造化並行性（`StructuredTaskScope`、Java 25ではプレビュー）、スコープ値（`ScopedValue`、Java 25で正式、`ThreadLocal`との違い）をコードなしで紹介する（2026-11-23、Issue #032）
- よくあるエラーと対処法（L1021–1036）
    + 競合状態、デッドロック、スレッドセーフでないコレクションの使用、ExecutorServiceのシャットダウン忘れの要点と、`appendix/e-common-errors/chapters/chapter15.md`のURL
- まとめ（L1037–1062）
    + スレッドの基本、同期制御、Executorフレームワーク、並行コレクションとスレッド間の協調、並列化の効果（時間を測って確かめる。コード例は付録H）の5項目
- 章末演習（L1063–1087）
    + リンクは`exercises/chapter15/`。基礎課題（Threadを継承する書き方とRunnableの比較、データ競合と同期、スレッドプールと非同期の処理、生産者と消費者）・発展課題・チャレンジ課題の一覧。第16章への案内と、付録B.14「Javaメモリモデル」の参照
