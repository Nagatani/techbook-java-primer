# 第23章 ビルドとデプロイ 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter23-build-and-deploy.md` を参照する。

## 章の概要

- 開発したJavaアプリケーションを、開発環境を持たない人に配布する方法を扱う最終章
- 内容は2本立てで、`javac`→マニフェスト→`jar cvfm`→`java -jar`による実行可能JARの作成と、`jpackage`によるランタイム同梱のネイティブアプリ化
- Maven/Gradle、Fat JAR、GraalVM、コンテナ、CI/CDはまとめで名前を挙げるだけで、詳細は付録G（GitHubリポジトリ）に委ねる
- 456行と短く、コードはほぼコマンド例。サンプルアプリはSwing（第17章以降の内容）

## 節ごとの要約

- 本章の学習目標（L3–32）
    + JARの仕組み、マニフェスト、実行可能JAR、jpackage、ビルドとパッケージングの流れの5項目
    + 2026-11-08に、別のH2だった「この章で学ぶこと」と「はじめに」を学習目標の下の小見出しにまとめ、学習目標を散文で言い直した部分を削除した
    + 前提知識は第1章、第14章（基本的なI/O操作）、第22章（Mavenによる依存関係管理）、推奨知識は第21章、CI/CD、OS差異
- なぜビルドと配布が必要か（L33–44）
    + ソースコードをそのまま渡せないこと、「ビルド」「パッケージング」「配布」の用語定義。H3「ビルドプロセスの技術的意味」は1段落のみで、後ろに空行が続く
- 実行可能JARファイルの作成（L45–258）
    + JARはZIP形式のアーカイブで、Main-Classを加えると`java -jar`で実行できる
    + Swingの最小アプリ（23-1）、TodoApp（23-2）と複数クラスのJAR作成（23-3）
    + `javac`（23-4）、マニフェストのMain-Classと末尾改行の注意（23-5）
    + `getResource`で画像を読むResourceApp（23-6）とリソース込みのJAR作成（23-7）
    + `jar cvfm`のオプション解説（23-8）、`java -jar`での実行（23-9）
    + IntelliJ IDEAのArtifacts機能でのJAR作成手順
- jpackageによるネイティブアプリケーション化（L259–349）
    + JARはJREが必要という限界と、ランタイムを同梱するjpackageの利点
    + 入力ディレクトリと出力ディレクトリを分ける準備とディレクトリ図
    + app-imageの作成とオプション解説（23-10）
    + Windows（exe、23-11）、macOS（dmg、23-12）、Linux（deb、23-13）向けの例
- まとめ（L350–383）
    + 発展技術としてビルド自動化ツール、Fat JAR、GraalVMネイティブイメージ、コンテナ化、CI/CDを列挙し、付録Gへ誘導する
- 章末演習（L384–399）

## 他章との関係

- 第1章: javac/javaコマンドとIntelliJ IDEAの導入。本章のIntelliJ手順はその延長

- 第22章: Maven/Gradleと外部ライブラリ・クラスパスを扱う。本章まとめの「ビルド自動化ツール」項目と重なり、Fat JARなど依存ライブラリ込みの配布はどちらの章でも本文では扱われない空白地帯になっている
