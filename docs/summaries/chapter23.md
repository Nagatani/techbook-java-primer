# 第23章 ビルドとデプロイ 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter23-build-and-deploy.md` を参照する。

## 章の概要

- 開発したJavaアプリケーションを、開発環境を持たない人に配布する方法を扱う最終章
- 内容は2本立てで、`javac`→マニフェスト→`jar cvfm`→`java -jar`による実行可能JARの作成と、`jpackage`によるランタイム同梱のネイティブアプリ化
- Maven、Fat JAR、GraalVM、コンテナー、CI/CDはまとめで名前を挙げるだけで、詳細は付録G（GitHubリポジトリ）に委ねる
- 399行と短く、コードはほぼコマンド例。サンプルアプリはSwing（第17章の内容）

## 構成上の問題

- 実行可能JARの手順の分断は、ステップ1〜5を先に通し、複数クラスの例とリソースの例をステップ5の後ろへ移して解消した（2026-11-11に解消）
- 前提知識の不一致（第14章にクラスパスの説明がない、第22章のGradleを前提にする、Swingの章が前提にない）は、前提を第17章（Swing）と第22章（クラスパスとJAR）に改めて解消した（2026-11-11に解消）
- 学習目標の「外部ライブラリを含む複雑なアプリケーション」の予告は、学習目標を書き直して解消した
- 「複数のクラスファイルを含むアプリケーションの例」のTodoApp（23-6）は1クラスだけで、`javac *.java`と`*.class`で複数のクラスを扱う意味が例から伝わらない
- 外部ライブラリを含むJAR（マニフェストの`Class-Path`やFat JAR）は、第22章でも本章でも本文では扱わない空白地帯になっている（まとめでFat JARの名前を挙げるだけ）
- コマンドライン操作の例（bash）に番号が付いている（23-2、23-4、23-5、23-7、23-9〜23-13）。CLAUDE.mdの番号付けルール（bashは除く）と合わない（2026-11-12に解消）

## 節ごとの要約

- 本章の学習目標（L3–33）
    + JARの仕組み、マニフェスト、実行可能JAR、jpackage、ビルドとパッケージングの流れの5項目
    + 前提知識は第1章、第14章（基本的なI/O操作）、第17章（Swing）、第22章（クラスパスとJAR）、コマンドライン操作。推奨は第21章、CI/CD、デプロイ、OS差異
- なぜビルドと配布が必要か（L34–51）
    + ソースコードをそのまま渡せないこと、「ビルド」「パッケージング」「配布」の用語定義と、ソースから配布形式までの図（chapter23-build-flow）
    + H3「ビルドプロセスの技術的意味」は1段落のみ
- 実行可能JARファイルの作成（L52–258）
    + JARはZIP形式のアーカイブで、第22章のライブラリのJARと同じ形式に自分のプログラムをまとめ、Main-Classを加えると`java -jar`で実行できる
    + ステップ1〜5: Swingの最小アプリ（23-1）、`javac`（23-2）、マニフェストのMain-Classと半角スペース・末尾改行の注意（23-3）、`jar cvfm`とオプション（23-4）、`java -jar`での実行（23-5）
    + 応用: TodoApp（23-6）と複数クラスのJAR作成（23-7）、`getResource`で画像を読むResourceApp（23-8、nullでNullPointerExceptionになる注意と、icon.pngとmanifest.txtを全文と同じ場所に用意したこと）とリソース込みのJAR作成（23-9）
    + IntelliJ IDEAのArtifacts機能でのJAR作成手順
- jpackageによるネイティブアプリケーション化（L259–353）
    + JARはJREが必要という限界と、ランタイムを同梱するjpackage（Java 16で正式導入）の利点
    + 入力ディレクトリと出力ディレクトリを分ける準備とディレクトリ図
    + app-imageの作成とオプション解説（23-10）
    + Windows（23-11）、macOS（23-12）、Linux（23-13）向けの例。インストーラーにはWiX Toolset・dpkg-deb・fakeroot・rpmbuildなどの追加ツールが要ること、app-imageはインストーラーでないことを述べる
- まとめ（L354–383）
    + 発展技術としてビルド自動化ツール（第22章のMaven）、Fat JAR、GraalVMネイティブイメージ、コンテナー化、CI/CD（第21章のGitHub Actions）を列挙し、付録Gへ誘導する
- 章末演習（L384–399）
    + `exercises/chapter23/`へのリンク。基礎（実行可能JAR）・発展（リソース込みJAR）・チャレンジ（各OS向けインストーラー）の3課題

- 第1章: javac/javaコマンドとIntelliJ IDEAの導入。本章のIntelliJ手順はその延長
- 第17章: サンプルアプリ（JFrame、JList、DefaultListModel、SwingUtilities.invokeLater）の前提
