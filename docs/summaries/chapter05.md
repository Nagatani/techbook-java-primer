# 第5章 継承とポリモーフィズム 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter05-inheritance-and-polymorphism.md` を参照する。

## 章の概要

- extendsによる継承、is-a関係、オーバーライドと`@Override`、`super`と`super()`（Java 25のJEP 513を含む）、ポリモーフィズム、instanceofとキャスト、`Object`クラスのtoString・equals・hashCodeを教える
- 後半の「実践的な継承設計パターン」で、具象クラスによるテンプレートメソッドパターン（決済システム）、重複コードから継承へのリファクタリング（ドキュメント）、継承の誤用（ArrayList継承のスタック、権限階層、正方形と長方形、多重継承の代替）とリスコフ置換原則・コンポジションを扱う
- 2026-11-11に章を組み替え、基本（継承の書き方 → オーバーライド → ポリモーフィズム → instanceof → Objectのメソッド）を先に、実践パターンを後に置いた。equals・hashCodeの正式な説明（第3章から移した）を新しい節「`Object`クラスのメソッド」に集めた
- 前提は第4章のクラス設計。第3章で継承の考え方を紹介済み、第4章のprotectedの例で`extends`の読み方だけを見ている

## 節ごとの要約

- 本章の学習目標（L3–28）
    + 継承の基本、オーバーライド（Objectクラスのメソッドを含む）、ポリモーフィズム（テンプレートメソッドパターンを含む）、型変換と型判定の4項目。前提は第4章
- なぜ継承とポリモーフィズムが必要なのか（L29–57）
    + 給与計算の雇用形態を例にコード重複の問題（保守性・バグ・拡張性）を示す
    + 継承によるDRY原則と変更の局所化、ポリモーフィズムによる開放閉鎖原則・依存関係逆転の原則を給与計算の例で説明する
- 継承の基本（L58–220）
    + 第3章の紹介を受け、Employeeを継承するManager/Developerで、フィールド・メソッドの継承と固有メンバーの追加を示す（5-1、5-2）
    + is-a関係とhas-a関係（コンポジション）の区別
    + 継承の実践例: RPGのHero/Wizardで親のフィールド・メソッドを使う（5-3。Character・Hero・Wizard・Mainの全体を載せる）
- メソッドのオーバーライド（L221–348）
    + シグネチャの一致、共変戻り値型、アクセス修飾子は緩める方向のみ、というルール。`@Override`の役割
    + Character/Wizard/Knightで、attackのオーバーライドと`super.attack()`の利用を示す（5-4）
    + コンストラクターと`super()`: 暗黙の`super()`挿入、引数なしコンストラクターがない場合の明示呼び出し、Java 25では`this`を使わない処理なら`super(...)`の前に書けること（JEP 513）。呼び出し順の図（chapter05-constructor-chain）
- ポリモーフィズム（多態性）（L349–786）
    + 親クラス型の変数への子クラスインスタンスの代入（アップキャスト、5-5）と、同じ呼び出しで異なる振る舞い（5-6）
    + User配列をループで処理する例（5-7）と利点
    + ユーザー通知のBefore/After比較（5-8、5-9）、動的バインディングの図（chapter05-polymorphism）
    + 図形描画システムのBefore/After比較（5-10、5-11。enumは第8章へ誘導）と、OCP・SRP・DIP・テスト容易性・並列開発の利点
- `instanceof`演算子とキャスト（L787–879）
    + 親クラス型では子クラス固有メソッドを呼べないこと（5-12）
    + instanceofによる型調査とダウンキャスト、ClassCastExceptionの注意（5-13）、アップキャスト・ダウンキャストの図（chapter05-up-down-cast）
    + Java 16のinstanceofパターンマッチング（5-14）
- `Object`クラスのメソッド（toString・equals・hashCode）（L880–1011）
    + extendsを書かないクラスはObjectを継承すること（コンストラクターの図の最後とつなげる）と、主な3メソッド
    + StudentクラスでtoString・equals（getClassとObjects.equals、引数をObject型にする理由）・hashCode（Objects.hashCode）をオーバーライドする（5-15）
    + 第3章の`==`とequalsを受け、Objectのequalsは参照比較であること、hashCodeの契約3点とHashSet・HashMap（第9章）との関係
    + ObjectMethodsDemo（5-16）で3つの動きを確かめ、レコード（第8章）では自動で用意されると予告（2026-11-11新設）
- 実践的な継承設計パターン（L1012–1907）
    + 冒頭で、ここまでの基本を組み合わせる節と位置づける。テンプレートメソッド、戦略パターン、LSP、拡張性を予告
    + 決済システム: 具象クラスPaymentProcessorのfinalなprocessPaymentでテンプレートメソッドパターンを実装し、CreditCardPayment/PayPalPaymentが検証やAPI呼び出しをオーバーライドする。例外を使わずPaymentResultとerrorMessageで失敗を伝える（5-17〜5-19、図chapter05-inheritance-hierarchy）。5-18は`Math.random()`で拒否を模擬し、5-19の実行結果は「一例」と断っている
    + 段階的リファクタリング: WordDocumentとPDFDocumentの重複（5-20〜5-22）から親クラスDocumentを抽出し（5-23）、子クラスを再実装する（5-24、5-25）
    + 継承の誤用例: ArrayList継承のスタックとコンポジションによる解決（5-26、5-27）、全従業員にシステム管理権限を持たせる権限階層のLSP違反（5-28）、正方形と長方形（5-29。リスコフ置換原則の定義は誤用例2に置く）とインターフェイスによる解決（5-30）、多重継承の代替としての無理な継承（5-31）。解決は第7章のインターフェイスへ送る
- 例外処理の基礎（補足）（L1908–1948）

    + 付録B.04「仮想メソッドテーブル」への参照（appendix/ディレクトリ名とも一致）

    + 本文に挙げるエラー: super()の呼び出しに関するエラー、オーバーライドの制約違反、ClassCastException

    + 継承、オーバーライド、ポリモーフィズム、instanceofとキャスト、Objectクラスのメソッド、継承と例外の6項目と、第6章への導入
