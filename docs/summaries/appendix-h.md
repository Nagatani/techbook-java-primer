# 付録H Java共通エラーガイド 要約

行番号の正確な対応は `docs/book-index/appendix-h-common-errors.md` を参照する。

## 章の概要

- Javaでよく遭遇するエラー（実行時例外、コンパイルエラー）とデバッグ手法をまとめる付録。本文は概要のみで、詳細はGitHubの`appendix/h-common-errors/`（compile-errors、runtime-exceptions、debuggingなどが実在）にある
- サンプルコードはない

## 構成上の問題

- 本編の各章に「よくあるエラーと対処法」節があり（第9章、第13章など）、本付録との役割分担が本文に書かれていない
    + 2026-11-09に、各章の節の詳細をGitHubの`appendix/h-common-errors/chapters/`へ移し、本文は要点だけにした。付録Hの「オンライン資料」からも案内している
    + 第13章「よくあるエラー」7種と「デバッグのヒント」は、本付録の学習内容（効果的なエラーハンドリング、デバッグ手法）とほぼ同じ範囲
    + 統合するなら、各章のエラー節は章固有のものに絞り、横断的な例外（NullPointerException、ClassCastExceptionなど）とデバッグ手法は本付録へ寄せる方向が考えられる

## 節ごとの要約

- 付録Hについて（L3–73）
    + 学習内容（L7–14）: 実行時例外、コンパイルエラー、デバッグ手法、予防のベストプラクティス、エラーハンドリング手法の5項目
    + 前提知識（L15–23）: 基本文法、オブジェクト指向の基礎、例外処理の基本概念（章番号なし）
    + オンライン資料（L24–37）: リポジトリの内容6点（2026-11-09に、各章のよくあるエラーの詳細`chapters/`を追加）
    + 関連する章（L42–49）: 第3章（NullPointerException）、第4章、第9章（ConcurrentModificationException）、第10章（ClassCastException）、第13章
    + 学習のポイント（L50–63）と実践への応用（L64–72）

## 他章との関係

- 第3章: 章名を「オブジェクト指向プログラミングの基礎」と書いているが、現行は「オブジェクト指向の考え方」
- 第9章: ConcurrentModificationExceptionのほか、ClassCastExceptionも第9章のエラー集で扱っている
- 第13章: 例外処理の体系と「よくあるエラー」。重複の中心
- 第2章（基本文法、コンパイルエラー）と第15章（並行処理の例外）は関連する章に挙がっていない
