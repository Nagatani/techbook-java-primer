# 第7章 抽象クラスとインターフェイス 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter07-abstract-classes-and-interfaces.md` を参照する。

## 章の概要

- 「図形の面積は親クラスでは決められない」という例を動機に、抽象クラス・抽象メソッドとインターフェイスを教える
- 両者の使い分けをis-a関係とcan-do関係で整理し、「迷ったらインターフェイス」という経験則を示す
- Java 8以降のdefaultメソッド・staticメソッド（Java 9のprivateメソッドにも触れる）、ダイヤモンド問題と優先順位規則を扱う
- 後半はMixin、トレイト、ISP、バージョニング、Factoryパターンの設計パターン集
- 前提は第5章（継承）と第6章（final）。2026-11-11に、未習のジェネリクス・ラムダ式・`Optional`・`CompletableFuture`を使う例を書き換え、サンプルコードは18本になった

- 前提知識と章順の矛盾（2026-11-11に解消）

    + `Function`を拡張する旧7-15は外し、第11章で扱う旨の誘導にした。バージョニング（7-15）から`CompletableFuture`を外した

## 節ごとの要約

- 本章の学習目標（L3–19）
    + 抽象クラス（テンプレートメソッドパターン）、インターフェイス、Java 8以降の機能、設計パターン（Factory・Mixin）の4項目
- 抽象化の必要性（L20–27）
    + 図形ごとに面積の計算方法が異なる例で、共通の概念はあるが実装は子クラスに任せたい場面を示す
- 抽象クラスと抽象メソッド（L28–154）
    + 抽象メソッドを持つクラスはabstract宣言が必要、abstractを付けたクラスは抽象メソッドの有無にかかわらずnewできない、子クラスはすべての抽象メソッドを実装する、という3つのルールを文章で説明する
    + `Shape`抽象クラス（7-1）、`Circle`と`Rectangle`による実装（7-2）、親クラス型の変数によるポリモーフィズムと実行結果（7-3）
- インターフェイス：振る舞いの契約（L155–232）
    + インターフェイスのルール6項目（主なメンバーとしてdefault・static・privateメソッドを挙げる）と、主要インターフェイスの実装関係図（chapter07-interface-implementation）
    + `Exportable`と`Archivable`の定義（7-4）と、両方を実装する`TextDocument`（7-5）。継承関係にないクラス間で共通の能力を持たせる用途を説明する
- 抽象クラス vs インターフェイス（L233–249）
    + 目的（is-a/can-do）、継承と実装、持てるメンバー、使い分けの比較表と経験則
- Java 8以降のインターフェイス進化（L250–568）
    + 冒頭で`List`・`Map`を第9章へ誘導する
    + defaultメソッドによる後方互換な機能追加を`Greeting`の例で示し（7-6）、標準ライブラリの`Collection.removeIf`を実例として挙げる
    + defaultメソッドによるテンプレートメソッドパターンとフックメソッド（7-7）
    + ダイヤモンド問題と`X.super.method()`による解決（7-8、図chapter07-diamond-problem）、優先順位規則3つを文章で説明する（7-9）
    + staticメソッドによるユーティリティの提供（JSONのエスケープ、7-10）
    + defaultメソッドでnullや変更可能なリストから呼び出し側を守るラッパー（7-11。`addItem`もnullを返す実装ではfalseを返す）。`Optional`は第12章へ誘導する
- 高度な設計パターン（L569–806）
    + 冒頭で、関数型インターフェイスへのdefaultメソッドの応用は第11章で扱うと予告する
    + Mixin: `Timestamped`・`Identifiable`・`Versioned`を組み合わせる`Memo`（7-12）。`Duration`は脚注で付録Fへ誘導する。全文の`MixinDemo`の実行結果は、経過時間を「1秒未満か」だけで示す
    + トレイト: `measure()`だけを求め比較メソッドをdefaultで提供する`Measurable`（7-13）。`Comparable`版は第10章の知識が要ると断る
    + インターフェイス分離原則: 肥大化した`BadUserService`を役割ごとに分割する（7-14）
    + `ServiceV1`〜`ServiceV3`の継承とdefaultメソッドによるAPIのバージョニング（7-15）。V1からある`oldProcess`をV3で`@Deprecated(since, forRemoval = true)`にし、非推奨と削除予定の伝え方を分けて説明する
- Factoryパターン：オブジェクト生成の抽象化（L807–994）
    + Simple Factory: 文字列から図形を生成する`FigureFactory`（7-16、図chapter07-factory-pattern）
    + Factory Method: 抽象クラス`DocumentFactory`のサブクラスがWord/PDF文書を生成する（7-17、図chapter07-factory-method）
    + 利点（結合度の低減、拡張性、生成ロジックの隠蔽、一貫性）を文章で説明する
    + MySQL/PostgreSQLの接続を切り替える`DatabaseConnectionFactory`（7-18）
- よくあるエラーと対処法（L995–1014）
    + 出会いやすい誤り6点（抽象クラスのインスタンス化、実装忘れ、ダイヤモンド問題、defaultとstaticの混同、使い分けの誤り、@Overrideの省略）の要点と、付録H（`appendix/h-common-errors/chapters/chapter07.md`）のURL
- まとめ（L1015–1032）
    + 抽象クラス、インターフェイス、Java 8以降のインターフェイス、設計パターンの4項目と、第8章（列挙型・レコード・内部クラス）への導入
