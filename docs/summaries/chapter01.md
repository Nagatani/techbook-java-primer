# 第1章 Java入門と開発環境構築 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter01-introduction.md` を参照する。

## 章の概要

- 書籍全体の導入（本書の考え方、GitHubリポジトリ、対象読者、本書で学べること）と、Javaの最初の一歩（Hello World、標準出力、Scannerによる標準入力）を1章にまとめている
- C言語のグローバル変数による「データと手続きの分離」を動機に、Productクラスでオブジェクト指向の考え方を先取りして見せる
- Javaの特徴としてプラットフォーム独立性（JVM・バイトコード）、GC、JIT、強い型付け、ライブラリエコシステムを紹介する
- 開発環境はOpenJDK 21とIntelliJ IDEA Community Editionを指定し、手順そのものは付録A（GitHub）へ委ねる
- 前提はC言語の基礎（変数、関数、if文、ループ）
- まとめの節がなく、章末演習のあとに「よくあるエラーと対処法」と生成AIのコラムが続いて章が終わる

    + ガベージコレクション: L268 と L282–285 で2回説明している（後者は脚注付き）
    + オブジェクト指向の利点: L252–253 と「Javaの特徴」L278–280
    + Androidの位置付け: L33 の脚注と L309
    + NumberFormatException: コラム（L535–595）と「よくあるエラー」（L779–807）
- 章の順序の乱れ
    + 章末演習（L601–685）のあとに「よくあるエラーと対処法」（L686–1021）が置かれ、章末演習の「次のステップ」が章の途中に来る

## 節ごとの要約

- 本章の学習目標（L3–37）
    + 学ぶこと3点（Javaプログラムの書き方、コンパイルと実行、Javaの特徴）と前提（C言語の基礎）
    + 「本書の考え方」として、OOPは歴史の中の1手法であり、Javaは他言語学習の礎になると述べる（豊富な機能、厳密な型システム、実用性）。Androidの現状を脚注で補足
- 本書のGitHubリポジトリについて（L38–95）
    + リポジトリURLと、演習・サンプル・解答例・付録A〜Hの一覧。付録Bは15セクションを列挙する
    + 正誤表はIssuesで公開、FAQなどの追加リソース
- 本書の対象読者（L96–106）
    + C言語で基礎（ポインタまで）を学んだ大学1年生程度を想定。ラムダ式、Stream API、Record、パターンマッチング、Virtual Threadsなどのモダン機能も扱うと予告
- 本書で学べること（L107–134）
    + 基本文法、OOP、コレクションとジェネリクス、ラムダ式とStream API、Swing、外部ライブラリ、マルチスレッド、ネットワークを散文で紹介
    + 「学習のコツ」で、演習はGitHubで提供すると説明
- C言語、Java、そして現代的ソフトウェア開発のしくみ（L135–162）
    + グローバル変数の価格と税率を参照するCコード（番号なしのCコード1つ）で、データと手続きの分離が大規模開発で複雑さを生むことを示す
- Javaとオブジェクト指向：データと処理を一体化する（L163–257）
    + ProductクラスとMainクラス（1-1、1-2）で、privateフィールド、コンストラクタ、メソッド、newによるインスタンス生成を丸数字で解説
    + 1ファイル1publicクラスの注意、C言語との対比表現
    + 巻末の「Deep Dive: 抽象構文木（AST）とコンパイラの仕組み」を案内するが、付録Bにその項目は存在しない
- Javaの特徴（L258–316）
    + Write Once, Run Anywhere、JVMとバイトコード、GC、サンドボックス、JIT。JVMアーキテクチャの図（figure01-01）
    + 参照とポインタの違い、強い型付け、Maven/Gradleを含むエコシステム。GCの表記についての脚注
    + 「なぜJavaを学ぶのか」で企業システム、Spring Boot/Jakarta EE、Android、Hadoop/Sparkを挙げる
- 開発環境の準備（L317–331）
    + OpenJDK 21（LTS）とIntelliJ IDEA Community Editionを使う。構築手順は付録A（GitHub）を参照
- 最初のJavaプログラム（L332–363）
    + HelloWorld（1-3）。クラス名とファイル名の一致、mainメソッドがエントリポイント、System.out.printlnを散文で説明
    + コンパイル・実行と標準入力は付録Aへ委ねる

## 他章との関係

- 第2章（Java基本文法）との重複
    + Scannerのサンプル1-6と2-6はプロンプト文以外ほぼ同一で、「このコードのポイント」の5項目とjava.langの自動インポートの説明も同文
    + println・print・printf（1-5）は第2章のコンソール入出力（2-3）と重なる
    + クラス名とファイル名の不一致、セミコロン忘れ、大文字小文字の誤りは第2章「よくあるコンパイルエラー」と重なる
- 第3章・第4章: Productクラス（1-1）でカプセル化、コンストラクタ、newを先取りしている
- 第13章（例外処理）: コラムで予告。章参照は正しい
- 付録A: 環境構築とコンパイル・実行の手順を委ねている
- 付録B: L57–79の一覧は原稿の付録B索引（appendix-b-index-revised.md）と一致するが、appendix/のディレクトリ番号とは食い違う（例: B.02はJavaメモリモデルだがディレクトリはb02-programming-paradigms）。Issue #011
