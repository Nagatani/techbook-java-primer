# 第1章 Java入門と開発環境構築 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter01-introduction.md` を参照する。

## 章の概要

- 書籍全体の導入（本書の考え方、GitHubリポジトリ、対象読者、本書で学べること）と、Javaの最初の一歩（Hello World、IOクラスによる標準入出力）を1章にまとめている
- C言語のグローバル変数による「データと手続きの分離」を動機に、Productクラスでオブジェクト指向の考え方を先取りして見せる
- Javaの特徴としてプラットフォーム独立性（JVM・バイトコード）、GC、JIT、強い型付け、ライブラリエコシステムを紹介する
- 開発環境はOpenJDK 21とIntelliJ IDEA Community Editionを指定し、手順そのものは付録A（GitHub）へ委ねる
- 前提はC言語の基礎（変数、関数、if文、ループ）
- まとめの節がなく、章末演習のあとに「よくあるエラーと対処法」と生成AIのコラムが続いて章が終わる

## 節ごとの要約

- 本章の学習目標（L3–37）
    + 学ぶこと4点（Javaプログラムの書き方、コンパイルと実行、Javaの特徴、Java 25の簡潔な書き方）と前提（C言語の基礎）
    + 「本書の考え方」として、OOPは歴史の中の1手法であり、Javaは他言語学習の礎になると述べる（豊富な機能、厳密な型システム、実用性）。Androidの現状を脚注で補足
- 本書のGitHubリポジトリについて（L38–107）
    + リポジトリURLと、演習・サンプル・解答例・付録A〜Hの一覧。付録Bは15セクションを列挙する
    + 正誤表はIssuesで公開、FAQなどの追加リソース
- 本書の対象読者（L108–118）
    + C言語で基礎（ポインタまで）を学んだ大学1年生程度を想定。ラムダ式、Stream API、Record、パターンマッチング、Virtual Threadsなどのモダン機能も扱うと予告
- 本書で学べること（L119–145）
    + 基本文法、OOP、コレクションとジェネリクス、ラムダ式とStream API、Swing、外部ライブラリ、マルチスレッド、ネットワークを散文で紹介
    + 「学習のコツ」で、演習はGitHubで提供すると説明
- C言語、Java、そして現代的ソフトウェア開発のしくみ（L146–175）
    + グローバル変数の価格と税率を参照するCコード（1-1）で、データと手続きの分離が大規模開発で複雑さを生むことを示す
- Javaとオブジェクト指向：データと処理を一体化する（L176–270）
    + ProductクラスとMainクラス（1-2、1-3）で、privateフィールド、コンストラクタ、メソッド、newによるインスタンス生成を丸数字で解説
    + 1ファイル1publicクラスの注意、C言語との対比表現
    + 巻末の「Deep Dive: 抽象構文木（AST）とコンパイラの仕組み」を案内するが、付録Bにその項目は存在しない
- Javaの特徴（L271–328）
    + Write Once, Run Anywhere、JVMとバイトコード、GC、サンドボックス、JIT。JVMアーキテクチャの図（chapter01-jvm-architecture）
    + 参照とポインタの違い、強い型付け、Maven/Gradleを含むエコシステム。GCの表記についての脚注
    + 「なぜJavaを学ぶのか」で企業システム、Spring Boot/Jakarta EE、Android、Hadoop/Sparkを挙げる
- 開発環境の準備（L329–342）
    + OpenJDK 25（LTS）とIntelliJ IDEA Community Editionを使う。構築手順は付録A（GitHub）を参照
- 最初のJavaプログラム（L343–374）
    + HelloWorld（1-4）。クラス名とファイル名の一致、mainメソッドがエントリポイント、IO.printlnを散文で説明し、標準入出力にIOクラスを使うと述べる
    + コンパイル・実行と標準入力は付録Aへ委ねる
- Javaプログラムの基本構文（L375–490）
    + クラスとmainの骨格（1-5）、ルール3点、mainシグネチャの各要素の表
    + 「Java 25の新しい書き方：クラス宣言を省いたプログラム」（2026-11-10〜）: JEP 512のコンパクトソースファイル（1-7 Hello、1-8 フィールド・メソッドとjava.baseの自動import）、`java Hello.java`での直接実行、javapで見える暗黙のクラス、パッケージ宣言不可などの制限、クラス内のインスタンスmainメソッド（1-9）、従来との比較表、`import module java.base;`の紹介
    + 「本書での書き方」: 本書はクラスを宣言し`public static void main(String[] args)`で書く。理由はOOPが主題、実務のコードがクラス単位、既存のコードを読むため。試し書きにはコンパクトソースファイルを使ってよい
    + 本書の標準入出力の方針（2026-11-10〜）: IO.println・IO.print・IO.readln（Java 25のjava.lang.IO）を表で示し、書式はString.formattedで作る（1-12）
    + コラム「System.out.printlnとIOクラス」で、従来のSystem.out・Scanner(System.in)との関係、System.errは引き続き使うこと、読み替え方を説明
- 標準入出力を扱うサンプルを動かしてみよう（L491–617）

    + コラム「Integer.parseIntのエラーから学ぶ」で、NumberFormatExceptionの読み方を説明し、例外処理は第13章で学ぶと予告。try-catchの参考例あり
