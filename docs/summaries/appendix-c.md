# 付録C ソフトウェア工学の理論的基盤 要約

行番号の正確な対応は `docs/book-index/appendix-c-theoretical-foundations.md` を参照する。

## 章の概要

- ソフトウェア工学の理論（設計原則、品質メトリクス、計算複雑度、形式手法、並行理論）の案内。本文は概要のみで、詳細は`appendix/c-theoretical-foundations/`（GitHub）にある方針どおり
- 構成は付録Aとほぼ同じ定型（学習内容、前提知識、オンライン資料、Issue案内、関連する付録、学習のポイント、実践への応用）に「章とのマッピング」が加わる
- サンプルコード・図・脚注はない

## 節ごとの要約

- 付録Cについて（L3–92）
    + 学習内容7項目（ソフトウェアクライシス、ADT・カプセル化・継承、結合度・凝集度、デザインパターンの理論、計算複雑度、形式手法、並行プログラミングの理論）
    + 前提知識として第3・4・7・13・15章を挙げる
    + リポジトリの内容5項目（30以上の理論実装例など）
    + 関連する付録B.01、B.02、B.14、B.15
    + 学習のポイント4項目、章とのマッピング6項目、実践への応用5項目

## 他章との関係

- 前提知識の章番号は現行構成と一致する（第3章OOP、第4章クラス、第7章抽象クラスとインターフェイス、第13章例外処理、第15章マルチスレッド）
- 前提知識（L26–27）で第7章を「抽象クラスとインターフェイス（継承）」としているが、継承は第5章の主題。マッピング（L77）では「第5章（継承）・第7章（インターフェイス）」と正しく分けており、両者で食い違う
- 章とのマッピング（L79）の「第19章（MVC）」は疑わしい。現行の第19章は「高度なイベント処理パターン」で、原稿中でMVCに触れているのは第3章と第20章（JTableとJList）
- 前提知識には第5章・第19章・第21章がなく、マッピングとの対応がとれていない
- 学習内容の「アルゴリズム解析と計算複雑度」に対応する章（第9章の計算量表など）がマッピングにない
- 付録Bとの番号の食い違い（Issue #011）
    + L54「付録B.02「ソフトウェア設計原則」」: 付録Bの原稿ではB.02はJavaメモリモデル、設計原則はB.03（ディレクトリもb03）。どちらの番号体系でも誤り
    + L55「付録B.14「Javaメモリモデル」」: ディレクトリ番号（b14）には合うが、付録Bの原稿ではB.14はNIO.2、メモリモデルはB.02
    + L53「B.01」とL56「B.15」は原稿・ディレクトリとも一致
