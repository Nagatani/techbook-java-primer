# 付録C ソフトウェア工学の理論的基盤 要約

行番号の正確な対応は `docs/book-index/appendix-c-theoretical-foundations.md` を参照する。

## 章の概要

- ソフトウェア工学の理論（設計原則、品質メトリクス、計算複雑度、形式手法、並行理論）の案内。本文は概要のみで、理論の要点を示す実装例は`appendix/c-theoretical-foundations/`（GitHub）にある方針どおり
- 構成は付録Aとほぼ同じ定型（学習内容、前提知識、オンライン資料、Issue案内、関連する付録、学習のポイント、実践への応用）に「章とのマッピング」が加わる
- サンプルコード・図はない。脚注は1つ（冒頭のソフトウェア工学という言葉の由来、1968年のNATO会議）

## 節ごとの要約

- 付録Cについて（L3–101）
    + 冒頭（L5）: 理論的基盤の「要点とJavaの実装例を示す」と位置付け、実際に動くコードで確かめることを目的とする（2026-11-14に、付録の実物に合わせて「詳しく解説」から改めた）
    + 学習内容7項目（ソフトウェアクライシス、ADT・カプセル化・継承、結合度・凝集度、デザインパターンの理論、計算複雑度、形式手法、並行プログラミングの理論）。リポジトリの実装例がこの7項目に対応すると導入する
    + 前提知識（L19–35）: 第3章（クラスとカプセル化の基本）、第4章（アクセス修飾子とパッケージ）、第5章（継承とポリモーフィズム）、第7章（契約としてのインターフェイス）、第13章（契約理論）、第15章
    + オンライン資料（L37–49）: リポジトリにあるのは実装例とその説明で、理論の詳しい解説文はないため教科書をあわせて参照するよう述べる。内容4項目（README.mdの一覧と実行手順、20ファイル・30以上のクラスの実装例、7項目と実装の対応表、全デモを呼ぶMain.java）
    + 関連する付録（L56–65）: B.01、B.03、B.14、B.15を階層化リストで挙げる（B.15は「事前条件・事後条件を意識したテスト設計」）
    + 学習のポイント4項目、章とのマッピング6項目（第3・4・5・7・21・20・13章）、実践への応用5項目
