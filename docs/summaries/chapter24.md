- 2026-11-16に、付録E「データベースプログラミング」（GitHubのREADMEが約1,200行で、実質1章分だった）を本文に移して新設した章（著者の指示「重要度とページ数を見て本文に入れられる付録は入れる」）

## 節ごとの要約

- 本章の学習目標（L3–34）
    + 7項目。前提は第3・4・8・9・12・13・22章
- データベースを使う準備（L35–96）
    + ファイルとの違い、H2の入手と接続URLの表、ほかのデータベースのドライバーの表（2026-11時点の版をMaven Centralで確かめた）
- SQLの基本（L97–164）
    + DDL（主キー・制約・外部キー。IDの自動採番は標準SQLの`GENERATED BY DEFAULT AS IDENTITY`を使い、MySQLの`AUTO_INCREMENT`・SQLiteの`AUTOINCREMENT`と比べる）とDML（CRUD、WHERE・ORDER BY・GROUP BY・JOIN）
- JDBCのしくみ（L165–227）
    + java.sqlのインターフェイスとドライバー、図（chapter24-jdbc-architecture）、DriverManagerと自動登録（JDBC 4.0は脚注）、24-4
- 行を操作する（L228–386）
    + 値を含まないSQL文は`Statement`の`execute`でも実行できること（全文は表の作成に使う。脚注で全文の場所）、24-5でCRUD、ResultSetのカーソル、executeUpdateの戻り値（2回目の`delete`で0になる）。24-6でSQLインジェクションとPreparedStatement（パスワードのハッシュは脚注）
    + コラム「SQLインジェクションはなぜなくならないのか」（2026-11-19）。OWASP Top 10:2025で5位、?で渡せるのは値だけで表・列の名前は渡せないこと、許した名前の一覧で照らし合わせること、入力を信用しない前提
- DAOパターン（L369–490）
    + エンティティ（Record User）・インターフェイス・JDBC実装、24-7・24-8、getGeneratedKeys、Optional、第25章のリポジトリへの誘導
- 日付と時刻の列とjava.time（L491–540）
    + 型の対応表、setObject・getObject、24-9、半開区間の条件、タイムゾーン。java.timeの詳細は第6章「日付と時刻（java.time）」
- トランザクション（L541–598）
    + 自動コミット、24-10の送金と取り消し、DECIMALとBigDecimal（ACIDとdoubleの誤差は脚注）
- コネクションプールとバッチ処理（L599–702）
    + HikariCP 7.1.0（24-11、SLF4Jの警告を実行結果に含めた。closeが切断でなくプールへ返すことをコメントで示す）、バッチ（24-12、抜粋は18〜39行目、MySQLのrewriteBatchedStatementsは脚注）
- よくあるエラーと対処法（L703–722）
    + 6項目。詳しい内容は付録E（Javaのよくあるエラーと対処法）の`appendix/e-common-errors/chapters/chapter24.md`（2026-11-16に作成）
- まとめ（L723–748）・章末演習（L749–766）
