# 付録B 技術的な詳細解説（Deep Dive） 要約

行番号の正確な対応は `docs/book-index/appendix-b-index-revised.md` を参照する。

## 概要

- 15節（B.01〜B.15）の索引。節の番号は`appendix/bXX-*`のディレクトリ番号が正。題名は目次・付録一覧と同じ「技術的な詳細解説（Deep Dive）」にそろえた（以前は原稿だけ「〜インデックス」）

## 節ごとの要約

- 冒頭（L1–10）
    + 各節は、JDKの内部を観察しながら読む形で、主張に確かめ方（javap・JVMのログ・観察用のプログラム・仕様の節）を対応づけ、載せた出力はJDK 25で実際に動かしたものだと述べる（2026-11-19）
- 付録リソース一覧（L11–146）
    + 分野ごとの各節の場所・内容・関連章。B.03の関連章に第25章、B.15に第26章。「内容」は2026-11-19の書き直しに合わせて改めた。B.02の「内容」に、2026-11-23に第11章から移した「設計パターンを関数で書く」を足した
- 付録の活用方法（L147–157）・注意事項（L158–161）
    + 解説・サンプル・観察用のプログラム（`verify/`）・ベンチマークの使い方。注意事項は追加のツールと環境による結果の違いの2点に絞った

## 2026-11-16の再編

- 付録D（統合プロジェクト）と付録E（データベース）を本文の第24〜26章へ移し、残りの付録をA・B・C・D（java.time）・E（ビルド）・F（エラー）に振り直した。GitHubのディレクトリ名も`d-java-time-api`・`e-build-and-deploy`・`f-common-errors`に改めた
- すべての付録のページを同じ形（付録Xについて／内容／関連する章／オンライン資料）にそろえた。中身の少ない「学習のポイント」「実践への応用」と、各ページに繰り返していた「問題や質問がある場合」を削り、問い合わせ先は付録一覧に1か所だけ置いた
