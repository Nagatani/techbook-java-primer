# 付録B 技術的な詳細解説（Deep Dive）インデックス 要約

行番号の正確な対応は `docs/book-index/appendix-b-index-revised.md` を参照する。

## 章の概要

- 各章の発展的な技術解説（B.01〜B.15）を、GitHubの`appendix/bXX-*`ディレクトリへのリンク一覧として示すインデックス
- 各項目は「場所」「内容」「関連章」の3階層リストで統一されている
- サンプルコード・図はない

## 構成上の問題

原稿の節番号B.XXと、リンク先ディレクトリ名の番号bXXが15項目中10項目で食い違っている（Issue #011）。
原稿は分野別（JVM・言語基盤、オブジェクト指向・設計…）に並べ替えて番号を振り直したが、ディレクトリ名は旧番号のまま残っている。

## 節ごとの要約

- 冒頭の導入（L1–4）
    + 付録の位置付けとGitHubの`appendix/`ディレクトリへの案内。URLが文中に地の文のまま埋め込まれている
- 付録リソース一覧（L5–141）
    + 7分野（JVM・言語基盤、オブジェクト指向・設計、コレクション・ジェネリクス、関数型プログラミング、高度な言語機能、I/O・並行処理、テスト・開発プロセス）に15項目を分類
    + 「B.02 Javaメモリモデル」が「JVM・言語基盤」に入り、分類名「I/O・並行処理」にはNIO.2しかない（メモリモデルは並行処理側が自然）
    + 「B.10 プログラミングパラダイム」が「関数型プログラミング」に分類されているが、内容は手続き型・OOP・関数型の比較
- 付録の活用方法（L142–150）
    + README.mdでの概要確認、`src/`のサンプル実行、ベンチマーク結果の参照の3項目
- 注意事項（L151–155）
    + 章の理解後に参照すること、追加ライブラリが必要な場合があること、最新情報はリポジトリで確認すること
