# 付録B 技術的な詳細解説（Deep Dive）インデックス 要約

行番号の正確な対応は `docs/book-index/appendix-b-index-revised.md` を参照する。

## 章の概要

- 各章の発展的な技術解説（B.01〜B.15）を、GitHubの`appendix/bXX-*`ディレクトリへのリンク一覧として示すインデックス
- 各項目は「場所」「内容」「関連章」の3階層リストで統一されている
- サンプルコード・図はない

## 構成上の問題

- 原稿の節番号B.XXとリンク先ディレクトリ名の番号bXXが15項目中10項目で食い違っていた（Issue #011）
    + 2026-11-09に、ディレクトリ番号（b01〜b15）を正として原稿の一覧を並べ替え、番号を振り直した。用語集・付録C・付録Dの参照もディレクトリ番号に合わせた
    + 各ディレクトリのREADMEの見出しを「付録B.NN …」にそろえた
    + `npm run check:structure`で、番号・ディレクトリ・READMEの見出し・本文の「付録B.NN「題名」」の一致を検査する

## 節ごとの要約

- 冒頭の導入（L1–4）
    + 付録の位置付けとGitHubの`appendix/`ディレクトリへの案内。URLが文中に地の文のまま埋め込まれている
- 付録リソース一覧（L5–140）
    + 6分野（言語基盤と設計の考え方、オブジェクト指向、コレクション・ジェネリクス・Stream、言語機能、I/O・並行処理、テスト）に15項目を分類。番号はディレクトリ名と一致する
- 付録の活用方法（L141–149）
    + README.mdでの概要確認、`src/`のサンプル実行、ベンチマーク結果の参照の3項目
- 注意事項（L150–154）
    + 章の理解後に参照すること、追加ライブラリが必要な場合があること、最新情報はリポジトリで確認すること

## 他章との関係

- 各章の発展的な解説の受け皿。関連章は第1・2・3〜7・8・9・10・11・12・13・14・15・21章
- 第16章以降（ネットワーク、GUI、ビルド）に対応するDeep Diveはない
- 付録A・付録Cの「関連する付録」から番号で参照されており、Issue #011の影響を受ける
