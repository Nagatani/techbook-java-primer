# 第9章 コレクションフレームワーク 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter09-collections.md` を参照する。

## 章の概要

- 配列の限界（固定サイズ、削除の手間、検索などの操作不足）を動機に、List・Set・Mapの使い分けを教える
- 主要な実装はArrayList/LinkedList、HashSet/TreeSet/LinkedHashSet、HashMap/TreeMap/LinkedHashMap
- 走査はfor-each文とIterator（走査中の削除）を扱う
- 前提は第2章の配列と第7章のインターフェイス
- ジェネリクス記法（`List<String>`）は説明なしで使い、第10章冒頭で「第9章で見た不思議な記法」として回収している

## 構成上の重大な問題

この章は、2つの版が結合されたまま残っている。

- 前半（L3–630）は「本章の学習目標」で始まり、「章末演習」と「次のステップ」で章の途中に終わる
- 後半（L631–1275）は2つ目の「本章の学習目標」から始まり、List・Set・Map・配列の限界を再度説明し、「よくあるエラー」「まとめ」で終わる
- 重複している内容
    + 配列の限界: 前半「なぜ必要か」と後半「データ管理の進化」
    + List/Set/Map: 前半は実装比較中心、後半はArrayList/HashSet/HashMapの完全なサンプル中心
    + イテレータでの削除: サンプルコード9-13と9-18
    + ArrayListとLinkedListの比較: 前半の箇条書きと後半の表
- 統合するなら、前半の流れ（動機→全体像→各インターフェイス→走査→選択指針）を骨格にし、後半の完全なサンプル（9-16、9-20、9-21）、配列とListの相互変換（9-19）、エラー集、まとめを移すのが自然

## 節ごとの要約

### 前半

- 本章の学習目標（L3–19）
    + 学ぶこととしてCollectionsユーティリティ、時間計算量、スレッドセーフティを挙げるが、本文で扱っていない（予告と本文の不一致）
- なぜコレクションフレームワークが必要か（L20–187）
    + 学生名簿を配列で書き、サイズ固定・削除時の穴・検索の自作という3つの問題を示す（9-1〜9-5）
    + 同じ処理をArrayListで書き直して解決を示す（9-6）
- コレクションフレームワークの全体像（L188–230）
    + Collection（List・Set・Queue）とMapの階層図。Queueはここで名前が出るだけで以降扱わない
- List インターフェイス（L231–307）
    + ArrayListとLinkedListの比較と基本操作（9-7、9-8）
    + HashMap内部構造の図（figure09-02c）がList節に置かれている（配置の誤り）
- Set インターフェイス（L308–372）
    + HashSet/TreeSet/LinkedHashSetの順序の違い（9-9）
    + addAll/retainAll/removeAllによる和集合・積集合・差集合（9-10）
- Map インターフェイス（L373–447）
    + HashMap/TreeMap/LinkedHashMapの違い（9-11）
    + getOrDefault、containsKey、keySetとentrySetの走査（9-12）
- イテレータとfor-each文（L448–520）
    + Iteratorでの走査中の安全な削除（9-13）とfor-each文の制約（9-14）
    + 拡張for文・イテレータ・従来のforループの使い分け
- コレクションの選択指針（L521–570）
    + 6実装の計算量表と、実装ごとの使用場面・実例
- 今後の学習へ向けて（L571–606）
    + Stream APIと`List.of`などの不変コレクションを紹介する。番号なしのJavaコードが2つあり、第12章への参照もない
- 章末演習（L607–630）
    + 演習リンクが`exercises/chapter10/`を指している（Issue #010）

### 後半

- 本章の学習目標 (2)（L631–650）
    + 長い散文の前提知識と目標。ラムダ式・メソッド参照（第11章で学ぶ内容）やCSV・DB処理の経験を前提にしていて、章の順序と矛盾する
    + カスタムComparatorや「100万件を1秒以内」を目標に掲げるが、本文で扱っていない
- データ管理の進化：配列からコレクションへ（L651–690）
    + 配列の2つの制限を再度説明（9-15）。コレクションの4つの利点（動的サイズ・豊富な機能・ポリモーフィズム・型安全）
- `List`インターフェイス：順序のあるデータ列（L691–822）
    + ArrayListの完全なサンプル（9-16）、ArrayListとLinkedListの比較表
    + 走査方法（9-17、9-18）、配列とListの相互変換とArrays.asListの固定サイズの注意（9-19）
- `Set`インターフェイス：重複のないユニークな集合（L823–866）
    + HashSetの完全なサンプル。addの戻り値で重複を検出する（9-20）
- `Map`インターフェイス：キーと値のペア（L867–924）
    + HashMapの完全なサンプル。putの上書き、entrySetの走査（9-21）。付録B.06への参照
- よくあるエラーと対処法（L925–1264）
    + NullPointerException、ClassCastException、UnsupportedOperationException、ConcurrentModificationException、IndexOutOfBoundsException、Mapの存在しないキー、equals/hashCode、Raw typeの8種（9-22〜9-30）とデバッグのコツ
- まとめ（L1265–1275）
    + List・Set・Mapの比較表。次章のジェネリクスへの導入
