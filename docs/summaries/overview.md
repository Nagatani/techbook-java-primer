## 章をまたぐ問題

### 1. 過去の版・分冊の結合跡（最優先）

- 2つの版が丸ごと結合されている
    + 第3章、第9章（2026-11-07〜08に解消済み）
- 分冊ファイルの結合跡（存在しないファイルへのリンク、`<!-- Merged from -->`コメント、パートごとのまとめ）
    + 第15章、第17章（2026-11-08に解消済み）
- まとめ・章末演習が章の途中にあり、その後ろに節が継ぎ足されている
    + 第4章、第5章、第6章、第11章、第12章、第19章（2026-11-08に解消済み）

    + 第15章（第13章は2026-11-08に解消済み）

### 2. 章の順序と合わない先取り

ほぼ全章で、後の章で学ぶ機能を説明なしに使っている。
とくに多いものは次のとおり。

- ジェネリクス・コレクション（第9・10章）
    + 第3、4、5、7、8章
- ラムダ式・Stream・Optional（第11・12章）
    + 第6、7、8、10、13章
- 例外処理（第13章）
    + 第2、3、5章
- スレッド・ExecutorService（第15章）
    + 第6、11、13、14章
- GUI（第17章以降）
    + 第14章のJFileChooser

2026-11-08に、要約で指摘した先取りの初出（第2〜4・6〜8・10〜14・19章）に、どの章で学ぶかと最小限の読み方を示す案内を加えた。サンプル自体の書き換えや、案内のない2回目以降の使用の整理はしていない。

前提知識の記述が章順と矛盾する例として、第9章（ラムダ式を前提）、第13章（「第5章まで」なのにJDBCやSpring）、第21章と第22章（互いを前提）がある。
