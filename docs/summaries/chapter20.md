# 第20章 JTableとJListの基礎 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter20-advanced-gui.md` を参照する。

## 章の概要

- データ表示用のSwingコンポーネントとして、JTable（ソート・フィルタ・カスタムエディター）、JTree（静的構築と動的操作）、JList（カスタムモデルとレンダラー）を扱う
- 最後にJSplitPaneで3つを組み合わせたプロジェクト管理アプリ（20-7）を示す
- 前提は第17章のSwing基礎、第18・19章のイベント処理、第9章のコレクション、第7章のインターフェイス
- 二重構成（過去の版の結合）は見られないが、章題・学習目標と本文の水準が大きくずれている

## 構成上の問題

- 章題「JTableとJListの基礎」と学習目標（基本的な使い方、選択・クリック、簡単なデータ表示アプリ）は入門水準だが、本文は旧題「高度なGUI」（ファイル名advanced-gui）の内容のまま
    + 基本は20-1の1例だけで、すぐにTableRowSorter、カスタムエディター、ポップアップメニュー付きJTree、統合アプリへ進む
    + JTreeは章題にも学習目標にもないのに、本文で最大級の節（L201–428）を占める
    + 学習目標の「基本的なテーブル操作（選択、クリック）」に当たる説明はなく、getSelectedRow（20-2）やTreeSelectionListener（20-7）がコード中に現れるだけ
- 章の導入が二重だった（「本章の学習目標」と「この章で学ぶこと」が別々のH2）のは2026-11-08に解消した。末尾も「よくあるエラー → まとめ → 章末演習」の順に並べ替えた
- まとめは本文と一致しない
    + 「AbstractTableModelによるカスタムモデルの実装」とあるが、本文の例はDefaultTableModelのみ（AbstractTableModelはエラー集の20-15だけ）
    + 「メニューバーとツールバーの実装」とあるが、20-7にJToolBarはなく、表示メニューに「ツールバー」チェック項目があるだけ（L801の説明文も同様）
- よくあるエラーと対処法（L465–484）の大半は本章のテーマと関係が薄く、第17・19章と重複する（2026-11-09に詳細をGitHubへ移したため、本文での重複は解消した）
    + paintComponentとダブルバッファリング（20-8〜20-11）は第17章のカスタム描画の範囲
    + EDTとSwingWorker（20-12）は第17章L1495付近と第19章のパフォーマンス節・エラー集で既に扱っている
    + 画像キャッシュ（20-13）とGridBagLayoutの動的再配置（20-16、20-17）は本章の本文に登場しない
    + 本章に直結するのはJTableの大量データ（20-14、20-15）とレンダラーの選択状態（20-18、20-19）のみ
- JListの基本（選択モードなど）は第17章L450付近で既に扱い、JTreeも第17章L804付近に登場する。本章の「基礎」という位置付けと第17章の境界が曖昧

## 節ごとの要約

- 本章の学習目標（L3–40）
    + 5項目の目標。JTableとJListの基本、選択・クリック、簡単なアプリ作成を掲げる
    + JTable・JListの概要とMVC設計の説明。前提知識に第17〜19章、第9章、第7章、推奨知識に第8章のRecord、MVC、オブザーバーパターン、第15章を挙げる
    + 「第15章のマルチスレッドプログラミング（SwingUtilities.invokeLater）」とあるが、第15章はinvokeLaterを扱っていない（第17章で扱う）
    + 2026-11-08に、別のH2だった「この章で学ぶこと」を学習目標の下の小見出しにまとめた
- JTableの詳細な実装（L41–100）
    + 2次元配列と列名からJTableを作り、JScrollPaneに入れる基本例（20-1）
    + 節題は「詳細な実装」だが中身は最も基本的な例
- テーブルのソートとフィルタリング（L101–156）
    + TableRowSorterによるヘッダークリックのソートと、RowFilterによる名前列のフィルタ、行の追加・削除（20-2）
    + 20-2が使うPersonTableModelとPersonの定義は本文にない（2026-11-08に、全文には補ってコンパイルできるようにした）
- JTreeの実装（L157–257）
    + DefaultMutableTreeNodeでファイルシステム風のツリーを作る基本例（20-3）

- JListの高度な使用法（L258–327）
    + Taskクラス、AbstractListModelを継承したTaskListModel、JPanelベースのListCellRendererで、タイトル・説明・期限・完了状態を表示するタスクリスト（20-5）。ダブルクリックで完了を切り替える
- カスタムセルエディターの実装（L328–398）
    + JColorChooserを開くColorCellEditor、ColorCellRenderer、コンボボックスのPriorityCellEditorをJTableに設定する（20-6）
- 実践的なアプリケーション例（L399–464）

- L34: 「推奨される知識：」はコロンでリストを導入している（2文構成パターンにそろえる余地がある）
