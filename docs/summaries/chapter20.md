# 第20章 JTable・JList・JTree 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter20-advanced-gui.md` を参照する。

## 章の概要

- データ表示用のSwingコンポーネントとして、JTable（ソート・フィルタ・カスタムエディター）、JTree（静的構築と動的操作）、JList（カスタムモデルとレンダラー）を扱う
- 最後にJSplitPaneで3つを組み合わせたプロジェクト管理アプリ（20-7）を示す
- 前提は第17章のSwing基礎、第18・19章のイベント処理、第9章のコレクション、第7章のインターフェイス
- 二重構成（過去の版の結合）は見られない。章題・学習目標と本文の水準のずれは、2026-11-14に章題を「JTable・JList・JTree」（副題「表・リスト・階層データの表示」）に改め、学習目標を本文の節（ソートとフィルタリング、JTree、レンダラー、エディター、統合アプリ）に合わせて解消した

    + 学習目標の下の導入（L16）でもJTableとJListを「Swingの高度なコンポーネント」と呼んでいる。導入の呼び方とJTreeへの言及は直した（2026-11-12に解消）。章題と学習目標も直した（2026-11-14に解消）
- まとめは本文と一致しない

## 節ごとの要約

- 本章の学習目標（L3–44）
    + 5項目の目標。JTableとJListの基本、選択・クリック、簡単なアプリ作成を掲げる
    + JTable・JListの概要とMVC設計の説明。前提知識に第17〜19章、第9章、第7章、推奨知識に第8章のRecord、MVC、オブザーバーパターン、第18章のEDT・第19章のSwingWorkerを挙げる（2026-11-11に、第15章でinvokeLaterを学ぶとした誤りを直した）
- JTableの詳細な実装（L45–114）
    + JTableと関連部品（モデル・レンダラー・エディター・ソーター）の役割分担の図（chapter20-jtable-roles）
    + 2次元配列と列名からJTableを作り、JScrollPaneに入れる基本例（20-1）と、表示される内容（列: ID・名前・年齢・メールアドレス、セルはダブルクリックで編集できる）
    + 節題は「詳細な実装」だが中身はもっとも基本的な例
- テーブルのソートとフィルタリング（L115–176）
    + TableRowSorterによるヘッダークリックのソートと、RowFilterによる名前列のフィルタ（「適用」ボタンで実行、入力は`Pattern.quote`で文字として扱う）、行の追加・削除（20-2）。表示される内容を示す
    + 20-2が使うPersonTableModel（AbstractTableModelを継承）の役割を前置きで述べる。定義は全文にある。追加する行のIDはいまの最大値+1
- JTreeの実装（L177–285）
    + DefaultMutableTreeNodeでファイルシステム風のツリーを作る基本例（20-3）。子を持つノードにはハンドルが出て、`setShowsRootHandles(true)`はルートにもハンドルを出す指定だと説明する
    + DefaultTreeModel、右クリックのポップアップメニューによるノード追加・削除、ノード名の編集、カスタムTreeCellRenderer（20-4）
- JListの高度な使用法（L286–388）
    + 第17章の17-9（文字列の配列とsetSelectionMode）から、モデルとカスタムレンダラーへ進むと述べる
    + ListModelの`getSize`・`getElementAt`、変更をリストに知らせる`fireIntervalAdded`・`fireIntervalRemoved`・`fireContentsChanged`、内部で知らせを送るDefaultListModelとの違い（20-7で使う）
    + Taskクラス、AbstractListModelを継承したTaskListModel、JPanelベースのListCellRendererで、タイトル・説明・期限・完了状態を表示するタスクリスト（20-5）。中のパネルを`setOpaque(false)`にして選択色を見せ、文字色も部品ごとに切り替える（完了タスクの灰色は選択していないときだけ。選択中に灰色だと青い選択色の上で読みにくかったため2026-11-14に直した）。ダブルクリックで完了を切り替える
- カスタムセルエディターの実装（L389–460）
    + JColorChooserを開くColorCellEditor、ColorCellRenderer、コンボボックスのPriorityCellEditorをJTableに設定する（20-6）
- 実践的なアプリケーション例（L461–533）
    + JTree・JTable・JListをJSplitPaneで組み合わせ、ツリー選択でタスク表とメンバー一覧を切り替えるプロジェクト管理アプリ（20-7）
    + タスクの表は表示専用で、DefaultTableModelに1行ずつ入れ直す。メニューは「ファイル」（終了）と「表示」（ステータスバーの表示切り替え）。ステータスバーに選択中のプロジェクト名を出す
- よくあるエラーと対処法（L534–554）
    + 本文に挙げる問題: paintComponentの描画が表示されない・ちらつく、背景スレッドからのGUI更新、大量の画像によるメモリ不足、大量データのJTableが遅い、動的な追加・削除で配置が崩れる、レンダラーで選択状態が表示されない
    + paintComponentは第17章、EDTは第18章、SwingWorkerは第19章で学んだと誘導する。詳細は`appendix/h-common-errors/chapters/chapter20.md`
    + 本章の本文に登場しない話題（paintComponent、ちらつき、EDT、画像のメモリ、動的な配置）が残っていた（2026-11-14に解消。並べ替えた表の行番号の変換、モデルの変更の通知、JTreeのinsertNodeInto、JScrollPaneと見出し、編集中の値の確定、レンダラーの選択状態、大量データの7項目にし、付録Hの第20章も同じ7節とコンパイルできる全文に書き直した）
