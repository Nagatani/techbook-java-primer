# 第20章 JTableとJListの基礎 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter20-advanced-gui.md` を参照する。

## 章の概要

- データ表示用のSwingコンポーネントとして、JTable（ソート・フィルタ・カスタムエディター）、JTree（静的構築と動的操作）、JList（カスタムモデルとレンダラー）を扱う
- 最後にJSplitPaneで3つを組み合わせたプロジェクト管理アプリ（20-7）を示す
- 前提は第17章のSwing基礎、第18・19章のイベント処理、第9章のコレクション、第7章のインターフェイス
- 二重構成（過去の版の結合）は見られないが、章題・学習目標と本文の水準が大きくずれている

## 構成上の問題

- 章題「JTableとJListの基礎」と学習目標（基本的な使い方、選択・クリック、簡単なデータ表示アプリ）は入門水準だが、本文は旧題「高度なGUI」（ファイル名advanced-gui）の内容のまま
    + 基本は20-1の1例だけで、すぐにTableRowSorter、カスタムエディター、ポップアップメニュー付きJTree、統合アプリへ進む
    + JTreeは章題にも学習目標にもないのに、本文の大きな節（L163–263）を占める
    + 学習目標の「基本的なテーブル操作（選択、クリック）」に当たる説明はなく、getSelectedRow（20-2）やTreeSelectionListener（20-7）がコード中に現れるだけ
    + 学習目標の下の導入（L16）でもJTableとJListを「Swingの高度なコンポーネント」と呼んでいる
- まとめは本文と一致しない
    + 「AbstractTableModelによるカスタムモデルの実装」とあるが、本文の例はDefaultTableModel（20-2のPersonTableModelの定義は本文にない）
    + 「メニューバーとツールバーの実装」とあるが、20-7にJToolBarはない（L412の説明文も「ツールバーも実装し」と書く）
- 第17〜19章との重複（エラー集のpaintComponent・EDT・SwingWorker）は、詳細を付録Hへ移し、本文から第17〜19章へ誘導する形にした（2026-11-11に解消）
- JListの基本は第17章の17-9で扱い、本章の20-5の冒頭から17-9を参照して境界を示すようになった（2026-11-11に解消）

## 節ごとの要約

- 本章の学習目標（L3–40）
    + 5項目の目標。JTableとJListの基本、選択・クリック、簡単なアプリ作成を掲げる
    + JTable・JListの概要とMVC設計の説明。前提知識に第17〜19章、第9章、第7章、推奨知識に第8章のRecord、MVC、オブザーバーパターン、第18章のEDT・第19章のSwingWorkerを挙げる（2026-11-11に、第15章でinvokeLaterを学ぶとした誤りを直した）
- JTableの詳細な実装（L41–106）
    + JTableと関連部品（モデル・レンダラー・エディター・ソーター）の役割分担の図（chapter20-jtable-roles）
    + 2次元配列と列名からJTableを作り、JScrollPaneに入れる基本例（20-1）
    + 節題は「詳細な実装」だが中身はもっとも基本的な例
- テーブルのソートとフィルタリング（L107–162）
    + TableRowSorterによるヘッダークリックのソートと、RowFilterによる名前列のフィルタ、行の追加・削除（20-2）。実行結果を示す
    + 20-2が使うPersonTableModelとPersonの定義は本文にない（全文には補ってある）
- JTreeの実装（L163–263）
    + DefaultMutableTreeNodeでファイルシステム風のツリーを作る基本例（20-3）
    + DefaultTreeModel、右クリックのポップアップメニューによるノード追加・削除、ノード名の編集、カスタムTreeCellRenderer（20-4）
- JListの高度な使用法（L264–334）
    + 第17章の17-9（文字列の配列とsetSelectionMode）から、モデルとカスタムレンダラーへ進むと述べる
    + Taskクラス、AbstractListModelを継承したTaskListModel、JPanelベースのListCellRendererで、タイトル・説明・期限・完了状態を表示するタスクリスト（20-5）。ダブルクリックで完了を切り替える
- カスタムセルエディターの実装（L335–405）
    + JColorChooserを開くColorCellEditor、ColorCellRenderer、コンボボックスのPriorityCellEditorをJTableに設定する（20-6）
- 実践的なアプリケーション例（L406–471）
    + JTree・JTable・JListをJSplitPaneで組み合わせ、ツリー選択でタスク表とメンバー一覧を切り替えるプロジェクト管理アプリ（20-7）
- よくあるエラーと対処法（L472–492）
    + 本文に挙げる問題: paintComponentの描画が表示されない・ちらつく、背景スレッドからのGUI更新、大量の画像によるメモリ不足、大量データのJTableが遅い、動的な追加・削除で配置が崩れる、レンダラーで選択状態が表示されない
    + paintComponentは第17章、EDTは第18章、SwingWorkerは第19章で学んだと誘導する。詳細は`appendix/h-common-errors/chapters/chapter20.md`
    + 本章の本文に登場しない話題（画像のメモリ、動的な配置）が残っている
- まとめ（L493–525）
    + 学習内容5項目と次章（ユニットテスト）への導入。本文と一致しない項目がある（構成上の問題を参照）
    + 「エンタープライズレベルのデスクトップアプリケーションを開発できる」は章題の「基礎」と釣り合わない
- 章末演習（L526–546）
    + 演習リンクは`exercises/chapter20/`。テーブル操作、ファイルエクスプローラー、IDE風アプリの3課題
