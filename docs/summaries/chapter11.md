# 第11章 ラムダ式と関数型インターフェイス 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter11-lambda-and-functional-interfaces.md` を参照する。

## 章の概要

- 匿名クラスの冗長さを動機にラムダ式を導入し、関数型インターフェイス、構文の省略形、Comparatorによる並べ替え、`java.util.function`の標準インターフェイス、メソッド参照の4種類を教える
- 応用としてThread、ExecutorService、関数型のバリデーションでのラムダ式の利用を示す
- 後半の「関数型プログラミングの実践例」に、高階関数・リアクティブストリーム・CQRS・金融取引などの発展的な実務例（多くは実行できない断片）をまとめている
- Comparator（`comparing`・`thenComparing`・`reversed`）を正式に説明する章（2026-11-11に第12章から集めた）
- 前提は第7章のインターフェイス、第9章のコレクション、第10章のジェネリクス

## 節ごとの要約

- 本章の学習目標（L3–19）
    + ラムダ式の基本、標準関数型インターフェイス、メソッド参照の4種類、関数型スタイル（宣言的・関数合成・副作用の最小化）の4項目
- 匿名クラスからラムダ式へ（L20–93）
    + 後の章の機能（Thread・ExecutorService・イベントリスナー・Stream API）が出てくる旨の案内
    + Runnableで匿名クラスとラムダ式を対比（11-1）
    + 匿名ActionListener（11-2）と、そのラムダ式版の1行（11-3）
- 関数型インターフェイス（L94–352）
    + 抽象メソッドが1つのインターフェイスと`@FunctionalInterface`。図2枚（基本・拡張）。独自インターフェイスの例（11-4）。ActionListenerも関数型インターフェイスである旨
    + ラムダ式の構文の省略形（型の省略、括弧の省略、波括弧とreturnの省略）
    + Comparatorによる並べ替え。自然な順序との違い、匿名クラス→ラムダ式→`Comparator.comparing`の3通り（11-5）
    + `thenComparing`と`reversed`による複数条件の並べ替え（11-6）。`reversed()`が条件全体を逆にする落とし穴、2つ目以降の条件だけ降順にする書き方、`comparingInt`。第12章の`sorted`にも渡せる旨
    + Predicate・Function・Consumer・Supplier・UnaryOperator・BinaryOperatorの表と使用例（11-7）
- メソッド参照（L353–504）
    + 静的・特定インスタンス・不特定インスタンス・コンストラクターの4種類の表。`IO::println`は静的メソッド参照、`System.out::println`は特定インスタンスの参照
    + `forEach`と`replaceAll`を使った4種類の例（11-8）
    + ラムダ式とメソッド参照の書き比べ（11-9）。引数を受け取るコンストラクター参照`Person::new`の補足
- ラムダ式の応用例（L505–692）
    + Threadへの匿名クラスとラムダ式のRunnableの受け渡し（11-10）
    + ExecutorServiceとCallableによるスレッドプールへのタスクの受け渡し（11-11、2026-11-11にメソッド参照の節から移動）
    + 関数型のバリデーション（11-12）
- 関数型プログラミングの実践例（L693–1273、2026-11-11に導入節から移して新設）
    + 発展的な内容で断片的なコードが多い旨と、Streamの読み方の案内
    + 高階関数によるリスク管理の抽象化（11-13）
    + アンチパターンとして過度なネストと副作用（11-14、11-15）
    + Netflixを例にした同期処理とリアクティブ処理の比較（11-16、11-17）。速くなる理由を待ち時間の合計と最大の違いで説明（2026-11-11に出典のない性能値を外した）
    + リトライ（11-18）、イベント処理（11-19）、ミドルウェア（11-20、`then`に改名した理由）、テンプレートメソッド（11-21）、イベントソーシング（11-22）、ファクトリ（11-23）
    + キャプチャの有無とラムダ式の性能（11-24）
    + 関数型ビルダーと設定ビルダー（11-25、11-26）、高頻度取引（11-27）、ビジネスロジックの関数合成と`andThen`の説明（11-28）
- よくあるエラーと対処法（L1274–1293）
    + 構文エラー、型推論の失敗、検査例外の扱い、変数のキャプチャ、関数型インターフェイスの実装の誤り、メソッド参照の型の不一致の要点と、`appendix/h-common-errors/chapters/chapter11.md`のURL
- まとめ（L1294–1305）
