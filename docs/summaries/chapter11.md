# 第11章 ラムダ式と関数型インターフェイス 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter11-lambda-and-functional-interfaces.md` を参照する。

## 章の概要

- 匿名クラスの冗長さを動機にラムダ式を導入し、関数型インターフェイス、構文の省略形、変数のキャプチャと副作用、Comparatorによる並べ替え、`java.util.function`の標準インターフェイス、関数の合成、メソッド参照の4種類を教える
- 応用としてThread、ExecutorService、関数型のバリデーションでのラムダ式の利用を示す
- 後半の「関数型プログラミングの実践例」に、高階関数・ベストプラクティス・リアクティブストリーム（文章のみ）・実装パターン（再試行、イベント処理、ミドルウェア、テンプレートメソッド、イベントソーシング、ファクトリ）・ラムダ式の内部実装・関数型ビルダー・関数合成による業務処理をまとめている
- Comparator（`comparing`・`thenComparing`・`reversed`）を正式に説明する章（2026-11-11に第12章から集めた）
- 前提は第7章のインターフェイス、第8章の匿名クラス、第9章のコレクション、第10章のジェネリクス

## 節ごとの要約

- 本章の学習目標（L3–19）
    + ラムダ式の基本、標準関数型インターフェイス、メソッド参照の4種類、関数型スタイル（宣言的・関数合成・副作用の最小化）の4項目
- 匿名クラスからラムダ式へ（L20–90）
    + 第8章で学んだ匿名クラスがラムダ式以前に使われていたことを述べ、後の章の機能（Thread・ExecutorService・イベントリスナー・Stream API）が出てくる旨を案内する
    + Runnableで匿名クラスとラムダ式を対比（11-1）
    + 匿名ActionListener（11-2）と、そのラムダ式版の1行（11-3）
- 関数型インターフェイス（L91–438）
    + ラムダ式は関数型インターフェイスの型が求められる場所（代入、引数）にだけ書け、評価するとそのインターフェイスを実装したオブジェクトになる。抽象メソッドが1つのインターフェイスと`@FunctionalInterface`。独自インターフェイスの例（11-4）。ActionListenerも関数型インターフェイスである旨
    + ラムダ式の構文の省略形（型の省略、括弧の省略、波括弧とreturnの省略、引数がないときの`()`は省略できない）
    + ラムダ式から参照できる変数は、finalか実質的にfinalなものに限られること（javacのメッセージ）と、外の状態を書き換えない書き方の利点
    + Comparatorによる並べ替え。自然な順序との違い、匿名クラス→ラムダ式→`Comparator.comparing`の3通り（11-5）
    + `thenComparing`と`reversed`による複数条件の並べ替え（11-6）。`reversed()`が条件全体を逆にする落とし穴、2つ目以降の条件だけ降順にする書き方、`comparingInt`。第12章の`sorted`にも渡せる旨
    + Predicate・Function・Consumer・Supplier・UnaryOperator・BinaryOperatorの表と使用例（11-7。Supplierは既定の値を返す例で、実行結果は毎回同じ）
    + 関数の合成。`andThen`と`compose`の順序の違い、`Predicate`の`and`・`or`・`negate`（11-8）
- メソッド参照（L439–590）
    + 静的・特定インスタンス（`変数名::メソッド名`）・不特定インスタンス・コンストラクターの4種類の表。`IO::println`は静的メソッド参照、`System.out::println`は特定インスタンスの参照
    + `forEach`と`replaceAll`を使った4種類の例（11-9）
    + ラムダ式とメソッド参照の書き比べ（11-10）。引数を受け取るコンストラクター参照`Person::new`の補足
- ラムダ式の応用例（L591–795）
    + Threadへの匿名クラスとラムダ式のRunnableの受け渡し（11-11）。`join()`で待つので「メインスレッド終了」が最後になること、開始の順序は実行ごとに変わりうること
    + ExecutorServiceとCallableによるスレッドプールへのタスクの受け渡し（11-12）。順に実行すると3秒のタスクが約1.5秒で終わることを、「3秒未満で終わったか」で示す
    + 関数型のバリデーション（11-13）
- 関数型プログラミングの実践例（L796–1518）
    + 発展的な内容で断片的なコードが多い旨と、Streamの読み方の案内
    + 高階関数によるリスク管理の抽象化（11-14）
    + ベストプラクティスとして、ラムダ式を深く入れ子にしない（11-15）と、外部の状態を変えない（11-16。並列ストリームの`forEach`に渡すと要素が欠けうる）
    + Netflixを例にした同期処理とリアクティブ処理の違い（文章のみ。Flowの脚注）
    + 実装パターン集: 再試行（11-17、2回失敗して3回目で成功する実行結果）、イベント処理（11-18）、ミドルウェア（11-19、ミドルウェアの説明、`then`に改名した理由と動き）、テンプレートメソッド（11-20、`removeIf`で書き換えるのは新しく作ったリストである旨）、イベントソーシング（11-21、設計の説明つき）、ファクトリ（11-22）
    + ラムダ式の内部実装。キャプチャの有無で同じインスタンスになるかを比べる（11-23）。使い回しは実装依存で、性能はJMHなどで測る
    + 関数型ビルダー（11-24、実行結果と第6章のビルダーとの違い）と、条件に応じた設定の組み立て（11-25）
    + 関数合成による業務処理（11-26）。5つの処理を`andThen`でつなぐ
- よくあるエラーと対処法（L1519–1538）
    + 構文エラー、型推論の失敗、検査例外（第13章）の扱い、変数のキャプチャ、関数型インターフェイスの実装の誤り、メソッド参照の型の不一致の要点と、`appendix/h-common-errors/chapters/chapter11.md`のURL
- まとめ（L1539–1552）
    + ラムダ式（関数型インターフェイスの型が求められる場所に書く）、標準インターフェイス、メソッド参照の要点と、入れ子にしすぎない注意。末尾で付録B.02「プログラミングパラダイム」を参照する（2026-11-14に章の最終行から移した）
- 章末演習（L1553–1573）
    + 演習リンクは`exercises/chapter11/`と、基礎・発展・チャレンジ課題の概要。第12章への案内
