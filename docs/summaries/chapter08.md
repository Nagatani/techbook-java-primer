# 第8章 Javaの特殊なクラス形式（列挙型とレコード） 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter08-special-classes.md` を参照する。

## 章の概要

- 列挙型、レコード、両者の使い分け、内部クラスの4部構成
- Enumは`static final int`定数の問題を動機に、values/valueOf、フィールドとメソッド、列挙子ごとの実装、Singleton・Strategy、EnumSet/EnumMapまで扱う
- Recordは自動生成される要素、コンパクトコンストラクター、withメソッド、パターンマッチング、sealed interface、データ指向プログラミングまで扱う。Recordを正式に説明する章で、第3章・第6章からここへ誘導される
- 内部クラスはメンバー・静的・ローカル・匿名の4種類と、匿名クラスによるイテレーターを扱う
- 前提は第6章のfinalと第7章のインターフェイス（Recordの節では第5章のequals・hashCodeも参照する）
- 2026-11-11に、未習のジェネリクス・Stream・ラムダ式を使う例を書き換え、全文で示した実行結果の出どころを本文に書いた
- 「よくあるエラーと対処法」はEnumの小節（H3）にしかなく、Record・内部クラスにはない
- 2026-11-14の校閲で、Record・sealed・パターンマッチング・内部クラスの構文の説明を足した（コンパクトコンストラクター、型パターン・レコードパターン・`case null`、permitsと網羅性、実質的にfinal）

## 節ごとの要約

- 本章の学習目標（L3–26）
    + Enum、Record（sealed interfaceやパターンマッチングと組み合わせた活用を含む）、両者の使い分け、内部クラスの基本の4目標
- 列挙型（Enum）（L27–439）
    + `int`定数の3つの問題（無効値、型の意味不明、表示が数値）を文章で示し、enumで解決する
    + 基本構文（`enum`の後ろに型名、列挙子をカンマで区切って波括弧で囲む）と使用例（8-1、8-2）、values/valueOf/name/ordinal（8-3）
    + フィールドとメソッドを持つ`Planet`（8-4、図chapter08-enum-instances）、switch文との組み合わせ（8-5）、列挙子ごとの`apply`実装（8-6）。8-5・8-6の実行結果はGitHubの全文に付けたデモクラスのものと本文に書く
    + Singleton（8-7。`Connection`が`java.sql`のインターフェイスである旨を書く）、Strategyパターンの名前を8-6の後で説明（同じしくみの繰り返しだった旧8-8は2026-11-23に削り、PaymentStrategyの全文は8-6のディレクトリへ移した）、インターフェイスの実装（8-8）、EnumSetとEnumMap（8-9。コレクションは第9章へ誘導）
    + ベストプラクティスとして命名の慣習、向く場面・避ける場面を文章で説明する
    + よくあるエラーとして定数名の大文字小文字の誤りを挙げ、付録E（`appendix/e-common-errors/chapters/chapter08.md`）のURLを示す。caseには定数名だけを書くのが一般的と書き、型名付きがJava 20以前はエラー・Java 21から書けることは脚注にする
- レコード（Record）（L440–981）
    + ボイラープレートの問題と、第6章（不変クラスのルール）・第5章（equals等）との関係。1行の定義（8-10）と、括弧の中の`name`・`age`を成分（record component）と呼ぶこと、コンパイラーによる展開イメージ（8-11）、自動生成される6要素、メリット・デメリット（文章）。デメリットとして、継承できない・ほかのクラスを継承できない（脚注）・成分のほかにインスタンスフィールドを足せない（staticフィールドとメソッドは書ける）ことを挙げる。`final`が守るのは参照だけで、`List`などの中身は第6章の防御的コピーで守る旨を書く
    + 使用例（8-12）、コンパクトコンストラクターの構文（引数リストを省く、本体の最後でフィールドへ自動代入）と検証（8-13）、追加コンストラクター（正準コンストラクター以外のもの。本体で`this(...)`により正準コンストラクターを呼ぶ規則、8-14）、静的ファクトリメソッド（`new`の代わりにオブジェクトを返すstaticメソッドで、`ofCelsius`のように名前で意味を表せる、8-15）、withメソッド（一部の成分だけを差し替えた新しいRecordを返す「with＋成分名」のメソッド、8-16）
    + 型パターン・レコードパターン・`case null`を使ったswitchとガード（`when`）（8-17）、配列の統計をまとめるローカルRecord（8-18）、ネストしたRecord（8-19）
    + DTO（8-20）とValue Object（8-21）の実践例。Value Objectの意味と、コンパクトコンストラクターで引数に代入し直すと正規化した値がフィールドに入ることを説明する
    + sealed interfaceとRecordによる網羅的なswitch（8-22、図chapter08-sealed-record）。permitsの意味、許可された型の修飾子（final・sealed・non-sealed）、defaultのないswitchが網羅性の検査で通ることを説明する。データとロジックを分けるデータ指向プログラミング（8-23。import文を省いた旨を書く）
- EnumとRecordの使い分けと組み合わせ（L982–1099）
    + Enumを使う場面・Recordを使う場面のガイドライン
    + 終端状態を持つ`OrderStatus`と、状態遷移で新しいインスタンスを返す`Order`（8-24）
    + ゲームのキャラクター職業（Enum）とステータス（Record）の組み合わせ（8-25）。導入文で、職業ごとの初期値をEnumに持たせ、レベルアップで新しいRecordを返すと説明する
- 内部クラス（Inner Classes）（L1100–1339）
    + 4種類の内部クラスの関係図（chapter08-inner-class-hierarchy）
    + メンバー内部クラスと`outer.new InnerClass()`（8-26）、静的内部クラス（8-27。第6章の`Book.Builder`がこれに当たると書く）、ローカルクラスと、参照できる変数の条件（final・実質的にfinal。第11章のラムダ式にも当てはまる）（8-28）、匿名クラスによる`Comparator`（8-29。ラムダ式とComparatorは第11章へ誘導）
    + 匿名内部クラスでイテレーターを返す`StringList`（8-30）と、標準の`Iterator`・拡張for文との関係
    + 種類の選び方、メモリリークの回避（外部クラスのフィールドやメソッドを使うメンバー内部クラスが外部のインスタンスへの参照を隠し持つため。Java 18以降のコンパイラーが使わない参照を省くことは脚注）、ラムダ式による代替を文章で説明する
- よくあるエラーと対処法
    + 2026-11-23にEnumの節のなかのh3から、まとめの前のh2へ移した。列挙型の定数名、Recordのアクセサー名（getNameは作られない）、コンパクトコンストラクターでの代入、sealedインターフェイスの制約、内部クラスの生成とローカル変数の実質的final。caseに型名を付けられるのはJava 21からと脚注。付録E（appendix/e-common-errors/chapters/chapter08.md）のURL
- まとめ（L1340–1365）
    + Enum・Record・内部クラスそれぞれの重要ポイント（Recordにはsealed interfaceとの組み合わせによる網羅性の検査を含む）と、第9章への導入
