# 第8章 Javaの特殊なクラス形式（列挙型とレコード） 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter08-special-classes.md` を参照する。

## 章の概要

- 列挙型（Part 1）、レコード（Part 2）、両者の使い分け（Part 3）、内部クラス（Part 4）の4部構成
- Enumは`static final int`定数の問題を動機に、values/valueOf、フィールドとメソッド、列挙子ごとの実装、Singleton・Strategy、EnumSet/EnumMapまで扱う
- Recordは自動生成される要素、コンパクトコンストラクタ、withメソッド、パターンマッチング、sealed interface、データ指向プログラミングまで扱う
- 内部クラスはメンバー・静的・ローカル・匿名の4種類と、匿名クラスによるIterator実装を扱う
- 前提は第6章のfinalと第7章のインターフェイス
- 2章を統合した跡として節がPart 1〜4のH2見出しになっていた（2026-11-08に「Part N:」を外した）。章内で同じ説明が二重に残っている箇所は見当たらない。一方で「よくあるエラーと対処法」はPart 1のH3にしかなく、Record・内部クラスにはない

## 構成上の問題

- 章タイトルの副題は列挙型とレコードだけを挙げ、内部クラスに触れていない（学習目標には2026-11-08に内部クラスの項目を追加した）
- まとめの「内部クラスの重要ポイント」にある「メモリモデルとパフォーマンスへの影響」は本文で扱っていない（ベストプラクティスにメモリリークの2行があるだけ）
- 章順より後で学ぶ機能をサンプルで多用している（2026-11-08に、初出の箇所へ後の章で学ぶ旨と最小限の読み方の案内を加えた）
    + ジェネリクス（第10章）: 8-21の`ApiResponse<T>`、8-31の`MyList<T>`
    + コレクション（第9章）: 8-19、8-24のList、Collections.max/min
    + Stream API・ラムダ式・メソッド参照（第11章・第12章）: 8-19、8-24
    + 匿名クラスとラムダ式の対比（8-30）は第11章冒頭「匿名クラスからラムダ式へ」と重複する
- 同じ型名が章内で別定義になっている
    + `Rectangle`: 8-15（正方形用コンストラクタ付き）と8-23（Shape実装）
    + `Order`: 8-24（Customerとitemsを持つ）と8-25（OrderStatusを持つ）
- 第3章「モダンJavaにおけるオブジェクト指向」（第3章 L2653–）がRecord、パターンマッチング、sealedクラスを先に紹介しており、本章Part 2と重複する。第6章の6-12もRecordを扱う

    + フィールドとメソッドを持つ`Planet`（8-4）、switch文との組み合わせ（8-5）、列挙子ごとの`apply`実装（8-6）

    + 命名・使うべき場面・避けるべき場面のベストプラクティス
