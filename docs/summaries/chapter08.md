# 第8章 Javaの特殊なクラス形式（列挙型とレコード） 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter08-special-classes.md` を参照する。

## 章の概要

- 列挙型、レコード、両者の使い分け、内部クラスの4部構成
- Enumは`static final int`定数の問題を動機に、values/valueOf、フィールドとメソッド、列挙子ごとの実装、Singleton・Strategy、EnumSet/EnumMapまで扱う
- Recordは自動生成される要素、コンパクトコンストラクター、withメソッド、パターンマッチング、sealed interface、データ指向プログラミングまで扱う。Recordを正式に説明する章で、第3章・第6章からここへ誘導される
- 内部クラスはメンバー・静的・ローカル・匿名の4種類と、匿名クラスによるイテレーターを扱う
- 前提は第6章のfinalと第7章のインターフェイス（Recordの節では第5章のequals・hashCodeも参照する）
- 2026-11-11に、未習のジェネリクス・Stream・ラムダ式を使う例を書き換え、全文で示した実行結果の出どころを本文に書いた
- 「よくあるエラーと対処法」はEnumの小節（H3）にしかなく、Record・内部クラスにはない
