# 第6章 不変性とfinal 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter06-immutability-and-final.md` を参照する。

## 章の概要

- 可変オブジェクトが引き起こす競合状態と副作用を動機に、不変オブジェクトとfinalキーワードを教える
- finalの3用途（変数・メソッド・クラス）、不変クラスの5つのルール、防御的コピー、ビルダーパターンを扱う。Recordは予告（6-8）にとどめ、本格的な説明は第8章に任せる
- 前提は第4章のカプセル化と第5章の継承・`Object`クラスのメソッド
- 動機づけの例（6-1）でスレッドとラムダ式、6-4・6-6でList・ArrayListを使う。どれも初出の箇所に、後の章で学ぶ旨と最小限の読み方を書いている（6-10の静的ネストクラスも同様）
- 2026-11-11に、利点を並べた箇条書きを文章にし、不変クラス・Recordの重複を整理した（サンプルコードは11本に。2026-11-12にViewVsCopyを足して12本）

## 節ごとの要約

- 本章の学習目標（L3–19）
    + 不変性の概念、finalの使い分け、不変オブジェクトの設計（防御的コピー・ビルダー）、実践的な実装技術の4目標
- 不変性の概念と重要性（L20–155）
    + 可変な`MutablePoint`を2スレッドで更新する競合状態（6-1。実行結果は一例と明記）と、getterが内部の可変オブジェクトを返す副作用（6-2）を問題として示す
    + finalフィールドと`withX`/`withY`を持つ`ImmutablePoint`で解決を示し（6-3）、スレッドセーフティ・キャッシュ・デバッグの利点を文章で述べる
    + スレッドセーフティは「共有しても状態が壊れない」に限り、6-1のように共有の値を更新し続ける処理は不変にしただけでは正しくならないこと、同期化は第15章で学ぶことを断る
- finalキーワードの3つの用途（L156–265）
    + final変数（static final定数、finalフィールド、finalローカル変数）（6-4）と、finalフィールドの初期化のタイミング（宣言時・コンストラクター・インスタンス初期化子・static初期化子）。finalのローカル変数は宣言のあとに1回だけ代入してもよいと添える
    + finalメソッドでテンプレートメソッドの流れを固定する例（6-5）
    + finalクラス。`String`の宣言を例に挙げ（コードではなく文中で）、6-3の`ImmutablePoint`を継承したときのコンパイルエラーを示す。利点は悪意あるサブクラスの防止、不変の前提が崩れることの防止、設計意図の明示で、速度のためにfinalを付ける必要はないと述べる
- 不変オブジェクトの設計パターン（L266–402）
    + 不変クラスの5ルール（finalクラス、private finalフィールド、setterなし、コンストラクターで初期化完了、防御的コピー）
    + 防御的コピーとwith系メソッドを持つ`ImmutablePerson`（6-6。equals・hashCode・toStringは全文にあり、第5章の書き方に従う旨を書く）と、その使用例（6-7）。重要な特性を文章で説明し、`HashMap`のキーや関数型プログラミングとの相性に触れる
    + 小節「Recordで不変なクラスを簡潔に書く」でRecordの1行の宣言（6-8）を示し、詳細は第8章へ誘導する
- 防御的コピーとビルダーパターン（L403–628）
    + `DateRange`で入力時・出力時の防御的コピーを示し（6-9）、図（chapter06-defensive-copy）で有無の違いを示す
    + 小見出し「防御的コピーのコストと注意点」で、コピーのコスト、浅いコピーと深いコピー、`Collections.unmodifiableList`のビューと`List.copyOf`の違いを説明し、ViewVsCopy（6-10）で示す
    + 必須とオプションのパラメーターを分けた`Book.Builder`（6-11）と、メソッドチェーンでの使用例（6-12）。ビルダーの利点（読みやすさ、必要な値だけの設定、完成後の不変性、構築時の検証）を文章で述べる
- よくあるエラーと対処法（L629–648）
    + 出会いやすい誤り6点（final変数の再代入と未初期化、可変なフィールドの露出、防御的コピーの実装忘れ、final配列・コレクションの誤解、継承による不変性の破綻、不必要な防御的コピー）の要点と、付録H（`appendix/h-common-errors/chapters/chapter06.md`）のURL
- まとめ（L649–668）
    + 学習内容4点を列挙する（不変性の利点は1項目にまとめた）
- 章末演習（L669–695）
    + `exercises/chapter06/`へのリンクと、基礎・発展・チャレンジ課題の概要。第7章への案内と付録B.05への参照
