# 第6章 不変性とfinal 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter06-immutability-and-final.md` を参照する。

## 章の概要

- 可変オブジェクトが引き起こす競合状態と副作用を動機に、不変オブジェクトとfinalキーワードを教える
- finalの3用途（変数・メソッド・クラス）、不変クラスの5つのルール、防御的コピー、ビルダーパターンを扱う。Recordは予告（6-8）にとどめ、本格的な説明は第8章に任せる
- 前提は第4章のカプセル化と第5章の継承・`Object`クラスのメソッド
- 動機づけの例（6-2）でスレッドとラムダ式、6-4・6-6でList・ArrayListを使う。どれも初出の箇所に、後の章で学ぶ旨と最小限の読み方を書いている（6-10の静的ネストクラスも同様）
- 2026-11-11に、利点を並べた箇条書きを文章にし、不変クラス・Recordの重複を整理した（サンプルコードは11本に。2026-11-12にViewVsCopyを足して12本。2026-11-16・17にjava.timeとBigDecimalの節を加えて18本）

## 節ごとの要約

- 本章の学習目標（L3–23）
    + 不変性の概念、finalの使い分け、不変オブジェクトの設計（防御的コピー・ビルダー）、実践的な実装技術、日付と時刻、数値の正確な計算の6目標
- 不変性の概念と重要性（L24–160）
    + 可変な`MutablePoint`を2スレッドで更新する競合状態（6-1。実行結果は一例と明記）と、getterが内部の可変オブジェクトを返す副作用（6-2）を問題として示す
    + finalフィールドと`withX`/`withY`を持つ`ImmutablePoint`で解決を示し（6-3）、スレッドセーフティ・キャッシュ・デバッグの利点を文章で述べる
    + スレッドセーフティは「共有しても状態が壊れない」に限り、6-1のように共有の値を更新し続ける処理は不変にしただけでは正しくならないこと、同期化は第15章で学ぶことを断る
- finalキーワードの3つの用途（L161–275）
    + final変数（static final定数、finalフィールド、finalローカル変数）（6-4）と、finalフィールドの初期化のタイミング（宣言時・コンストラクター。初期化子は本書のほかの章で説明しないので、2026-11-23にリストから外し、本書では使わないと1文で触れる形にした）。finalのローカル変数は宣言のあとに1回だけ代入してもよいと、リストの後に添える。6-4の前に`LocalDateTime`は本章の節「日付と時刻（java.time）」で学ぶと案内する
    + 小見出し「finalが固定するのは参照だけ」で、参照型の変数に`final`を付けても指す先の中身は変えられること（配列の例をインラインコードで示す）と、finalだけでは不変にならず、可変なフィールドの扱いは次の節と防御的コピーの節で学ぶことを述べる（2026-11-23に追加）
    + finalメソッドでテンプレートメソッドの流れを固定する例（6-5）。コードの後ろに、入力の確認を飛ばせないこと、第5章の5-17の`processPayment()`と同じ形であること、守りたい手順を決めるメソッドに絞って付けることを説明する（2026-11-23。第5章が「第6章で詳しく学ぶ」と送っていたのに説明がなかった）
    + finalクラス。`String`の宣言を例に挙げ（コードではなく文中で）、6-3の`ImmutablePoint`を継承したときのコンパイルエラーを示す。利点は悪意あるサブクラスの防止、不変の前提が崩れることの防止、設計意図の明示で、速度のためにfinalを付ける必要はないと述べる
- 不変オブジェクトの設計パターン（L276–415）
    + 不変クラスの5ルール（finalクラス、private finalフィールド、setterなし、コンストラクターで初期化完了、防御的コピー）
    + ルール5の防御的コピーのしくみ（節「finalが固定するのは参照だけ」を受ける）と図（chapter06-defensive-copy）を6-6の前に置く（2026-11-23。以前は6-6で使ったあとの節で初めて説明していた）
    + 防御的コピーとwith系メソッドを持つ`ImmutablePerson`（6-6。equals・hashCode・toStringは全文にあり、第5章の書き方に従う旨を書く）と、その使用例（6-7）。重要な特性を文章で説明し、`HashMap`のキーや関数型プログラミングとの相性に触れる
    + 小節「Recordで不変なクラスを簡潔に書く」でRecordの1行の宣言（6-8）を示し、詳細は第8章へ誘導する
- 防御的コピーとビルダーパターン（L416–652）
    + 小見出し「何をコピーするか」（2026-11-23に「防御的コピーの重要性」から改めた）で、6-6を受け、`DateRange`（6-9）で不変の`LocalDate`はそのまま持ち、リストだけをコピーし、配列でも返す例を示す
    + 小見出し「防御的コピーのコストと注意点」で、コピーのコスト、浅いコピーと深いコピー、`Collections.unmodifiableList`のビューと`List.copyOf`の違いを説明し、ViewVsCopy（6-10）で示す
    + 必須とオプションのパラメーターを分けた`Book.Builder`（6-11）と、メソッドチェーンでの使用例（6-12）。ビルダーの利点（読みやすさ、必要な値だけの設定、完成後の不変性、構築時の検証）を文章で述べる
- 日付と時刻（java.time）（L653–860）
    + DateとCalendarの問題、主なクラスの表、作成と計算（6-13）、差（ChronoUnit・Period・Duration、6-14）、表示と読み取り（DateTimeFormatter、SMARTとSTRICT、6-15）。書式の記号（`yyyy`・`MM`・`M`・`dd`・`d`・`E`）を説明する
    + コラム「タイムゾーンと「2038年問題」」（2026-11-19）。32ビットの秒数が2038-01-19T03:14:07Zであふれること、Instantは64ビット、タイムゾーンと夏時間の存在しない時刻、UTCで保存し表示で変換する定石
- 数値の正確な計算（BigDecimal）（L861–1112）
    + 第2章の基本データ型からの誘導を受け、`java.math`の不変クラス`BigDecimal`・`BigInteger`を扱う
    + `double`で0.1を10回足すと1.0にならない誤差と、文字列から作る`BigDecimal`での正確な計算。`new BigDecimal(0.1)`と`valueOf`の違い、計算は新しいオブジェクトを返すので戻り値を受け取ること、スケール（6-16）
    + 掛け算のスケール、`setScale`、割り切れない割り算の`ArithmeticException`と`divide(割る数, 桁数, 丸め方)`（6-17）。`RoundingMode`の主な6つと2.5・-2.5の丸めの表（列挙型は第8章へ誘導）
    + `compareTo`による比較と、`equals`がスケールまで比べる注意（`HashSet`のことは脚注）。`long`のオーバーフローと`BigInteger`、30の階乗（6-18）。`Math.addExact`
    + 使い分け（BigDecimal・最小単位のlong・BigInteger・double）と、第24章のDECIMAL型への案内
    + コラム「お金の計算は「型」より「決まりごと」が難しい」（2026-11-19）。品目ごとか合計かで税額が変わる例（27円と29円）、丸め方と丸める場所は業務の決まりで、担当者に確かめて仕様書に書くこと
- よくあるエラーと対処法（L1076–1097）
    + 出会いやすい誤り7点（final変数の再代入と未初期化、可変なフィールドの露出、防御的コピーの実装忘れ、final配列・コレクションの誤解、継承による不変性の破綻、不必要な防御的コピー、BigDecimalの扱いの誤り）の要点と、付録E（`appendix/e-common-errors/chapters/chapter06.md`）のURL
