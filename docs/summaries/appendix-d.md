# 付録D 統合プロジェクト - 学生管理システム 要約

行番号の正確な対応は `docs/book-index/appendix-d-integrated-project.md` を参照する。

## 章の概要

- 本書の技術を統合して「学生管理システム」を6フェーズで段階的に構築する付録。本文は概要のみで、実装はGitHubの`appendix/d-integrated-project/`（phase1〜phase6のディレクトリが実在）にある
- サンプルコードはない

## 節ごとの要約

- 付録Dについて（L3–95）
    + 学習内容（L7–15）: クラス設計（第3-4章）、継承とポリモーフィズム（第5-7章）、コレクションとジェネリクス（第9-11章）、例外処理（第13章）、GUI（第17-19章）、データベース統合（付録E）の6フェーズ
    + 前提知識（L16–31）: 学習内容と同じ章範囲を再掲
    + オンライン資料（L32–45）: リポジトリの内容6点
    + プロジェクト概要（L51–63）: 完成時の機能（登録・更新・削除、成績管理、検索、永続化、GUI、エクスポート/インポート）
    + 関連する付録（L64–69）: 付録E、付録B.03、付録B.15
    + 学習のポイント（L70–84）と実践への応用（L85–95）

## 他章との関係

- 第3〜13章、第17〜19章の総まとめ。ファイルI/O（第14章）、ユニットテスト（第21章）、JTable（第20章）はフェーズに含まれていない。エクスポート/インポートやテストコードを掲げながら第14章・第21章に触れていない
