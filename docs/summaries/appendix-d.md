# 付録D 統合プロジェクト - 学生管理システム 要約

行番号の正確な対応は `docs/book-index/appendix-d-integrated-project.md` を参照する。

## 章の概要

- 本書の技術を統合して「学生管理システム」を6フェーズで段階的に構築する付録。本文は概要のみで、実装はGitHubの`appendix/d-integrated-project/`（phase1〜phase6のディレクトリが実在）にある
- サンプルコードはない

## 節ごとの要約

- 付録Dについて（L3–107）
    + 学習内容（L7–20）: クラス設計（第3-4章）、継承とポリモーフィズム（第5-7章）、コレクション・ジェネリクス・ラムダ式・Stream API（第9-12章）、例外処理とファイル入出力（第13-14章）、GUI（第17-20章）、データベース統合（付録E）の6フェーズ
    + 前提知識（L22–36）: 学習内容と同じ章範囲を再掲（第17-20章は「JTableを含む」）
    + オンライン資料（L38–50）: リポジトリの内容5点（各フェーズの実行手順とファイル構成のREADME.md、実行可能なソース、動作確認用のプログラム、SQLiteのテーブル定義（DatabaseManager.java）、CSVのインポート・エクスポート）
    + プロジェクト概要（L57–68）: 完成時の機能（学生の登録・削除、成績の追加・削除とGPA計算、氏名・学生IDの検索と学部の絞り込み、SQLiteによる永続化、GUI、CSVのインポート・エクスポート）
    + 関連する付録（L70–80）: 付録E、付録B.03、付録B.15（動作確認のプログラムをテストに発展させるときの考え方）。付録EはH2で例を動かすが、フェーズ6はSQLiteを使い、JDBCの使い方は同じと補う
    + 学習のポイント（L82–95）と実践への応用（L97–107）
- 2026-11-14に、リポジトリの内容と完成時の機能を付録の実物に合わせた（なかった「段階的な実装ガイド」「テストコード」「セットアップスクリプト」「サンプルデータ」と、実装のない「更新」を削った）
