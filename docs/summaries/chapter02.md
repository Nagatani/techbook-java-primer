# 第2章 Java基本文法 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter02-getting-started.md` を参照する。

## 章の概要

- C言語との比較を軸に、プリミティブ型、変数、演算子、型変換、コンソール入出力、制御構造、配列、staticメソッド、文字列（String・StringBuilder）、import文を一通り扱う
- 型選択は「整数はint、小数はdouble」を基本とし、8型の仕様表は参考として示す
- staticメソッドに限定してメソッドを教え、インスタンスメソッドとコンストラクターは第3章以降へ送る
- 前提は第1章とC言語の変数・条件分岐・ループ・関数。入出力の基本は第1章で学んだものとして、この章では補足に絞る（2026-11-11〜）
- Javaコードブロックの大半は短い断片。2026-11-11に番号を振り直した（2-1〜2-47）

## 節ごとの要約

- 本章の学習目標（L3–23）
    + データ型と変数、演算子と制御構造、配列とメソッド、文字列処理とコンソール入出力の4項目。前提は第1章とC言語の基礎
- 基本データ型（L24–124）
    + 初学者はint・double・boolean・charの4型で足りるとし、intとdoubleが基本である理由、ほかの型を使う場面（2-1）を説明
    + 浮動小数点の丸め誤差（0.1を10回足す例）とBigDecimal・BigIntegerに触れ、第6章の節「数値の正確な計算（BigDecimal）」へ誘導する
    + 8型の仕様表（サイズ、範囲、デフォルト値。最初に覚える4型は型名を太字）とC言語との違い（サイズ固定、16ビットでUnicodeの文字を表すchar、整数と相互に変換できないboolean型（C99の`_Bool`・C23の`bool`に触れる）、デフォルト値はフィールドと配列の要素に限る）
- 変数の宣言と初期化（L125–288）
    + 宣言と初期化（型を書く。`var`は脚注で第10章へ誘導。C言語と違い、代入前のローカル変数を使うとコンパイルエラー）、finalによる定数。命名規則（単独の`_`はJava 9以降で予約語）とcamelCase
    + 日本語変数名のメリット・デメリット（テストメソッド名の脚注あり）
    + 単行・複数行・JavaDocコメント（第22章を脚注で参照）
    + セミコロンが必要な場所と不要な場所（2-9 Sample.java）
- 演算子（L289–401）
    + C言語との違いとして、論理演算子や条件式にboolean型しか使えないことと、文字列連結の`+`（演算子オーバーロードは不可、と脚注）を挙げる
    + 算術、インクリメント、比較、論理（短絡評価はC言語と同じ）、ビット演算を丸数字で解説（2-10）
    + 優先順位の表と実例（`x = 3 > 0`が`x = (3 > 0)`と解釈されてコンパイルエラーになる理由とC言語では通ること、2-11）。括弧の使用を推奨（括弧で実行速度は変わらない）
- 型変換（L402–547）
    + 拡大変換と縮小変換、C言語ではコンパイルが通る（gccの既定では警告も出ない）小数部を失う変換がJavaではエラーになる点（2-12）
    + TypeConversionExample（2-13）: 暗黙・明示の変換、byteへのオーバーフロー、parseIntとvalueOfで変換した値に`+`を使うと足し算と連結になる違い。NumberFormatExceptionは第1章のコラムと本章の「入出力のベストプラクティス」へ誘導（2026-11-11）
    + 整数除算の落とし穴（2-14）、byte配列によるメモリ効率（2-15）、APIが要求する型（2-16 Math.sqrt・Math.round）、ベストプラクティス4点
- コンソール入出力（L548–728）
    + 冒頭で、基本は第1章で学んだとし、書式・変換・入力の終わりを補うと位置づける（2026-11-11）
    + 標準出力・標準入力・標準エラー出力とIOクラスの対応（System.errだけはIOにない）、型安全性と国際化。Cのprintf/scanfとの比較（2-17）
    + IOExample（2-18）: formattedの書式（%.2f、%-10s、%10s）と、IO.readlnとparseIntによる入力。整数以外を入れると止まり、やり直しはベストプラクティスで扱うと案内
    + 入力した文字列の変換: parseInt・parseDouble・parseBoolean・split（2-19）。Scannerは第14章へ
    + 入出力のベストプラクティス: 誤った入力への対処として、変換できるまで繰り返すSafeInputExample（2-20、try-catchとフラグ変数。実行結果あり）、IO.readlnが入力の終わり（Ctrl+D、WindowsはCtrl+Zの後にEnter）でnullを返すこと（2-21）、1行単位の読み取り、ロケール（formattedはOSのロケールに従い、ドイツ語の設定では`3,14`になる。`String.format(Locale.US, ...)`で指定でき、Localeにはimportが要ると脚注）
- 制御構造（L729–886）
    + 条件分岐: if-else ifの成績判定（2-22）
    + switch文とswitch式: 従来形式の成績評価（2-23 SwitchExample）と注意点（C言語と違い文字列でも分岐できる）、同じ判定のswitch式（2-24、Java 14以降）とその利点。caseに型と条件（`when`）も書けることを脚注で示し、第8章へ誘導する
    + 繰り返し処理: for、拡張for、while（2-25）と使い分け、ループ変数のスコープ（for文の初期化部の変数はループ内だけで有効。C99でも同じと補う）。do-while、break・continueは扱わない
- 配列（L887–1031）
    + リテラルとnewによる初期化、length、多次元配列（2-26）、境界チェックと自動初期化（2-27）
    + インデックスと拡張forによる走査、C言語との違い（length、境界チェック、メモリ管理、初期化保証）
    + 合計（2-28）とコピー（2-29、System.arraycopy・Arrays.copyOf）、サイズ固定（ArrayListは後の章）、参照の代入（2-30）、ジャグ配列（2-31）
- メソッド（staticメソッドの基本）（L1032–1122）
    + addとdivideを持つCalculator（2-32）、staticメソッドの構文と構成要素（2-33）
    + mainから直接呼べる理由、再利用と構造化、C言語の関数との違い。インスタンスメソッドとコンストラクターは第3章以降と案内
- 文字列処理（L1123–1389）
    + C言語のchar配列とnull終端に対する、Stringの安全性・長さによらず一定の時間で返るlength・Unicodeを比較表とコード対比で示す（2-34〜2-41）
    + リテラルと文字列プール、`==`とequals、equalsIgnoreCase（2-42〜2-43）。リテラルどうしの`==`がtrueになるのは同じオブジェクトを共有するためで、入力や実行中に組み立てた文字列では成り立たないと説明
    + trim、toUpperCase、substring、replace、split、indexOf、contains（2-44）
    + 不変性（concatで元の文字列は変わらない、2-45）と、ループ内連結にはStringBuilderを使う理由（2-46。`+`は毎回全体をコピーし、1000回で約50万文字。StringBuilderは内部の配列を広げるときだけコピー）
- import文の使い方（L1390–1442）
    + パッケージに分かれた標準ライブラリと、java.lang以外のクラスにimportが要ることを説明（2026-11-11）
    + java.util.Arraysをimportし、IO.readlnで読んだ整数を並べ替える例（2-47）とコードのポイント。パッケージのしくみは第4章へ誘導
- よくあるコンパイルエラーとその対処法（L1443–1459）
    + 本文には出会いやすいエラーと原因の要点のリストとGitHubのURL（`appendix/e-common-errors/chapters/chapter02.md`）だけを残す
    + 本文に挙げるエラー: セミコロン忘れ、大文字・小文字の間違い（「シンボルを見つけられません」）。クラス名とファイル名の不一致などの手順のエラーは第1章へ委ねる（2026-11-11）
- まとめ（L1460–1477）
    + 型安全性（静的型付け）、メソッドによる構造化、文字列処理の安全性の3点を挙げる
