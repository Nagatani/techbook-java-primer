# 第2章 Java基本文法 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter02-getting-started.md` を参照する。

## 章の概要

- C言語との比較を軸に、プリミティブ型、変数、演算子、型変換、コンソール入出力、制御構造、配列、staticメソッド、文字列（String・StringBuilder）、import文を一通り扱う
- 型選択は「整数はint、小数はdouble」を基本とし、8型の仕様表は参考として示す
- staticメソッドに限定してメソッドを教え、インスタンスメソッドとコンストラクタは次章以降へ送る
- 前提は第1章とC言語の変数・条件分岐・ループ・関数
- サンプルコード番号は6つ（2-1〜2-6）だけで、Javaコードブロックの大半（50近く）は番号なしの断片になっている

## 構成上の問題

- switchの説明が章内で3回出てくる
    + 「条件分岐」でif文と並べてswitch式を示し（L719–725）、続けて従来のswitch文と新しいswitch式を比較し（L736–776）、さらに独立した「switch文」の節（L828–871、2-4）で従来形式を一から説明し直す
    + 2-4の節は、すでにアロー形式を紹介したあとで「breakを忘れると次のcaseも実行される」と基礎から説明しており、旧版の節が残ったものと考えられる
- まとめ相当の節が3つある
    + 「Javaのメソッドの基本まとめ」（L1082–1087）、「Java基本文法の総合的な理解」（L1393–1407）、その中の「まとめ」（L1408–1421）
    + 「総合的な理解」は Spring Boot、Servlet/JSP、マイクロサービスに言及しており、本書の範囲外
- 学習目標と「章の構成」がほぼ同じ内容の繰り返し
    + 学習目標の L11 は、L8–10 の3項目を1行に連結した重複
- 説明前の先取り
    + import文の節（L1289）より前の 2-3（L549）で import を使っている
    + 例外処理（try-catch、try-with-resources）を 2-2・2-3・入出力のベストプラクティスで説明なしに使っている（第13章の内容）
    + 型変換の「APIとの整合性」で`Collections.shuffle(list, …)`を使っている（第9章の内容。listも未定義）
- 章末演習と本文の不一致
    + MethodExerciseでメソッドのオーバーロード、StringExerciseでパターンマッチングを求めるが、本文で扱っていない
    + 「つまずきポイント」の表に、まだ学んでいないコンストラクタやNullPointerExceptionが並ぶ
    + 本文の課題名（ControlFlowExercise、ArrayExercise、MethodExercise、StringExercise）が`exercises/chapter02/`の実ファイル（basic/Person.java・PersonTest.java、advanced/GradeManagement.java・LibraryManagement.java）と一致しない。リンク自体は正しい番号を指している

## 節ごとの要約

- 本章の学習目標（L3–24）
    + データ型と変数、演算子と制御構造、配列とメソッド、文字列処理とコンソール入出力の4項目。前提は第1章とC言語の基礎
- 章の構成（L25–49）
    + 本文の9つの節を順に列挙する。import文、コンパイルエラー、総合的な理解は含まない
- 基本データ型（L50–142）
    + 初学者はint・double・boolean・charの4型で足りるとし、intとdoubleが基本である理由、ほかの型を使う場面を説明
    + 浮動小数点の丸め誤差とBigDecimalに一言触れる
    + 8型の仕様表（サイズ、範囲、デフォルト値）とC言語との違い（サイズ固定、16ビットchar、boolean型、初期値）
- 変数の宣言と初期化（L143–287）
    + 宣言と初期化、finalによる定数。命名規則（単独の`_`はJava 9以降で予約語）とcamelCase
    + 日本語変数名のメリット・デメリット（テストメソッド名の脚注あり）
    + 単行・複数行・JavaDocコメント（第22章を脚注で参照）
    + セミコロンが必要な場所と不要な場所（2-1）
- 演算子（L288–388）
    + 算術、インクリメント、比較、論理（短絡評価）、ビット演算を丸数字で解説
    + 優先順位の表と実例（`x = 3 > 0`がコンパイルエラーになる例）。括弧の使用を推奨
- 型変換（L389–509）
    + 拡大変換と縮小変換、C言語では警告で済む変換がJavaではエラーになる点
    + 暗黙・明示の変換、byteへのオーバーフロー、parseIntとvalueOf、NumberFormatExceptionの捕捉（2-2）
    + 整数除算の落とし穴、byte配列によるメモリ効率、APIが要求する型、ベストプラクティス4点
- コンソール入出力（L510–696）
    + System.out・in・err、Scannerの型別入力、国際化の特徴。Cのprintf/scanfとの比較
    + println・print・printfの書式（%-10sなど）と、InputMismatchExceptionで再入力させるScannerの例（2-3）
    + nextInt・nextDouble・next・nextLine、hasNextIntによる検証、useDelimiter
    + ベストプラクティスとしてエラー処理、try-with-resources、nextInt後の改行の残り、ロケール
- 制御構造（L697–881）
    + 条件分岐: if-else ifの成績判定とswitch式、従来のswitch文との比較（fall-throughの解消、式として使える）
    + 繰り返し処理: for、拡張for、whileと使い分け、ループ変数のスコープ。do-while、break・continueは扱わない
    + switch文: 従来形式の成績評価（2-4）と注意点3つ
- 配列（L882–1008）
    + リテラルとnewによる初期化、length、多次元配列、境界チェックと自動初期化
    + インデックスと拡張forによる走査、C言語との違い（length、境界チェック、メモリ管理、初期化保証）
    + 検索・合計・コピー（System.arraycopy、Arrays.copyOf）の応用例、サイズ固定（ArrayListは後の章）、参照の代入、ジャグ配列
- メソッド（staticメソッドの基本）（L1009–1096）
    + addとdivideを持つCalculator（2-5）、staticメソッドの構文と構成要素
    + mainから直接呼べる理由、再利用と構造化、C言語の関数との違い
- 文字列処理（L1097–1297）
    + C言語のchar配列とnull終端に対する、Stringの安全性・O(1)のlength・Unicodeを比較表とコード対比で示す
    + リテラルと文字列プール、`==`とequals、equalsIgnoreCase
    + trim、toUpperCase、substring、replace、split、indexOf、contains
    + 不変性（concatで元の文字列は変わらない）と、ループ内連結にはStringBuilderを使う理由
- import文の使い方（L1298–1355）
    + Scannerでの入力と整数変換（2-6）とコードのポイント5項目。java.langは自動インポート
- よくあるコンパイルエラーとその対処法（L1356–1401）
    + セミコロン忘れ、大文字小文字の誤り（system）、クラス名とファイル名の不一致の3種
- Java基本文法の総合的な理解（L1402–1443）
    + 安全性・保守性・可読性という3原則で章を総括し、Spring Bootなど実務への接続を述べる
    + 「まとめ」で型安全性、メソッドによる構造化、文字列処理の安全性の3点を挙げる。末尾に空行が10行続く
- 章末演習（L1444–1556）
    + 演習リンクは`exercises/chapter02/`で正しい
    + 課題の実装ポイント（データ型、変数、制御構造、配列）、発展課題（メソッド、文字列）、つまずき表、デバッグのコツ、追加課題
    + 次のステップとして第3章を案内

## 他章との関係

- 第1章との重複
    + 2-6は1-6とプロンプト文以外ほぼ同一で、「このコードのポイント」とjava.langの説明も同文
    + println・print・printfの説明、コンパイルエラー3種（第1章「よくあるエラー」と章末のトラブル表）が重なる
- 第3章・第4章: staticでないメソッドにはインスタンス化が必要と予告する。L1086 は「次章でインスタンスメソッドやコンストラクタを学ぶ」とするが、それらは第4章の内容
- 第6章（不変性とfinal）: finalによる定数とStringの不変性を先取りしている
- 第9章（コレクション）: ArrayListを後の章として予告し、Collections.shuffleを使っている
- 第13章（例外処理）: try-catch、InputMismatchException、try-with-resourcesを先取りしている。章参照はない
- 第22章（ドキュメントと外部ライブラリ）: JavaDocの詳細を脚注で参照
