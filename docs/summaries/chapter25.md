# 第25章 統合プロジェクトの設計 要約

行番号・サンプルコード番号の正確な対応は `docs/book-index/chapter25-integrated-project-design.md` を参照する。

## 章の概要

- 2026-11-16に、付録Dの「統合プロジェクト」を本文へ移して新設した章（著者の指示）。第26章と2章で1組
- 旧付録Dのコード（現在は`sample-code/integrated-project/`）の6フェーズの初版を題材に、初版に残る設計の問題を事例として取り上げ、選択肢・判断・理由を示す。改善版のコードは見本で、アプリケーション全体の書き換えは演習の課題
- 改善版のサンプル（25-1〜25-4）は、sealedインターフェイスの在籍区分、Transcriptへの合成、単位数で重み付けしたGPA、StudentRepositoryインターフェイスとLinkedHashMapの実装、CSVの取り込み結果のRecord。全文は`sample-code/chapter25/`。第26章のサンプルも同じモデルのクラスを複製して使う

## 節ごとの要約

- 本章の学習目標（L3–36）
    + 7項目。完成品ではなく選ぶ過程を示すと断る。前提は第3〜5・7・8・9・12・13・21章
- 統合プロジェクトの全体像（L37–87）
    + 題材と完成時の機能、6フェーズと章の対応表（フェーズ6は第24章のH2ではなくSQLiteに保存し、理由は第26章で扱うと断る）、コードの場所（`sample-code/integrated-project/`、脚注でURL）、初版を事例にすること、第26章との分担
- 要求を整理する（L88–164）
    + ユーザーストーリー5つ、機能要求と非機能要求（数百〜数千人、1人で使う、3つのOS、サーバーなし、コピーで配布）、作らないもの、GPAの定義の曖昧さ（単純平均3.50と単位数で重み付け3.33）
- 設計判断を記録する（L165–209）
    + ADR（Nygard 2011）を5項目（状況・選択肢・決定・理由・影響）で書く。GPAの判断の例
- 事例1：クラスの候補を見つけて責務を割り当てる（L210–243）
    + 名詞と動詞から候補を拾う。情報エキスパート（GRASP、脚注で付録Cへ）
- 事例2：継承か合成か（L244–379）
    + 初版の階層の図、問題が表に出るのはフェーズ3以降（初版はフェーズ3の`StudentService`から扱う対象を`GradeableStudent`に限定し、フェーズ5の画面とフェーズ6のデータベースもそれに合わせたため、大学院生は画面から登録できず保存もできない）、独立した性質の組み合わせ爆発、is-a/has-aと3つの問い、合成の図とサンプルコード25-1、継承が向く場面。GoF本は脚注
- 事例3：計算で求められる値を保存するか（L380–473）
    + 初版のgpaが3か所にありsetGpaで食い違う。サンプルコード25-2（Gradeの検査、Transcript.gpa）。年齢も保存しない（脚注で第6章の`LocalDate`と`Period`へ）。保存してよい場合（重い計算、卒業時のGPA、ほかのツールが読む）
- 事例4：層に分けて依存の向きを決める（L474–579）
    + 初版の4層、フェーズ6の二重管理と元に戻す処理、層構造の図、サンプルコード25-3（インターフェイスと依存性の注入（DI）、第21章へ）、MapとListの二重管理からLinkedHashMapへ（キーで引く処理も削除も平均O(1)。第9章の「コレクションの選択指針」）
- 事例5：例外をどこで投げ、どこで受け止めるか（L580–693）
    + 利用者が直せる誤り・プログラムの誤り・環境の異常の3分類と例外の種類の表、サンプルコード25-4（失敗した行と理由を集める）。行の内容の誤りは利用者が直せる誤りだが、`parse`が非検査例外の`IllegalArgumentException`を投げ、同じクラスの`importLines`ですぐ`ImportError`に変えるので検査例外にしない理由を説明する。受け止める場所は画面
- 段階的に作る計画を立てる（L694–722）
    + 層ごとと機能ごと（縦）の切り方、確認のプログラムを残しJUnitへ（フェーズ6には`Phase6Test`のほか`StudentTest`と`Phase2Test`〜`Phase4Test`が残る）
- 設計でよくある失敗（L723–739）
    + 6項目。付録E（`appendix/e-common-errors/`）には対応する章のファイルがない（設計の章なので本文に置いた）
- まとめ（L740–766）・章末演習（L767–784）
    + 演習は`exercises/chapter25/`（図書貸し出しの要求とADR、成績の訂正の履歴、フェーズ3のリポジトリのインターフェイス化、フェーズ6の大学院生の成績。チャレンジは方針だけでコードの解答例なし）
