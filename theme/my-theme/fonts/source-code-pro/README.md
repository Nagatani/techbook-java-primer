# Source Code Pro

本書のコードの書体です。SIL Open Font License 1.1（`OFL.txt`）で配布されています。

- 入手元: npmの`@fontsource/source-code-pro@5.3.0`（太さごとの静的なフォント）。latinとlatin-extの400・700だけを置いている
- Google Fontsが配る可変フォントは、ChromeがPDFにType3として埋め込み、文字の検索や取り出しがうまくいかないため、静的なフォントを同梱する（2026-11-24）
- 英数字の幅は0.6字（Monacoと同じ）。コードを紙面の幅（73桁）に収める調整は、この幅を前提にしている
