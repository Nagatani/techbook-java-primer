# 付録D: 統合プロジェクト - 学生管理システム

本付録では、これまでに学んだ複数の技術を統合した実践的なプロジェクトとして「学生管理システム」を段階的に構築していきます。各段階で新しい技術を追加し、システムを発展させていく過程を通じて、実践的なアプリケーション開発の流れを学びます。

## プロジェクト概要

学生管理システムは、教育機関で学生情報を管理するためのアプリケーションです。基本的なデータ管理から始めて、最終的にはGUIを持ち、データベースにデータを保存するアプリケーションへと発展させます。

### 完成時の機能
- 学生の登録・削除
- 成績の追加・削除とGPAの計算
- 氏名・学生IDによる検索と、学部による絞り込み
- データの永続化（SQLiteデータベース）
- グラフィカルユーザーインターフェイス（Swing）
- CSVファイルのインポート・エクスポート

登録した学生の氏名・年齢・学部を変更する機能はありません。発展課題として追加してみてください。

## プロジェクト構成

各フェーズのディレクトリには、そのフェーズで動かすのに必要なJavaファイルがすべて含まれています。
前のフェーズのファイルも複製して入れてあるので、各フェーズのディレクトリだけでコンパイル・実行できます。

### フェーズ1: 基本的なクラス設計（第3-4章）
- `phase1/`: 基本的なStudentクラスと動作確認用のプログラム
- 学習内容：カプセル化、getter/setter、データ検証

### フェーズ2: 継承とポリモーフィズム（第5-7章）
- `phase2/`: 抽象クラス、継承、インターフェイスの実装
- 学習内容：継承階層の設計、ポリモーフィズムの活用

### フェーズ3: コレクション、ジェネリクス、ラムダ式、Stream API（第9-12章）
- `phase3/`: StudentRepositoryとStudentServiceクラス
- 学習内容：ジェネリクス、Stream API、コレクション操作

### フェーズ4: 例外処理とファイル入出力（第13-14章）
- `phase4/`: 独自の例外クラスとエラー処理、CSVファイルの読み書き
- 学習内容：例外の設計、ロギング、1行ごとのエラーを記録して処理を続ける方法

### フェーズ5: GUI実装（第17-20章）
- `phase5/`: Swingを使用したGUIアプリケーション
- 学習内容：イベント駆動プログラミング、JTableによる一覧表示、画面とサービス層（StudentService）の分離
- 学生追加の画面で使う`GridBagLayout`と`JDialog`は本文では扱っていません。Javaの公式ドキュメント（APIリファレンス）で確かめてください

### フェーズ6: データベース統合（付録E）
- `phase6/`: JDBCを使用したデータの永続化
- 学習内容：データベース接続、SQL、トランザクション管理
- 付録EはH2で例を動かしますが、このフェーズはサーバーを用意しなくてよい組み込み型のデータベースSQLiteを使います。JDBCの使い方は同じです

## 実行方法

各フェーズのディレクトリで以下のコマンドを実行してください。Java 25でコンパイル・実行できます。

```bash
# コンパイル
javac *.java

# 実行（フェーズ1の例）
java StudentTest

# GUIアプリケーション（フェーズ5）の実行
java StudentManagementGUI
```

フェーズ6はSQLiteのJDBCドライバーが必要です。手順は`phase6/README.md`を見てください。

## 段階的な学習アプローチ

1. フェーズ1から順番に実装する
    + 各フェーズのコードを理解し、実行してみる
2. コードを拡張する
    + 各フェーズのコードに機能を追加してみる
3. 統合する
    + 全フェーズを統合した完全なアプリケーションを構築する

## 発展課題

このプロジェクトをさらに発展させるためのアイデアは次のとおりです。

1. 学生情報の編集
    + 氏名・年齢・学部を変更する画面を追加する
2. 大学院生の管理
    + `GraduateStudent`を成績管理やデータベースの保存に対応させる
3. Web化
    + Spring Bootを使ってWebアプリケーションに変換する
4. セキュリティ
    + 認証・認可機能を追加する
5. レポート機能
    + PDFやExcel形式でのレポートを生成する
6. 国際化
    + 多言語に対応する
