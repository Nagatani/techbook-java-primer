# フェーズ5: GUI実装

このフェーズでは、Swingを使用してグラフィカルユーザーインターフェイスを実装します。
データはメモリ上にだけ保存するので、終了すると消えます（保存はフェーズ6で扱います）。

## 実行方法

```bash
# コンパイル
javac *.java

# 実行
java StudentManagementGUI
```

起動すると、サンプルの学生が3人登録された状態で始まります。

## 学習ポイント

- Swingコンポーネントの使用（第17章）
- イベント駆動プログラミング（第18-19章）
- JTableによる一覧表示（第20章）
- 画面（StudentManagementGUI）と処理（StudentService）の分離
- ダイアログとユーザー入力の処理

## ファイル構成

- `StudentManagementGUI.java`: メインウィンドウ
- `GradeManagementDialog.java`: 成績管理ダイアログ
- `StudentService.java`: フェーズ4のサービスクラスに、学生と成績の削除を追加したもの
- `GradeableStudent.java`: 成績の削除（`removeGrade`）を追加したもの
- フェーズ4までのファイルも複製して含めている

## 機能

- 学生一覧の表示
- 学生の追加（学部は一覧から選ぶか、新しい名前を入力する）
- 学生の削除
- 成績の管理（「成績管理」ボタンか、一覧の行をダブルクリックして開く。成績の追加・削除）
- 氏名・学生IDによる検索と、学部による絞り込み（2つの条件を組み合わせて絞り込む）
- CSVファイル（UTF-8）のインポート・エクスポート（インポートの後に成功とエラーの件数を表示する）

登録した学生の氏名・年齢・学部を変更する機能はありません。
