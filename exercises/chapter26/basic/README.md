# 第26章 基礎課題 - 技術選定と実装

## 課題概要

第26章の「評価の観点と確かめ方」に沿ってライブラリを実際に調べ、比べる練習をします。
あわせて、本章で選んだApache Commons CSVを使い、成績のCSVを読むクラスを作ります。

このフォルダーには解答例を置いていません。解答例は[solutions/](../solutions/)にあります。

## 課題1: JSONを読み書きするライブラリを比べる

学生管理システムに「学生と成績をJSONファイルに書き出し、別のパソコンで読み込む」機能を加えることになりました。
JSONを読み書きするライブラリとして、Gson（第22章）とJackson（第22章）を比べ、どちらを使うかを決めてください。

**要件:**

- 第26章の表の観点（目的に合うか・保守・ライセンス・推移的な依存・大きさ・Javaの版・取り替えやすさ）ごとに、両者を調べて表にする
- それぞれの値を、どこで確かめたか（Maven Centralのページ、pom.xmlなど）と、調べた日付を書く
- 第25章の設計判断記録の形式で、どちらを選ぶかを書く。「影響」の欄も書く

**ヒント:**

- Maven Centralの`https://repo1.maven.org/maven2/`の下で、グループIDの`.`を`/`に置き換えたディレクトリをたどると、版の一覧・公開日・pom.xml・JARファイルの大きさがわかる
- Jacksonには、版2（グループID`com.fasterxml.jackson.core`）と版3（グループID`tools.jackson.core`）がある。どちらを候補にするかも検討する

## 課題2: 成績のCSVを読み込む

次の形式の成績のCSVを読み、学生IDと`Grade`（サンプルコード25-2）の組のリストにするクラス`GradeCsvReader`を作ってください。

```
学生ID,科目,単位数,評価点
S001,線形代数,4,3.0
S001,"情報科学演習Ⅰ,Ⅱ",2,4.0
```

**要件:**

- Apache Commons CSV（サンプルコード26-3）を使う。Commons CSVのクラスを使うのは`GradeCsvReader`だけにする
- 先頭のBOMを取り除き、引用符で囲んだ項目（カンマを含む科目名）を正しく読む
- 見出しに4つの列がそろっていなければ、`IOException`を投げる
- 列の数が足りない行、数値でない単位数・評価点、範囲外の評価点は、その行だけを誤りとして記録し、残りの行を読み続ける。誤りには行の番号と理由を含める
- 読めた成績と誤りの一覧を、自分で定義したRecordで返す
- 動作を確かめるプログラム`GradeCsvCheck`を作る

**実行例:**

```
S001 線形代数 4単位 3.0
S001 情報科学演習Ⅰ,Ⅱ 2単位 4.0
行4: 評価点は0.0〜4.0にします: 4.5
行5: 単位数または評価点が数値ではありません
行6: 列の数が見出しと合いません（2列）
すべての確認に成功しました
```
