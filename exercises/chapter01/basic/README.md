# 第1章 基本課題

## 学習目標
- クラスと`main`メソッドを持つプログラムを書き、コンパイル・実行する
- `IO.println`・`IO.print`・引数なしの`IO.println()`を使い分ける
- `IO.readln`でキーボードから1行を読む
- `Integer.parseInt`で文字列を整数に変換し、`formatted`で書式を指定して表示する

## 課題一覧

### 課題1: Hello World の拡張
**ファイル名**: `Exercise01_HelloWorld.java`

自分の名前と現在の年を表示するプログラムを作成してください。

**実行例**:
```
こんにちは！私の名前は田中太郎です。
今年は2026年です。
Java学習を開始します！
```

**実装のポイント**:
- クラス名とファイル名を一致させる
- `main`メソッドのシグネチャ（`public static void main(String[] args)`）を正確に書く
- `IO.println()`で文字列を出力する

### 課題2: IO.printとIO.printlnで名刺を表示する
**ファイル名**: `Exercise02_BusinessCard.java`

`IO.print`、`IO.println`、引数なしの`IO.println()`を使い分けて、名刺のような表示を作成してください。

**実行例**:
```
==============================
情報学部 1年
氏名: 田中太郎

好きなこと: プログラミング
==============================
```

**実装のポイント**:
- 「氏名: 」は`IO.print`、名前は`IO.println`で出力し、1行にまとめる
- 空行は引数なしの`IO.println()`で出力する
- 最後の線は`IO.print`と文字列の中の`\n`で改行する

### 課題3: キーボードから名前を読んであいさつする
**ファイル名**: `Exercise03_Greeting.java`

`IO.readln`で名前と出身地を入力してもらい、あいさつを表示するプログラムを作成してください。

**実行例**（「田中太郎」「北海道」と入力した場合）:
```
お名前を入力: 田中太郎
出身地を入力: 北海道
こんにちは、田中太郎さん。
北海道の出身なのですね。Javaの学習を一緒に始めましょう。
```

**実装のポイント**:
- `String name = IO.readln("お名前を入力: ");`のように、読んだ文字列を変数で受け取る
- 文字列どうしは`+`でつなぐ

### 課題4: 入力した数で計算する
**ファイル名**: `Exercise04_PriceCalculation.java`

商品1個の値段を整数で入力してもらい、3個分と5個分の金額を表示するプログラムを作成してください。

**実行例**（「120」と入力した場合）:
```
1個の値段を入力: 120
1個120円の商品を3個買うと360円です
1個120円の商品を5個買うと600円です
```

**実装のポイント**:
- `IO.readln`の戻り値は文字列なので、`Integer.parseInt`で整数に変換してから計算する
- `"1個%d円の商品を3個買うと%d円です".formatted(price, price * 3)`のように書式を指定する
- 数字以外を入力すると`NumberFormatException`で止まるが、この課題では気にしなくてよい

## よくある間違い

1. セミコロン忘れ
    - Javaの文の最後にはセミコロンが必要
2. 大文字・小文字の間違い
    - `io.println`ではなく`IO.println`
3. クラス名とファイル名の不一致
    - `Exercise01_HelloWorld.java`には`public class Exercise01_HelloWorld`を書く
4. 文字列と文字
    - 文字列は`""`で囲む（`''`は1文字用）
5. 入力した文字列をそのまま計算する
    - `input * 3`はコンパイルエラー、`input + 3`は文字列の連結になる
