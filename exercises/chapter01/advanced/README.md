# 第1章 発展課題

## 学習目標
- 複数の入力を順に受け取り、組み合わせて表示する
- 書式指定子（`%s`、`%d`、幅を指定した`%5d`）で見やすい出力を作る
- 入力した文字列を整数に変換して計算する

## 課題一覧

### 課題1: プロフィールカード
**ファイル名**: `ProfileCard.java`

名前・学年・趣味をキーボードから入力してもらい、枠で囲んだプロフィールカードを表示してください。

**要求仕様**:
- `IO.readln`で名前、学年（整数）、趣味の3つを読む
- 学年は`Integer.parseInt`で整数に変換し、1を足した「来年の学年」も表示する
- 各行は`formatted`と`%s`・`%d`で組み立てる

**実行例**（「田中太郎」「1」「読書」と入力した場合）:
```
名前を入力: 田中太郎
学年を入力: 1
趣味を入力: 読書

+------------------------------+
| 名前: 田中太郎
| 学年: 1年生（来年は2年生）
| 趣味: 読書
+------------------------------+
```

### 課題2: レシート
**ファイル名**: `ShoppingReceipt.java`

商品名・値段・個数を入力してもらい、レシートの形で表示してください。

**要求仕様**:
- `IO.readln`で商品名、値段（整数）、個数（整数）を読む
- 小計（値段 × 個数）を計算する
- `%5d`のように幅を指定して、金額の桁をそろえる

**実行例**（「ノート」「150」「4」と入力した場合）:
```
商品名を入力: ノート
値段を入力: 150
個数を入力: 4

===== レシート =====
商品: ノート
単価:   150円
個数:     4個
小計:   600円
====================
```

## ヒント

- `IO.readln`の結果をそのまま`Integer.parseInt(IO.readln("学年を入力: "))`のように変換してもよい
- `%5d`は5文字分の幅で右詰めに表示する（C言語のprintfと同じ）
- 入力と表示の間に空行を入れるには、引数なしの`IO.println()`を使う
