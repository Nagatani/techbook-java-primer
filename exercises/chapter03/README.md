# 第3章 オブジェクト指向の考え方 - 演習課題

## 概要
このディレクトリは第3章「オブジェクト指向の考え方」の演習課題です。クラスの設計、オブジェクトの生成、メソッドの実装など、オブジェクト指向プログラミングの基本概念を実践的に学習します。

## 学習目標
- クラスとオブジェクトの関係を理解する
- インスタンス変数とインスタンスメソッドを実装できる
- コンストラクタの役割と実装方法を習得する
- カプセル化の原則を理解し実践する
- getter/setterメソッドを適切に実装できる

## 課題構成

### 基礎課題 (basic/)
1. **Person.java** - 人を表すクラス（フィールドとメソッド）
   - 自己紹介、誕生日の処理
2. **Book.java** - 本を表すクラス
   - 情報の表示、税込価格の計算、価格の比較
3. **Circle.java** - 円を表すクラス
   - 面積・円周の計算
4. **Student.java** - 学生情報管理クラス
   - 複数のコンストラクタ
5. **Rectangle.java** - 長方形クラスの実装
   - 面積・周長計算、サイズ変更機能（オーバーロード）
6. **BankAccount.java** - 銀行口座クラスの実装
   - 残高管理、入出金機能、残高照会
7. **Time.java** - 時刻管理クラス
   - 時刻の加算、表示形式の変換

### 発展課題 (advanced/)
1. **LibraryManagement.java** - 図書管理システム（BookクラスとLibraryクラスの連携）
2. **GradeManagement.java** - 成績管理プログラム（StudentクラスとGradeBookクラスの連携）

### チャレンジ課題 (challenge/)
- 準備中

### 解答例 (solutions/)
- 基礎課題1〜7の解答例
- 発展課題は、`advanced/`のJavaファイルが完成したプログラム（解答例）


- [ ] 適切なアクセス修飾子を使用している

## ヒント
- インスタンス変数は`private`で宣言しましょう
- publicメソッドを通じてのみアクセスを許可します
- コンストラクタ内で妥当性検証を行いましょう
- `toString()`メソッドをオーバーライドすると便利です
- 単体テストを書いて動作を確認しましょう
