## 実装のヒント

### 課題1のヒント
```java
class Library {
    private Book[] books;
    private int count; // 登録した冊数

    public void addBook(Book book) {
        if (count >= books.length) {
            return; // これ以上は登録できない
        }
        books[count] = book;
        count++;
    }
}
```
- 配列の要素を調べるループは`i < count`までにする（それより後ろは`null`）

### 課題2のヒント
```java
public double getAverage() {
    int sum = 0;
    for (int score : scores) {
        sum += score;
    }
    return (double) sum / scores.length;
}
```
- 評価を求める処理は、どの学生にも共通なのでstaticメソッドにしてもよい
