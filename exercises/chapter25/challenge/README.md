# 第25章 チャレンジ課題 - 学生の情報を変更する機能を加える

## 課題概要

付録Dのフェーズ6（`appendix/d-integrated-project/phase6/`）のアプリケーションには、登録した学生の氏名・年齢・学部を変更する機能がありません。
第24章では、これを「この版では作らないもの」として決めていました。
利用者から要望が出たという想定で、この機能を加えてください。

## 要件

- 一覧で選んだ学生の氏名・年齢・学部を、ダイアログで変更できる（学生IDは変更できない）
- 入力に誤りがあれば（空の氏名、数値でない年齢など）、理由を表示して入力し直してもらう
- 変更はデータベースに保存し、次に起動したときも残る
- 保存に失敗したら、画面の表示とデータベースの内容が食い違わないようにする
- 加える前に、変更の範囲（どのクラスの何を変えるか）を書き出し、第25章の「初版から改善版へ移す」のように小さな手順に分けて進める
- 振り返りとして、第25章の「振り返りの観点」で、この機能を加えたときに直した箇所の数と、変えにくかった点を書く

## 進め方のヒント

- フェーズ6の`StudentService`は、メモリとデータベースの両方を更新し、失敗したらメモリを元に戻す。変更の機能でも同じ形で書くか、第24・25章の改善版のようにデータベースだけを保存先にするかを、先に決める
- 画面のダイアログは、学生の追加のダイアログ（`StudentManagementGUI`の`showAddStudentDialog`）が参考になる
- 学部を変えると、学部の絞り込みの一覧も変わる

## 解答例について

この課題には、コードの解答例を用意していません。
解答の方針と、変更するファイルの一覧を`solutions/challenge-guide.md`に書いています。
