# 第2章 基本課題

## 学習目標
- 変数の宣言と初期化、データ型の使い分け
- 算術演算子と整数除算・余り
- 条件分岐（if、switch）と繰り返し（for、拡張for）
- 配列の作成と走査
- staticメソッドの定義と呼び出し
- Stringのメソッドと、StringBuilderによる文字列の組み立て

## 課題一覧

### 課題1: 変数を使った自己紹介
**ファイル名**: `Exercise01_SelfIntroduction.java`

変数を使って自己紹介プログラムを作成してください。

**要求仕様**:
- 名前（String型）
- 年齢（int型）
- 身長（double型）
- 好きな科目（String型）

**実行例**:
```
=== 自己紹介 ===
名前: 田中太郎
年齢: 20歳
身長: 170.5cm
好きな科目: 数学
```

**実装のポイント**:
- 文字列はString型、整数はint型、小数はdouble型で変数を宣言する
- 文字列と変数は`+`でつなぐ（`"名前: " + name`）

### 課題2: 基本計算プログラム
**ファイル名**: `Exercise02_BasicCalculation.java`

2つの整数を使って四則演算と余りの計算を行うプログラムを作成してください。

**要求仕様**:
- 2つの整数を変数に格納（例: 15と4）
- 加算、減算、乗算、除算、余りの計算
- 結果をわかりやすく表示

**実行例**:
```
=== 計算結果 ===
数値1: 15
数値2: 4

15 + 4 = 19
15 - 4 = 11
15 × 4 = 60
15 ÷ 4 = 3
15 % 4 = 3
```

**実装のポイント**:
- int型どうしの割り算は小数部が切り捨てられる（15 / 4 は 3、5 / 2 は 2）
- 小数の結果がほしいときは、どちらかをdouble型にする（`15.0 / 4`、`(double) a / b`）
- 文字列の中で計算するときは括弧で囲む（`"合計: " + (a + b)`）

### 課題3: データ型の理解
**ファイル名**: `Exercise03_DataTypes.java`

さまざまなデータ型を使った変数宣言と出力を行ってください。

**要求仕様**:
- byte, short, int, long型の数値
- float, double型の小数
- char型の文字
- boolean型の真偽値
- String型の文字列

**実行例**:
```
=== データ型の確認 ===
byte値: 100
short値: 30000
int値: 2000000
long値: 9000000000
float値: 3.14
double値: 3.141592653589793
char値: A
boolean値: true
String値: Hello Java!
```

**実装のポイント**:
- long型のリテラルには`L`を付ける（`9000000000L`）
- float型のリテラルには`f`を付ける（`3.14f`）。付けないとdouble型として扱われ、コンパイルエラーになる
- char型は単一引用符で1文字を囲む（`'A'`）
- boolean型は`true`か`false`

### 課題4: 条件分岐と繰り返し
**ファイル名**: `Exercise04_ControlFlow.java`

点数から成績を判定する処理と、1から15までの数を条件に応じて表示する処理（FizzBuzz）を作成してください。

**要求仕様**:
- 点数から、90点以上はA、80点以上はB、70点以上はC、60点以上はD、それ未満はFと判定する（if-else if）
- 判定した成績から、Aは「優秀」、BとCは「合格」、Dは「再確認」、Fは「不合格」というコメントを選ぶ（switch文またはswitch式）
- for文で1から15までの数を表示する。3の倍数は「Fizz」、5の倍数は「Buzz」、両方の倍数は「FizzBuzz」と表示する

**実行例**:
```
=== 成績判定 ===
85点: B（合格）
92点: A（優秀）
58点: F（不合格）

=== FizzBuzz ===
1
2
Fizz
4
Buzz
（中略）
14
FizzBuzz
```

**実装のポイント**:
- 範囲の判定は、大きい点数から順に調べる
- 倍数かどうかは余り（`%`）が0かどうかで調べる。両方の倍数を最初に調べる

### 課題5: 配列の操作
**ファイル名**: `Exercise05_Arrays.java`

5人分のテストの点数を配列に入れ、合計・平均・最高点・最低点と、平均点以上の人数を求めてください。

**実行例**:
```
=== 点数の集計 ===
点数: 78 92 65 88 71
人数: 5人
合計: 394点
平均: 78.8点
最高点: 92点
最低点: 65点
平均点以上: 2人
```

**実装のポイント**:
- 要素数は`scores.length`で求める
- 平均は`(double) sum / scores.length`のように小数の割り算にする
- 最高点・最低点は、最初の要素を仮の値にして残りと比べる
- 添字は0から`length - 1`まで（`i <= scores.length`は範囲外になる）

### 課題6: staticメソッドの定義
**ファイル名**: `Exercise06_StaticMethods.java`

次の3つのstaticメソッドを定義し、mainメソッドから呼び出してください。

**要求仕様**:
- `max(int a, int b)`: 大きいほうの値を返す
- `isEven(int n)`: 偶数なら`true`を返す
- `celsiusToFahrenheit(double celsius)`: 摂氏を華氏に変換して返す（華氏 = 摂氏 × 9 / 5 + 32）

**実行例**:
```
=== staticメソッドの練習 ===
max(12, 30) = 30
7は偶数か: false
10は偶数か: true
摂氏25.0度は華氏77.0度
```

**実装のポイント**:
- 戻り値の型、メソッド名、引数の型と名前を宣言する
- `9 / 5`は整数の割り算で1になるので、`9.0 / 5`と書く

### 課題7: 文字列の操作
**ファイル名**: `Exercise07_Strings.java`

キーボードから入力した英文を、Stringのメソッドを使って調べてください。

**要求仕様**:
- `IO.readln`で1行の英文を読み、前後の空白を`trim`で取り除く
- 文字数、大文字にした文字列、最初の単語を表示する
- 「Java」を含むかどうか、入力が「exit」かどうか（大文字・小文字を区別しない）を表示する
- StringBuilderで文字の並びを逆にした文字列を作って表示する

**実行例**（「 I like Java programming 」と入力した場合）:
```
英文を入力: I like Java programming
入力: I like Java programming
文字数: 23
大文字: I LIKE JAVA PROGRAMMING
最初の単語: I
Javaを含むか: true
exitか: false
逆順: gnimmargorp avaJ ekil I
```

**実装のポイント**:
- 文字列の比較には`==`ではなく`equals`・`equalsIgnoreCase`を使う
- 最初の単語は`indexOf(" ")`と`substring`で取り出す。空白がないと`indexOf`は-1を返す
- Stringは不変なので、`line.trim();`だけでは`line`は変わらない（`line = line.trim();`と書く）

## よくある間違い

1. セミコロン忘れ
2. 文字と文字列の混同（`char ch = "A";`はエラー）
3. 整数除算の誤解（`15 / 4`は3）
4. リテラルのサフィックス忘れ（`long big = 9000000000;`、`float f = 3.14;`はエラー）
5. 配列の範囲外の参照（`ArrayIndexOutOfBoundsException`）
6. 文字列を`==`で比べる
