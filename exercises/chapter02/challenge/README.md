## 課題一覧

### 課題1: 数当てゲーム
**ファイル名**: `NumberGuessingGame.java`（このフォルダーのファイルは解答例です）

コンピューターが選んだ数を、ヒントを頼りに当てるゲームを作成してください。

**要求仕様**:
- 難易度を3つから選ぶ（簡単: 1〜50で10回まで、普通: 1〜100で7回まで、難しい: 1〜200で5回まで）
- 選んだ範囲から数を1つランダムに選ぶ
- 入力した数が正解より小さいか大きいかを、残りの回数とともに表示する
- 当てたらスコア（残った回数が多いほど高い）を表示し、ベストスコアを更新する
- 1回のゲームが終わったら、続けて遊ぶかどうかを尋ねる
- 最後に、遊んだ回数・当てた回数・当てるまでの平均回数・ベストスコアを表示する
- 範囲外の数や数字以外が入力されたら、もう一度入力してもらう

**実行例**:
```
=== 数当てゲーム ===
難易度を選んでください
1. 簡単（1〜50、10回まで）
2. 普通（1〜100、7回まで）
3. 難しい（1〜200、5回まで）
番号: 2
1から100までの数を選びました。7回以内に当ててください
1回目: 50
もっと大きい数です（残り6回）
2回目: 75
もっと小さい数です（残り5回）
3回目: abc
1から100までの整数を入力してください
3回目: 62
正解です。3回で当てました
スコア: 300点
ベストスコアを更新しました
もう一度遊びますか？ (y/n): n

=== ゲームの記録 ===
遊んだ回数: 1回
当てた回数: 1回
当てるまでの平均回数: 3.0回
ベストスコア: 300点
```

## 実装のヒント

```java
// 1からmaxまでの整数を1つ選ぶ（Math.random()は0.0以上1.0未満の値を返す）
int target = (int) (Math.random() * max) + 1;

// 難易度ごとの設定を配列にまとめる
String[] levelNames = {"簡単", "普通", "難しい"};
int[] maxNumbers = {50, 100, 200};
int[] maxTries = {10, 7, 5};
```

- 「当たるか、回数を使い切るまで」の繰り返しは、`while (tries < maxTries && !hit)`のようにboolean型の変数を条件に使う
- 入力を読む処理（範囲外なら読み直す）はstaticメソッドにまとめると、難易度の選択と数の入力の両方で使える
- 数字以外の入力を`Integer.parseInt`に渡すと例外で止まる。例外処理は第13章で学ぶので、ここでは`charAt`で1文字ずつ調べ、数字だけのときに変換する
- `IO.readln`は入力の終わり（パイプで渡した入力がなくなったときなど）で`null`を返す

## 応用のポイント

1. 処理の分割
    - 難易度の選択、1回分のゲーム、スコアの計算、入力の読み取りをメソッドに分ける
2. 入力の検証
    - 想定外の入力でもプログラムが止まらないようにする
3. 状態の管理
    - ゲームをまたいで使う値（遊んだ回数、ベストスコア）はmainメソッドの変数で持つ
