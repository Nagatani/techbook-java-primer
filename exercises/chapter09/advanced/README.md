# 第9章 発展課題

## 学習目標
- 目的（順番・重複なし・キーで引く・並び順）に合わせて、List・Set・Mapとその実装クラスを選ぶ
- `LinkedHashMap`・`LinkedHashSet`で登録した順を保ち、`TreeSet`・`TreeMap`で並べ替える
- `containsKey`・`get`・`add`の戻り値で、すでに登録されているかを確かめる
- `Iterator`の`remove`で、走査しながら要素を安全に取り除く
- 値がコレクションのMap（`Map<String, List<String>>`）を組み立てる

## 課題一覧

### 課題1: 履修登録と時間割
**ファイル**（このフォルダーのファイルは解答例です）:
```
advanced/task1-timetable/
├── Course.java        科目
├── Timetable.java     1人の学生の時間割（履修登録）
└── TimetableApp.java  mainメソッド
```

開講科目の中から科目を選んで履修登録し、曜日ごとの時間割を表示するプログラムを作成してください。
科目は「月1」（月曜1限）のような曜日時限に開かれます。

**要求仕様**:
- `Course`（科目）
    - 科目コード・科目名・曜日時限・単位数を持つ
- `Timetable`（時間割）
    - 開講科目を科目コードから引けるMapで持つ。一覧は加えた順に出すので`LinkedHashMap`にする
    - 登録した科目コードをSetで持つ。登録した順に表示するので`LinkedHashSet`にする
    - 曜日時限から登録した科目を引けるMapを持つ
    - 登録では次の場合を断り、理由を返す
        + 開講科目にない科目コード
        + すでに登録した科目
        + 同じ曜日時限に別の科目を登録している
        + 登録すると単位の合計が上限（コンストラクターで指定する）を超える
    - 登録の取り消し、単位の合計、曜日ごとの時間割の文字列を作るメソッドを持つ

**実行例**:
```
=== 開講科目 ===
  C101 プログラミング（月1、2単位）
  C102 線形代数（月1、2単位）
  C103 英語（火2、1単位）
  C104 統計学（水1、2単位）
  C105 情報倫理（木3、2単位）
  C106 データベース（金2、2単位）
  C107 体育（金4、1単位）

=== 履修登録 ===
プログラミングを登録しました（合計 2単位）
英語を登録しました（合計 3単位）
線形代数は月1のプログラミングと重なります
プログラミングはすでに登録しています
統計学を登録しました（合計 5単位）
C999という科目はありません
情報倫理を登録しました（合計 7単位）
データベースを登録すると上限の8単位を超えます
体育を登録しました（合計 8単位）

=== 登録の取り消し ===
情報倫理の登録を取り消しました（合計 6単位）
C105は登録していません
データベースを登録しました（合計 8単位）

=== 時間割 ===
月: 1限 プログラミング
火: 2限 英語
水: 1限 統計学
木: なし
金: 2限 データベース、4限 体育
登録した科目（登録順）: [C101, C103, C104, C107, C106]
合計: 8単位
```

単位の上限は8単位です。
データベースは上限を超えるので一度断られ、情報倫理を取り消したあとに登録できます。

### 課題2: タグ付きのToDoリスト
**ファイル**（このフォルダーのファイルは解答例です）:
```
advanced/task2-todo/
├── Task.java      タスク
├── TodoList.java  ToDoリスト
└── TodoApp.java   mainメソッド
```

「大学」「買い物」のようなタグを付けられるToDoリストを作成してください。

**要求仕様**:
- `Task`（タスク）
    - 番号・内容・タグ・完了したかどうかを持つ
    - タグはSetで持ち、同じタグを二重に付けない。付けた順に表示する
- `TodoList`（ToDoリスト）
    - タスクを`ArrayList`で持つ。番号は1から順に振る
    - 番号でタスクを探す、完了にする、先頭に移す（`remove`と`add(0, タスク)`）
    - 完了したタスクをまとめて取り除き、取り除いた数を返す。`Iterator`の`remove`を使う
    - 使われているタグの一覧を、重複なしで辞書順（`TreeSet`）に返す
    - タグごとのタスクの内容を`Map<String, List<String>>`（`TreeMap`）で返す

**実行例**:
```
=== ToDoリスト ===
  [ ] 1. レポートを書く [大学, 締切]
  [ ] 2. 牛乳を買う [買い物]
  [ ] 3. サークルの会計をまとめる [サークル, 締切]
  [ ] 4. 図書館に本を返す [大学]
  [ ] 5. 洗剤を買う [買い物]

=== 3番を先頭に移し、2番と4番を完了にする ===
9番を完了にする: その番号はない
  [ ] 3. サークルの会計をまとめる [サークル, 締切]
  [ ] 1. レポートを書く [大学, 締切]
  [x] 2. 牛乳を買う [買い物]
  [x] 4. 図書館に本を返す [大学]
  [ ] 5. 洗剤を買う [買い物]

=== タグの一覧 ===
  [サークル, 大学, 締切, 買い物]

=== タグごとのタスク ===
  サークル: [サークルの会計をまとめる]
  大学: [レポートを書く, 図書館に本を返す]
  締切: [サークルの会計をまとめる, レポートを書く]
  買い物: [牛乳を買う, 洗剤を買う]

=== 完了したタスクを片付ける ===
  2件を取り除きました
  [ ] 3. サークルの会計をまとめる [サークル, 締切]
  [ ] 1. レポートを書く [大学, 締切]
  [ ] 5. 洗剤を買う [買い物]
  タグの一覧: [サークル, 大学, 締切, 買い物]
```

4番のタスクには「大学」を2回付けていますが、Setなので1つになります。
`TreeSet`と`TreeMap`の辞書順は文字コードの順なので、漢字は五十音順になりません（「大学」が「締切」より前に来るのは、文字コードがその順だからです）。

## 実装のヒント

```java
// 課題1: Setのremoveは、取り除けたかどうかをbooleanで返す
public String drop(String code) {
    if (!registered.remove(code)) {
        return code + "は登録していません";
    }
    // ...
}

// 課題2: 走査しながら取り除くときはIteratorを使う
Iterator<Task> it = tasks.iterator();
while (it.hasNext()) {
    if (it.next().isDone()) {
        it.remove();
    }
}
```

- 課題1の重なりの判定は、曜日時限をキーにしたMapで`get(course.getSlot())`を調べれば、登録した科目を1つずつ比べずに済む
- 課題1の時間割は、曜日の配列`{"月", "火", "水", "木", "金"}`と時限の番号を組み合わせたキー（`day + period`）でMapを引いて組み立てる
- 課題2で拡張for文の中から`tasks.remove(task)`を呼ぶと、`ConcurrentModificationException`になる
- 課題2のタグごとの一覧は、`get`して`null`なら新しい`ArrayList`を`put`してから、そのリストに加える
- 並べ替えの基準を自分で決める`Comparator`は第11章で学ぶので、ここでは`TreeSet`・`TreeMap`の標準の順（文字列なら文字コードの順）を使う

## 応用のポイント

1. 実装クラスの選び方
    - 「キーで引く」ならMap、「重複させない」ならSet、「順番に意味がある」ならList。そのうえで、順序が要らなければHash、登録順ならLinkedHash、並べ替えるならTreeを選ぶ
2. 戻り値を使った判定
    - `Set`の`add`・`remove`は、変更できたかどうかを返す。`contains`で調べてから変更する手間を省ける
3. 安全な削除
    - 走査しながら要素を取り除くのは`Iterator`の`remove`だけが安全である
