# 第17章 GUIプログラミングの基礎 - 演習課題

書籍『Java入門』第17章「GUIプログラミングの基礎」の演習課題です。

本章では画面の組み立てだけを学び、ボタンを押したときの処理（イベント処理）は第18章で学びます。
そのため、本章の課題のボタンやメニューは、押しても何も起きません。
第18章を読んだら、これらの画面にイベント処理を付け足してみてください。

## 基礎課題（[basic/](basic/)）

- プロフィールカード（BorderLayoutの5つの領域、JLabelのHTML表示、背景を塗るラベル）
- 電卓の画面（GridLayoutで同じ大きさのボタンを並べる、編集できないテキストフィールド）
- 授業アンケートの入力画面（入力系・選択系のコンポーネント、JPanelの入れ子）
- 棒グラフ（JPanelを継承し、paintComponentで描く）
- このフォルダーのJavaファイルは解答例です（課題ごとに`task1-profile/`などのフォルダーに分けてあります）

## 発展課題（[advanced/](advanced/)）

- 1か月分のカレンダー（GridLayoutでマス目を作る、日付の計算を画面から分ける）
- アナログ時計の文字盤（三角関数で円周上の点を求める、Graphics2Dの線の太さ）
- このフォルダーのJavaファイルは解答例です

## チャレンジ課題（[challenge/](challenge/)）

- 家計簿の画面（メニューバー、タブ、分割ペイン、自作の円グラフ）
- このフォルダーのJavaファイルは解答例です

## 動作確認のプログラム

計算をするクラスには、画面を開かずに計算の結果だけを確かめるプログラム（`〜Check.java`）を付けています。
期待する値と実際の値を比べて「OK」か「NG」を表示します。
