# 第17章 基礎課題

## 学習目標

- JFrameにコンポーネントを置き、`SwingUtilities.invokeLater`で画面を組み立てる（第17章の定型）

- JPanelを入れ子にして、複数のレイアウトを1つの画面で組み合わせる
- JPanelを継承し、`paintComponent`で図形と文字を描く

### 課題1: プロフィールカード

**ファイル**: `task1-profile/ProfileCardApp.java`

自己紹介のカードを表示するウィンドウを作ります。

**要求仕様**:

- BorderLayoutで、上（NORTH）に見出し、左（WEST）にアイコン、中央（CENTER）に項目、下（SOUTH）にボタンを置く
- 見出しは「自己紹介」を太字で大きく、中央にそろえて表示する
- アイコンは画像の代わりに、色を塗ったJLabelに頭文字を白い文字で出す。JLabelは背景を塗らないのが既定なので、`setOpaque(true)`にしてから`setBackground`で色を付ける。大きさは`setPreferredSize`で90×90にする
- 項目は、HTMLの表（`<table>`）を書いたJLabelで、名前・所属・得意な言語・趣味を2列にそろえて並べる
- 下のボタンは、FlowLayoutのJPanelに「メッセージを送る」と「フォロー中」の2つを並べる。「フォロー中」は押せなくしておく（`setEnabled(false)`）
- ウィンドウの大きさは`pack()`で中身に合わせる

**実行例**:

- 「プロフィール」というウィンドウが開き、上に大きく「自己紹介」と表示される
- 左に青い正方形があり、白い文字で「YT」と書いてある
- その右に「名前　山田 太郎」「所属　情報工学科 2年」のように、項目名と内容が2列にそろって並ぶ
- 下に2つのボタンが中央に並び、「フォロー中」は灰色で押せない

### 課題2: 電卓の画面

**ファイル**: `task2-calculator/CalculatorLayoutApp.java`

電卓の見た目だけを作ります。

**要求仕様**:

- 上（NORTH）に表示欄、中央（CENTER）に数字と演算子のボタン、下（SOUTH）に「クリア」ボタンを置く
- 表示欄は`JTextField`で、最初は「0」を右寄せで表示する。入力はボタンで行うので`setEditable(false)`にする
- ボタンは`GridLayout(4, 4, 4, 4)`のJPanelに16個並べる。ボタンの文字は、並べる順に配列に入れておき、拡張for文で作る
- 「クリア」はSOUTHに1つだけ置き、左右いっぱいに広がることを確かめる
- ウィンドウの大きさは`setSize(300, 380)`にする

**実行例**:

- 「電卓」というウィンドウが開き、上の欄の右端に大きく「0」と表示される
- 中央に「7 8 9 ÷」「4 5 6 ×」「1 2 3 −」「0 . = +」の4行のボタンが、すべて同じ大きさで並ぶ
- 下の「クリア」ボタンはウィンドウの幅いっぱいに広がる
- ウィンドウの端をドラッグして広げると、16個のボタンが同じ割合で大きくなる。表示欄と「クリア」は横にだけ広がる

### 課題3: 授業アンケートの入力画面

**ファイル**: `task3-survey/SurveyFormApp.java`

授業アンケートの入力画面を作ります。

**要求仕様**:

- 項目名と入力部品を、`GridLayout(0, 2, 8, 6)`のJPanelに2列で並べる（行の数の0は「必要なだけ」の意味）
    - 名前: `JTextField`
    - 年齢: `JSpinner`（初期値20、0〜120）
    - 学年: `JComboBox`（1年〜4年、最初は2年を選んでおく）
    - 好きな言語: `ButtonGroup`にまとめた3つの`JRadioButton`（Java・C・Python、最初はJava）。3つを左寄せのFlowLayoutのJPanelに入れて、1つのマスに置く
    - 使ったことのあるエディター: 3つの`JCheckBox`（VS Code・IntelliJ IDEA・Eclipse、最初はVS Codeだけにチェック）
    - 満足度: 1〜5の`JSlider`（最初は4）。目盛りと数字を表示する
- 感想は`JTextArea`を`JScrollPane`に入れ、「感想」という枠（`BorderFactory.createTitledBorder`）を付ける
- 全体はBorderLayoutで、上に項目の格子、中央に感想、下に右寄せの「送信」ボタンを置く

**実行例**:

- 「授業アンケート」というウィンドウが開き、左に項目名、右に入力部品が6行並ぶ
- 年齢の欄には20と表示され、右の矢印で数を増減できる
- 好きな言語のラジオボタンは、別のものを選ぶと前の選択が外れる。エディターのチェックボックスはいくつでも選べる
- 満足度のスライダーの下に1〜5の数字が並び、つまみは4の位置にある
- その下に「感想」の枠付きの入力欄があり、いちばん下の右端に「送信」ボタンがある
- GridLayoutはすべてのマスを同じ高さにするので、1行のテキストフィールドも、いちばん高いスライダーと同じ高さになる

### 課題4: 棒グラフ

**ファイル**: `task4-bar-chart/ChartScale.java`、`task4-bar-chart/BarChartPanel.java`、`task4-bar-chart/BarChartApp.java`

月ごとの来館者数を棒グラフで表示します。

**要求仕様**:

- `ChartScale`は画面に依存しないクラスで、配列の最大値を返す`max`と、値を棒の高さ（ピクセル）に直す`barHeight(値, 最大値, 描く領域の高さ)`を持つ。最大値の棒が領域の高さちょうどになるようにし、四捨五入する
- `BarChartPanel`は`JPanel`を継承し、タイトル・ラベルの配列・値の配列を受け取る。配列はコピーして持つ（第6章）。ラベルと値の数が違うときは`IllegalArgumentException`を投げる
- `getPreferredSize`で480×320を返し、`paintComponent`では最初に`super.paintComponent(g)`を呼んでから描く
    - 上の中央にタイトル、左と下に軸を引く
    - 棒は、最大値の棒だけ色を変える
    - 棒の上に値、下にラベルを、`FontMetrics`で文字の幅を測って棒の中央にそろえて書く
- `BarChartApp`は4月〜9月の来館者数（120, 95, 140, 180, 210, 160）を渡して表示する

**実行例**:

- 「図書館の来館者数」というウィンドウが開き、上に「月ごとの来館者数（人）」と表示される
- 4月〜9月の6本の棒が並び、いちばん高い8月（210）の棒だけが赤く、ほかは青い
- 棒の上に「120」「95」などの値、下に「4月」「5月」などのラベルが、棒の中央にそろって表示される
- ウィンドウを広げると、棒の幅と高さが新しい大きさに合わせて描き直される

`ChartScaleCheck`を実行すると、棒の高さの計算を確かめられます。

```
=== ChartScaleの動作確認 ===
OK  最大値
OK  空の配列の最大値は0
OK  最大値の棒は領域の高さ
OK  半分の値は半分の高さ
OK  四捨五入する（120 / 210 × 230 = 131.4...）
OK  0の値は高さ0
OK  最大値が0なら高さ0

7件中7件OK
```

## 実装のヒント

- BorderLayoutのNORTH・SOUTHに置いた部品は左右いっぱいに、WEST・EASTに置いた部品は上下いっぱいに広がる。CENTERは残りの全部を使う
- GridLayoutは、すべてのマスを同じ大きさにする。項目名と入力欄で幅や高さを変えたいときは、本書では扱わないGridBagLayoutやBoxLayoutを使う方法がある
- FlowLayoutは、部品を適切な大きさのまま左から並べる。ボタンを伸ばしたくないときは、FlowLayoutのJPanelに入れてからBorderLayoutの領域に置く
- `paintComponent`の中では、`getWidth()`と`getHeight()`で今のパネルの大きさを調べてから描く。決まった数で描くと、ウィンドウを広げたときに図がついてこない
- 画面のy座標は下へ行くほど大きい。棒の左上の角のy座標は「x軸のy座標 − 棒の高さ」になる
