# 第17章 チャレンジ課題

## 学習目標

- メニューバー・タブ・分割ペインを組み合わせて、1つのアプリの画面を組み立てる
- 画面ごとの部品を作るメソッドを分け、コンストラクターを読みやすく保つ
- 集計をするクラスを画面から分け、その結果を一覧・グラフ・合計の表示に使い回す

## 課題一覧

### 課題1: 家計簿の画面

**ファイル**（このフォルダーのファイルは解答例です）:

```
challenge/
├── Expense.java         1件の支出（レコード）
├── Household.java       支出の一覧と集計（GUIなし）
├── HouseholdCheck.java  Householdの動作確認
├── PieChartPanel.java   分類ごとの合計を描く円グラフ
└── HouseholdApp.java    画面、mainメソッド
```

1か月分の支出を、一覧・円グラフ・入力欄の3つのタブで表示する家計簿の画面を作成してください。

**要求仕様**:

- `Expense`は、日付（`LocalDate`）・分類・内容・金額を持つレコードにする。金額が0以下なら`IllegalArgumentException`を投げる
- `Household`（GUIに依存しない）
    - 分類の一覧を受け取り、支出を追加する`add`を持つ。一覧にない分類の支出は`IllegalArgumentException`で断る
    - 合計の`getTotal`と、分類ごとの合計を返す`totalsByCategory`を持つ。分類ごとの合計は、分類を登録した順に並べ（`LinkedHashMap`）、支出のない分類も0として入れる
    - 金額が合計に占める割合を、円グラフの角度（度）に直す静的メソッド`toDegrees(金額, 合計)`を持つ。四捨五入し、合計が0なら0を返す
- `PieChartPanel`は、分類ごとの合計と色の一覧を受け取り、`fillArc`で扇形を描く
    - 12時の方向から時計回りに並べる。`fillArc`の角度は3時の方向が0度で反時計回りに増えるので、開始角を90度にし、扇の角度を負の数で渡す
    - 四捨五入の誤差で隙間や重なりができないよう、最後の扇は残りの角度すべてにする
- `HouseholdApp`（画面）
    - ウィンドウのタイトルは「家計簿 - 2026年11月」
    - メニューバーに「ファイル」（開く・保存・区切り線・終了）と「表示」（前の月・次の月）を置く
    - `JTabbedPane`に3つのタブを置く
        - 一覧: 支出を1行ずつ書いた、編集できない`JTextArea`（等幅の文字）を`JScrollPane`に入れる
        - グラフ: `JSplitPane`の左に円グラフ、右に凡例（色の見本と「食費  9,700円」の形の文字）を置く
        - 入力: 日付・分類（`JComboBox`）・内容・金額（`JSpinner`）の格子と、右寄せの「追加」ボタンを置く
    - 下に「支出 8件  合計 24,500円」の形で件数と合計を表示する
    - タブ・グラフ・入力欄はそれぞれ別のメソッドで作り、コンストラクターではそれらを組み合わせるだけにする

**実行例**:

`java HouseholdApp`を実行すると、「家計簿 - 2026年11月」というウィンドウが開きます。

- 上に「ファイル」「表示」のメニューがあり、クリックすると項目が開く（選んでも何も起きない）
- 「一覧」タブには、次のように8件の支出が並ぶ

```
2026-11-02    3,200円  食費  スーパー
2026-11-03    9,800円  交通費  定期券
2026-11-07      650円  日用品  洗剤
2026-11-09    2,400円  食費  学食
2026-11-14    1,900円  娯楽  映画
2026-11-16    4,100円  食費  スーパー
2026-11-21    1,650円  娯楽  本
2026-11-25      800円  日用品  文房具
```

- 「グラフ」タブを開くと、左に円グラフ、右に凡例が並ぶ。円グラフは12時の方向から時計回りに、食費（約4割）・交通費（約4割）・日用品・娯楽の順に色分けされる。支出のない「その他」は凡例に「その他  0円」と出るだけで、扇はない
- 円グラフと凡例の境目はドラッグで動かせる
- 「入力」タブには、日付（2026-11-30）・分類・内容・金額（1000）の入力欄と「追加」ボタンが並ぶ
- ウィンドウの下には「支出 8件  合計 24,500円」と表示される

`java HouseholdCheck`を実行すると、集計の結果を確かめられます（最後に「7件中7件OK」と表示されます）。

## 本文で扱っていないAPI

円グラフを滑らかに描くために、`Graphics2D`と`RenderingHints`（発展課題2のREADMEを参照）を使っています。

## コンパイルと実行

```bash
cd exercises/chapter17/challenge
javac *.java
java HouseholdApp
java HouseholdCheck
```

## 実装のヒント

- 日本語の文字は、等幅の文字でも英数字の2倍ほどの幅がある。`%-6s`などで文字数をそろえても列がずれるので、幅の決まった日付と金額を前に、日本語の分類と内容を後ろに置く
- `JSplitPane`の`setResizeWeight(0.6)`で、ウィンドウを広げたときに増えた幅の6割を左側に配る
- 凡例の色の見本は、課題1（基礎）のアイコンと同じく、`setOpaque(true)`にしたJLabelで作れる
- 第18章を読んだら、「追加」ボタンで支出を加えて一覧・グラフ・合計を作り直す処理を付けてみる。そのとき、集計を`Household`に分けてあるので、画面のクラスは表示を作り直すだけで済む
