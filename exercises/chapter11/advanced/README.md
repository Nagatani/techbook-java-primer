# 第11章 発展課題

## 学習目標
- 独自の関数型インターフェイスを設計し、ラムダ式とメソッド参照で実装する
- 関数型インターフェイスにデフォルトメソッドを書き、ルールを組み合わせる
- 静的メソッド参照と、特定のインスタンスのメソッド参照を使い分ける
- `Comparator.comparing`・`comparingInt`・`thenComparing`・`reversed`で並べ方を組み立てる
- 関数（ラムダ式やComparator）をMapに入れたり、メソッドの引数として渡したりする

## 課題一覧

### 課題1: レジの割引ルール
**ファイル**（このフォルダーのファイルは解答例です）:
```
advanced/task1-discount/
├── Item.java          商品（レコード）
├── Cart.java          買い物かご
├── DiscountRule.java  割引ルール（独自の関数型インターフェイス）
├── Discounts.java     店の決まった割引（静的メソッド）
├── MemberCard.java    会員カード（会員ごとの割引率）
├── Register.java      割引ルールを当てはめてレシートを表示するレジ
└── DiscountApp.java   mainメソッド
```

パンと弁当を扱う小さな店のレジを作成してください。
割引の決まりは店の都合でよく変わるので、割引を「買い物かごを受け取って割引額を返す関数」として表し、レジに登録できるようにします。

**要求仕様**:
- `DiscountRule`（割引ルール）
    - `@FunctionalInterface`を付け、抽象メソッド`int discount(Cart cart)`を1つだけ持つ
    - デフォルトメソッド`plus(DiscountRule other)`は、2つのルールの割引額を足した新しいルールを返す
    - デフォルトメソッド`upTo(int limit)`は、割引額に上限を付けた新しいルールを返す
- `Cart`（買い物かご）
    - 合計金額と、指定した分類（「パン」「弁当」「飲み物」）の商品の数を返す
    - `forEachItem(Consumer<Item> action)`で、商品を1つずつ呼び出し側の処理に渡す
- 割引の実装
    - パンを3個以上買うと100円引き、弁当と飲み物の組1つごとに50円引きを、`Discounts`の静的メソッドとして書く
    - 合計1000円以上で100円引きは、登録するときにラムダ式で書く
    - 会員割引は、会員カードのオブジェクトごとに割引率が違う。`MemberCard`の`discount`メソッドを、特定のインスタンスのメソッド参照（`card::discount`）で登録する
- `Register`（レジ）
    - 割引の名前とルールを、登録した順に保持する（`LinkedHashMap`）
    - 会計では、商品・小計・0円でない割引・支払額を表示する。どの割引も割引前の合計をもとに計算する

**実行例**:
```
=== 1人目 ===
  あんパン 150円
  食パン 230円
  メロンパン 160円
  牛乳 180円
  小計 720円
  パン3個割 -100円
  田中さんの会員割引(5%) -36円
  お支払い 584円

=== 2人目 ===
  のり弁当 480円
  唐揚げ弁当 550円
  お茶 130円
  小計 1160円
  弁当セット割 -50円
  1000円以上で100円引き -100円
  田中さんの会員割引(5%) -58円
  お支払い 952円

=== ルールを組み合わせる ===
  あんパン 150円
  クリームパン 150円
  カレーパン 180円
  幕の内弁当 600円
  お茶 130円
  小計 1210円
  セット割(上限120円) -120円
  お支払い 1090円
```

3人目は、パン3個割（100円）と弁当セット割（50円）を`plus`で足した150円に、`upTo(120)`で上限を付けています。

### 課題2: 成績一覧の並べ替え
**ファイル**（このフォルダーのファイルは解答例です）:
```
advanced/task2-ranking/
├── Student.java     学生の成績（レコード）
├── Ranking.java     並べ方を受け取って並べ替える成績一覧
└── RankingApp.java  mainメソッド
```

同じ成績一覧を、学籍番号順・点数順・学年順など、いろいろな順に並べて表示するプログラムを作成してください。

**要求仕様**:
- `Student`は学籍番号・氏名・学年・点数を持つレコードにする
- `Ranking`（成績一覧）
    - `sortedBy(Comparator<Student> order)`は、元のリストを変えずに、並べ替えた写しを返す
    - `first(Comparator<Student> order)`は、並べ方で最初に来る学生を返す。並べ方を逆にすれば、同じメソッドで最後の学生も求められる
    - `printRanked(Comparator<Student> order, Consumer<String> out)`は、順位を付けた行を`out`に渡す。mainからは`IO::println`を渡す
- 並べ方
    - 学籍番号順、点数の高い順（同点は学籍番号順）、学年順で学年の中は点数の高い順の3つを、`Comparator`のメソッドとメソッド参照（`Student::score`など）で組み立てる
    - 並べ方に名前を付けて`Map<String, Comparator<Student>>`に入れ、順に取り出して表示する
    - `reversed()`を条件の最後に付けると、2つ目の条件まで逆順になることを確かめる
- 60点未満の学生（再試験の対象）を、`removeIf`とラムダ式で絞り込んで表示する

## 実装のヒント

```java
@FunctionalInterface
public interface DiscountRule {
    int discount(Cart cart);

    // 自分とotherの両方を使う新しいルールを、ラムダ式で作って返す
    default DiscountRule plus(DiscountRule other) {
        return cart -> discount(cart) + other.discount(cart);
    }
}

// どれもDiscountRuleとして渡せる
register.addRule("パン3個割", Discounts::breadBundle);        // 静的メソッド参照
register.addRule("1000円以上", cart -> cart.total() >= 1000 ? 100 : 0);
register.addRule("会員割引", card::discount);                 // 特定のインスタンスのメソッド参照
```

- メソッド参照は、メソッドの引数と戻り値の型が関数型インターフェイスの抽象メソッドと合えば使える。`Discounts.breadBundle(Cart)`も`card.discount(Cart)`も、`Cart`を受け取り`int`を返す
- メソッド参照のあとに直接`.plus(...)`は書けない（どの関数型インターフェイスか決まらない）。`DiscountRule bread = Discounts::breadBundle;`と、いったん変数に入れてから呼ぶ
- `Comparator.comparingInt(Student::score).reversed()`のように、降順にしたい条件の直後で`reversed()`を呼ぶ。条件全体の最後に付けると、後ろの条件も逆になる
- 2つ目の条件だけを降順にするときは、`thenComparing(Comparator.comparingInt(Student::score).reversed())`と、逆にしたComparatorを渡す
- `List.sort`は元のリストを並べ替えるので、元の順序を残したいときは`new ArrayList<>(リスト)`で写しを作ってから並べ替える

## 応用のポイント

1. 振る舞いをデータとして扱う
    - 割引の決まりや並べ方を、`if`文の分岐ではなく関数として登録するので、決まりを足すときにレジや一覧のクラスを直さなくてよい
2. 関数型インターフェイスとメソッド参照
    - 既存のメソッドの形が抽象メソッドと合っていれば、ラムダ式を書かずにメソッド参照で渡せる
3. 組み合わせて新しい関数を作る
    - `plus`・`upTo`や`thenComparing`・`reversed`は、元の関数を変えずに新しい関数を返す
