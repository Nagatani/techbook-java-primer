# 第23章 ビルドとデプロイ - 演習課題

## 概要
本章ではJavaアプリケーションのビルド、パッケージング、配布について学習しました。実行可能JARの作成、リソースを含むJAR、jpackageによるランタイム同梱のアプリケーションとインストーラーの作成を通じて、作ったプログラムを他の人に届ける方法を身につけましょう。

## 課題構成

### 基礎課題（basic/）
- **課題1**: 実行可能JARの作成（解答例は`solutions/`の`CalculatorApp.java`・`manifest.txt`・`build.sh`）
- **課題2**: リソースを含むJAR（解答例は`solutions/`の`MessageApp.java`・`resources/`）
- **課題3（発展）**: 外部ライブラリを使うアプリのFat JAR（解答例は`solutions/`の`JsonTool.java`・`build-fatjar.sh`）

### 発展課題（advanced/）
このフォルダーのJavaファイルは解答例です。
- **課題1**: 時間割ビューアーの実行可能JAR（`task1-timetable/`）。時間割のCSVと設定ファイルをリソースとしてJARに含め、`getResourceAsStream`で読む

### チャレンジ課題（challenge/）
このフォルダーのJavaファイルは解答例です。
- **課題1**: 単語帳アプリを配布できる形にする。Swingアプリを実行可能JARにし、`jdeps`で調べたモジュールだけを同梱したapp-imageと、自分のOS向けのインストーラーを`jpackage`で作る

## 実行方法
各課題のディレクトリに移動し、README.mdの指示に従ってください。
ビルドツールのインストールが必要な場合があります。

## 評価基準
- マニフェストとJARの中身が正しいこと
- リソースをJARの中から読めること
- 開発に使ったフォルダーの外でも、配ったファイルだけで動くこと
- セキュリティとベストプラクティスの遵守
