# SimpleJSONへの貢献

SimpleJSONに関心を持っていただき、ありがとうございます。
不具合の報告・改善の提案・プルリクエストを受け付けています。

## 不具合を報告する

Issueに次のことを書いてください。

- 解析・生成した入力（短くした例があると助かります）
- 期待した結果と、実際の結果（例外のメッセージを含む）
- JDKの版（`java -version`の表示）

## プルリクエストを送る

1. 変更の前に、`mvn test`（または`gradle test`）がすべて通ることを確かめる
2. 機能を足すときや不具合を直すときは、先にその動きを確かめるテストを書き、失敗することを確かめてから実装する
3. 公開するクラスとメソッドには、Javadocを書く。`mvn javadoc:javadoc`（または`gradle javadoc`）が警告なしで通ることを確かめる
4. 変更の内容と理由を、プルリクエストの説明に書く

## コードの書き方

- 外部ライブラリに依存しない。テストのJUnitだけを使う
- 字下げは空白4文字
- 失敗は`JsonException`で知らせ、メッセージには何が・なぜ失敗したかを日本語で書く
- 公開するAPIを変えるときは、これまでの利用者のプログラムが動き続けるかを考える。新しいメソッドには`@since`を付ける
