# 第18章 基本的なイベント処理 - 演習課題

書籍『Java入門』第18章「基本的なイベント処理」の演習課題です。

## 基礎課題（[basic/](basic/)）

- 入室カウンター（ActionListener、1つのリスナーをアクションコマンドで使い分ける、ボタンの有効・無効）
- ピザの注文（ItemListener、JRadioButtonとButtonGroup、JCheckBox）
- 色の調合（ChangeListener、スライダーとスピナーの連動、getValueIsAdjusting）
- 会員登録フォーム（FocusListenerによる入力の検査、MouseAdapterによる説明の切り替え、WindowAdapterによる終了の確認）
- このフォルダーのJavaファイルは解答例です（課題ごとに`task1-counter/`などのフォルダーに分けてあります）

## 発展課題（[advanced/](advanced/)）

- ストップウォッチ（javax.swing.Timer、状態に合わせたボタンの切り替え、ラップの記録）
- 長さの単位換算（ActionListener・ItemListener、入力の検査とエラー表示）
- このフォルダーのJavaファイルは解答例です

## チャレンジ課題（[challenge/](challenge/)）

- 制限時間つきクイズ（ボタンと数字キーでの回答、Timerによる制限時間、終了時の確認）
- このフォルダーのJavaファイルは解答例です

マウスの移動やドラッグ、キーバインディング、DocumentListenerを使う大きめの例は、第19章で学ぶ内容なので、[第19章のexamples/](../chapter19/examples/)に置いています。
