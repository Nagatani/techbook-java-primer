# 第14章 基本課題

## 学習目標

- 文字ストリーム（BufferedReader・BufferedWriter）とバイトストリーム（FileInputStream・FileOutputStream）を使い分ける
- 文字エンコーディングを指定してテキストを読み書きする
- `Files`クラスで、フォルダーの作成、ファイルの一覧・コピー・削除・大きさの取得を行う
- CSVやログのような行単位のテキストを読み、壊れた行を読み飛ばしながら集計する
- try-with-resources（第13章）で、例外が起きてもファイルを確実に閉じる

## 課題一覧

各課題の「作成するファイル」は、自分で作成するファイルの名前の例です。課題ごとの解答例は[solutions/](../solutions/)にあり、実行例はその解答例を動かした出力です。

どの課題も、実行したフォルダーに作業用のフォルダー（`io-basic-work/`など）を作り、その中でファイルを読み書きします。
何度実行しても同じ結果になるよう、読み込む見本のファイルもプログラムの中で作ります。

### 課題1: テキストとバイナリの読み書き

**作成するファイル**: `BasicFileIO.java`

テキストを1行ずつ書いて読み、バイナリのファイルをバッファーを使ってコピーします。

**要求仕様**:

- `io-basic-work/`がなければ`Files.createDirectory`で作る
- `Files.newBufferedWriter`でUTF-8を指定して3行書き、`Files.newBufferedReader`で行番号を付けて読む
- `Files.readAllLines`で行数を、`Files.size`でファイルの大きさを表示する
- `FileOutputStream`で0〜255の256バイトを書き、`FileInputStream`から100バイトずつのバッファーで別のファイルへコピーする
- 2つのファイルを`Files.readAllBytes`で読み、中身が同じことを確かめる

**実行例**:

```
書き込み: diary.txt
--- BufferedReaderで読む ---
1: 今日はJavaのファイル入出力を学んだ
2: BufferedWriterで1行ずつ書く
3: 最後の行
readAllLinesの行数: 3
ファイルの大きさ: 97バイト
--- バイナリのコピー ---
コピーしたバイト数: 256
先頭の4バイト: 0 1 2 3
中身が同じ: true
```

`newLine()`が書く改行はOSで異なります。Windowsでは改行が2バイトになるので、ファイルの大きさは100バイトになります。

### 課題2: フォルダーの操作とバックアップ

**作成するファイル**: `FolderOperations.java`

フォルダーの中のファイルを一覧にし、`.txt`のファイルだけをバックアップ用のフォルダーへコピーします。

**要求仕様**:

- `folder-work/`と`folder-work/backup/`を作り、`Files.writeString`で3つのファイルを作る
- `Files.list`でファイルの一覧を取り、名前順に並べて大きさと合計を表示する（`Files.list`の順序はOSによって変わるため、並べ替えてから使う）
- `.txt`で終わるファイルを`Files.copy`で`backup/`へコピーする。2回目の実行でも止まらないよう、`StandardCopyOption.REPLACE_EXISTING`を指定する
- `Files.delete`で1つのファイルを消し、バックアップには残っていることを`Files.exists`で確かめる

**実行例**:

```
--- フォルダーの中身（名前順） ---
memo.txt (24バイト)
report.txt (58バイト)
score.csv (34バイト)
合計: 116バイト

--- .txtをバックアップ ---
コピー: memo.txt -> backup/memo.txt
コピー: report.txt -> backup/report.txt

--- 削除 ---
memo.txtを削除しました
memo.txtはある？: false
backup/memo.txtはある？: true

--- 削除したあとの中身 ---
report.txt (58バイト)
score.csv (34バイト)
合計: 92バイト

--- backupの中身 ---
memo.txt (24バイト)
report.txt (58バイト)
合計: 82バイト
```

### 課題3: CSVの読み込みと集計

**作成するファイル**: `CsvProcessor.java`

社員の一覧のCSVを読み、部署ごとに集計して、一部の行を別のCSVに書き出します。

**要求仕様**:

- `csv-work/employees.csv`に、見出しの行と7行のデータを書く。そのうち2行は、項目が足りない行と、年齢が数字でない行にする
- 1行目（見出し）を読んだあと、残りの行を`split(",")`で分けてRecordの`Employee`にする。項目の数が違う行と、数値に変換できない行は、行番号と理由を表示して読み飛ばす
- 部署ごとの人数と平均給与を、部署名の順に表示する（`TreeMap`を使う）
- 開発部の社員だけを、見出しを付けて`csv-work/development.csv`に書き出し、読み直して表示する

**実行例**:

```
見出し: ID,名前,部署,年齢,給与
4行目を読み飛ばします: 項目の数が3個です（5個のはず）
7行目を読み飛ばします: 数値に変換できません（1006,中村美咲,営業部,三十二,5200000）
読み込み: 5件、読み飛ばし: 2件

--- 部署別 ---
営業部: 1名（平均給与 5,000,000円）
総務部: 1名（平均給与 4,200,000円）
開発部: 3名（平均給与 5,666,666円）

--- development.csv（3件） ---
ID,名前,部署,年齢,給与
1002,佐藤花子,開発部,25,4500000
1004,鈴木一郎,開発部,35,6000000
1007,小林健,開発部,41,6500000
```

部署名は文字コードの順に並ぶため、「営業部・総務部・開発部」の順になります。

### 課題4: アクセスログの集計

**作成するファイル**: `LogAnalyzer.java`

Webサーバーのアクセスログ（時刻・IPアドレス・メソッド・パス・ステータスを空白で区切った形）を読み、集計します。

**要求仕様**:

- `log-work/access.log`に10行のログを書く。そのうち1行は形式の違う行にする
- 各行を`split(" ")`で分け、項目が5つの行だけをRecordの`LogEntry`にする。形式の違う行は数える
- ステータスごとの件数（ステータスの順）、ページごとの件数（多い順、同じ件数ならパスの順）、異なるIPアドレスの数を表示する
- ステータスが400以上の行を、時刻・パス・ステータスで表示する

**実行例**:

```
解析した行: 9、形式が違う行: 1

--- ステータス別 ---
200: 5件
302: 1件
403: 1件
404: 1件
500: 1件

--- ページ別（多い順） ---
/index.html: 4件
/about.html: 2件
/admin: 1件
/login: 1件
/style.css: 1件

異なるIPアドレスの数: 5

--- エラー（400以上） ---
10:02:31 /style.css 404
10:07:45 /admin 403
10:09:59 /index.html 500
```

## コンパイルと実行

```bash
javac BasicFileIO.java
java BasicFileIO
```

ほかの課題も同じように実行します。作業用のフォルダーは、実行したフォルダーにできます。

## ヒント

### 課題1のヒント

- `Path.of("io-basic-work").resolve("diary.txt")`で、フォルダーの中のファイルのパスを作れる
- `readLine()`はファイルの終わりで`null`を返す
- `read(buffer)`は読んだバイト数を返し、終わりでは`-1`を返す。書くときは`write(buffer, 0, n)`で読んだ分だけ書く

### 課題2のヒント

- `Files.list`はStream（第12章）を返す。閉じる必要があるので、try-with-resourcesで囲む
- `Files::isRegularFile`で、フォルダーを除いてファイルだけにできる

### 課題3のヒント

- 見本のCSVは、テキストブロック（`"""`）で書くと読みやすい
- `NumberFormatException`は`IllegalArgumentException`の子なので、まとめてcatchできる
- `map.computeIfAbsent(部署, k -> new ArrayList<>()).add(社員)`で、部署ごとのリストを作れる

### 課題4のヒント

- `map.merge(キー, 1, Integer::sum)`で、キーごとの件数を数えられる
- 件数の多い順に並べるには、`Map.Entry.comparingByValue()`を`reversed()`した比べ方を使う。並べ替えは安定なので、TreeMapから取り出した順（パスの順）が同じ件数の中で保たれる
